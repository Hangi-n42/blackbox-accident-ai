# 선택 분할 시각 중복 감사

**관찰한 사고 중복 미발견.** train4×CCD8의32쌍과 train4 내부6쌍에서 같은 사고로 볼 근거를 찾지 못했다. 데이터셋명이 다르다는 이유가 아니라 실제 상대 차량·사고 경로·도로/건물 맥락으로 비교했다. 완전한 원천 독립성은 인증하지 않는다.

CCD8은 각각 눈 남은 상가 주차장 해치백(688), 적재물 있는 흰 평판트럭(801), 트럭 카메라와 BMW SUV(453), 낮 수목도로 Mazda(196), 교차로 흰 MPV(728), 녹색 광고 탑차(1237), 눈 남은 도심의 선회 세단(052), 방호벽 고속도로 흰 SUV(540)로 시각상 위4사고와 구별된다.

직전 동일 세션에서 실제 본 학습4의192개 시간 표본/사건6시트/선택 원본13장과 CCD8 전체400프레임 시트를 사용했다. 이번에는 CCD196/052 사고 시트를 다시 열어 대조했다. 구체적 파일과32+6쌍 기록은 JSON에 있다.

기존 [CCD12 공개/Nexar 감사](/Users/hyeongi/projects/blackbox-accident-ai/artifacts/stage2_goal_20260920/ccd_public_overlap.md)는 CCD600·공개250·Nexar64×12 표본을, [신규CCD12 감사](/Users/hyeongi/projects/blackbox-accident-ai/artifacts/stage2_first_frame_policy_20260920/intake/overlap.md)는 신규600 대 기존1822개 지정 프레임을 선별 비교했다. 두 문서는 해당 범위 해시 일치0과 시각 중복 미발견을 보고한다. 이 후속에서 해시/pHash/전수 시간정렬을 다시 계산하지 않았다.

Nexar 미표본 구간, 숨은 편집/재업로드, 임의 crop·색변경 및 다른 카메라를 모두 배제하지 못한다. 원본 전체 사건이 독립이라고 단정하지 않으며, CCD8의 기존 결과 노출도 그대로 남는다. 이 결과는 현재 선택 분할의 중복 선별 통과로만 사용한다.
