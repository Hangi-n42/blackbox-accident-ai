2026-09-21. AI 전문가 에이전트의 독립 반박 검토이며 사람 검수 아니다. 학습·추론·코드 변경 없이 기존 보고서와 동결 기준을 읽었다. 아래는 구체 후보 수신 전 초안이다.

## 바로 재제안하면 안 되는 실험

- **범위 확대 후보를 새 개선 후보로 되살리기:** strict 1,083→curated 2,395는 이미 공개 S3 .749301→.808951와 공개 반전1→2, 날짜1 반전140→278이 함께 관찰됐다. 예약18창에서 좋아도 기존 위험 위반이 사라지지 않는다. 새 경로 일반화 진단은 가능하지만 새 안전 개선의 증거로 표현하면 안 된다. 학습 총손실량 맞춘 대조도 이미 완료했다.
- **같은 가중치/편향 재탐색:** 차량 균등, 차량·원천 균등, 50% 혼합, 4배 상한 및 train-only 내부 선택 모두 완료했다. official bias는 nested LOVO + lambda1, 공개 변화0·외부 새 반전6개로 실패했다. 새 C/상한/lambda 하나 선택만으로 다른 오류 가정이 생기지 않는다.
- **같은 표현에서 단순 용량 확대:** 제한 HGB는 train F1 .947–.976이나 공개 S3 .740018로 악화했고, RF/ExtraTrees/작은 시간창 NN은 이전 검토 대상이었다. 다른 모델 전부를 기각할 수는 없지만, 다른 이름만으로 새 가설을 주장할 수 없다.
- **ROI 제거/가림의 반복:** 12개 ROI 50% 가림 증강은 외부 날짜 F1이 모두 올랐지만 공개 .808951→.800063, 날짜1 새 반전14개·ZOD3개였다. 특징 기여도가 높다는 것은 제거가 개선된다는 인과 근거가 아니다.
- **기하 중간 지표 연장:** 배경점 공급/PnP 유효 쌍 증가에도 실제 사용 가능 q는0/8이다. 45분 안 실제 분류 평가로 연결할 수 있다는 근거가 없으면 후보로 택하지 말아야 한다.

## 평가 오류 방지 조건

1. 운영 c52 체크포인트의 공개 .849724는 공개 정답 학습 노출 재평가다. 연구 LOVO .808951와 직접 비교 금지. 운영 과거 OOF .798298 역시 학습 표본/캐시/선택 조건이 달라 단순 우열 근거가 아니다.
2. 연구 공개 LOVO는 fold당 외부2395+공개40, held-out10, 고정 조향47시각 F1 .850304, S3=.7*가감속4범주MacroF1+.3*조향3범주MacroF1 조건이다. 날짜별 external-only 기준은 .607414/.484176/.302424다.
3. official_bias 날짜 결과는 external-train+공개50 학습이므로 기준부터 .613896/.504946/.310648이다. 이 결과를 external-only 기준과 비교해 후보 이득이라 부르면 오류다.
4. ZOD에 정지 정답이 없을 때 4범주 평균과 관측3범주 평균은 다르다. 같은 라벨 집합 지표끼리만 비교하고 support를 함께 보고한다. comma 날짜 분할의 반복시각을 합쳐 독립 사례 수로 주장하지 않는다.
5. 반전→등속은 반전 해소이나 정답 복구가 아니다. 최소한 기존 반전→정답, 기존 반전→다른 오답, 기존 정답→반전, 기타 오답→반전을 각각 저장해야 한다.
6. 새 반전0과 반전율 비증가는 다른 조건이다. 사전 기준을 바꾸려면 새 결과 전 이유를 명시해야 하며 사후 완화는 안 된다. 이전 연구 승격 기준은 공개 새 반전0 및 외부 각 날짜/차량 반전율 증가≤.01이다. `stage3_group_weighting_20260919/freeze.json`은 연구 기준 상대 부분 개선와 strict 상대 승격을 명확히 나눈다.

## 예약18창의 한계와 사용 조건

- 실제 예측 미사용 기록을 새로 확인하고 후보/설정/평가 중심을 먼저 동결해야 한다.
- 2route·6segment·18개의2초창으로 A/D/C 각6이며 STOP 없음. 각route에 범주3창씩이다. 18창을 10Hz로 펼친 행을 독립 표본으로 세면 안 된다. 중심18개/창별 집계와 dense 보조 지표를 구분한다.
- 학습 모델 DIS는 장시간 문맥을 쓰는데 선정 창의 센서 강한 범주 조건은2초 기준이다. 주변 영상 문맥이 존재하는지 확인은 필요하나 후보 예측에 맞춰 정답/창을 제거하면 안 된다.
- RAV4는 야간·고속, Civic은 주간·저속이다. 원천별 성능은 보고할 수 있지만 순수 차량 효과로 해석 불가. 기존 두 차량의 새 경로이므로 새 차량/공식 점수 일반화 주장 불가.
- 이미 개발 평가 gate에서 실패하면 예약 자료를 굳이 소비해 후보를 구조할 필요가 없다. 사용해도 그 결과로 후보/설정 변경 금지.

## 구체 후보 반박 — 가감속만 좌우반전 학습 증강

주 에이전트가 제시한 후보: 동일2395시각·fold·정답·기존scaler·C·조향, 원본0.5/수평반전0.5 학습, 추론 원본만. 기존 영상을 실제 반전한 뒤 같은 DIS864 추출. 결과를 보기 전에 아래 의견을 전달했다.

### 중복 여부와 실행 허용 범위

검색한 `artifacts/stage3*` 보고서/코드에서 **학습 수평반전** 대조는 발견하지 못했다. DA3 프레임 시간순서 뒤집기는 다른 작업이다. 전체 원격 history까지 부재를 입증한 것은 아니다. ROI 제거/가림은 정보 삭제였고 좌우반전은 공간 배치를 바꾸면서 가감속 라벨을 유지한다는 점에서 핵심 가정이 다르다. 한 설정·한 번의 실제 분류 대조 자체에 반대하지 않는다. 이 판단은 성공 예측이나 채택 지지가 아니다.

### 약한 근거와 반례

- 지금까지 확인된 것은 원천 간 성능 차이와 영역 민감도다. **좌우 위치 의존이 그 오류의 원인이라는 인과 증거는 없다.** 깊이/원근/회전에 의한 등속과 가감속의 혼동은 그대로 남는다.
- 입력 반전은 가감속 물리량의 부호를 바꾸지 않지만 좌·우측 통행 장면, 카메라 비대칭, 본넷 모양, 왜곡 위치도 뒤집는다. 원본 분포와 반전 분포의 차이를 모델이 해결해야 하는 추가 문제도 생긴다.
- 독립 학습 시각과 새 원천 수는 늘지 않는다. 증강 후 행 수가 두 배라도 독립 자료 수 증가라고 보고하면 안 된다.
- 기존 scaler를 고정하면 반전 특징이 원본 통계에서 멀어지는 효과와 규제 효과가 동반될 수 있다. 결과가 좋아도 공간 불변성 한 요인의 인과 증명으로 주장하면 안 된다.
- 단순 캐시 대수변환은 DIS 비등변성·픽셀 경계·통계 순서에 의해 실제 영상 반전과 같지 않을 수 있다. 실제 프레임 반전 재추출 계획은 이 오류를 피한다.

### 평가 전 필수 고정

- 공개 held-out 영상과 외부 held-out 원천의 **반전본도 학습 제외**. 원본-반전은 반드시 같은 source ID/fold.
- sample_weight 원본0.5/flip0.5, 전체·범주별 총손실량 보존 확인. class_weight 계산에서 클래스 수가 정확히 두 배이므로 balanced 계수는 같아야 한다.
- 조향에 좌우반전 가감속 학습을 적용하지 않는다. 조향 모델/평가 결과 고정.
- feasibility는 featureshape/finite/정렬/예산과 최소학습 실행 가능성 검사로 제한. flip 일관성이나 점 수 같은 중간 수치를 추가 최적화 목표로 삼지 않는다.
- 기존 공개/날짜/ZOD paired 기준과 실제 정답 복구/새 반전 출력. 고정 gate 실패하면 예약18창을 이용해 실패를 구제하거나 비중/TTA/대칭 특징을 추가하지 않는다.

**결론:** 성능 향상의 직접 근거는 약하지만, 미실행인 좁은 가정·원본 정보 보존·저비용 실제 분류 대조가 가능하다는 이유로 한 번의 제한 실험은 수용 가능하다. 결과가 실패하면 이번 작업의 연구 후보는 미확보로 종료하고, 이를 다음 증강 탐색의 자동 허가로 바꾸지 않는다.

### 사전 검색 범위 오류 정정 — 과거 mirror 실험 발견

주 에이전트가 `research/train_stage3.py`와 `research/stage3_validation_public_mirror.json`을 발견했고 반박 담당도 원문을 확인했다. 앞 절의 'artifacts 검색에서 미발견'은 검색 범위가 좁아 과거 시도를 놓친 것이며, **학습 수평반전은 기존 시도다.** 이 후보를 새 기법 또는 미실행 기법이라고 설명하면 안 된다.

과거 구현은 `mirror_features()`로864특징의 좌우 ROI 및 수평광류 통계를 대수 변환한 뒤 원본과 이어 붙였고, scaler도 증강 자료에 재적합했다. 별도 sample_weight 없이 fit하므로 행/총손실량이 두 배였다. 공개-only LOVO에서 선형 가감속F1 .539394→.590219, ExtraTrees .636659→.674431, RF .609470→.653501의 부분 이득이 있었지만 모델 선택 역시 같은5영상에서 했고 외부2395 환경의 효과는 이 결과로 입증되지 않는다.

수정된 판정: 이번 후보는 **과거 부분 효과를 현재 학습 자료에서, scaler 및 총손실량을 고정하고 실제 영상 반전으로 재검증하는 제한 대조**다. 과거 효과는 시도할 최소 경험 근거이지만 좌우 불변성이 유일 원인이라는 증거가 아니다. 과거와 달라지는 통제를 명시하면 완전 중복으로 기각하지 않는다. 한 설정 종료·중간지표 연장 금지·실제 성능/반전 gate 유지라는 조건은 동일하다.
