# 반박 담당 최종 결과 감사

저장된 `predictions.csv`에서 sklearn F1와 혼동행렬을 독립 재계산했다. 기존 평가 함수를 호출하지 않았다. 학습/추론/새 실험은 수행하지 않았다. 새 파일 `audit.json`과 본 문서만 작성했다.

## 검사 결과

- 공개 S3·범주별F1·각 날짜/ZOD F1·원천별 혼동행렬 및 F1: 저장 결과와 일치.
- 새 반전, 반전→정답, 반전→등속 오답, 전체 오답→정답 및 정답→오답: 저장 결과와 일치.
- scope/id/sample_index 평가 키 중복 없음. 날짜 분할 간 반복 시각은 있을 수 있으므로 독립 표본 합계로 취급하지 않는다.
- 동결 각 학습 selection의 원천ID와 해당 평가 원천ID 교집합 없음. 원본/반전은 같은 selection을 사용한다. 이것은 원천 ID 기준 검사이며 지리적 원천 중복 전체의 부재를 증명하지는 않는다.
- 동결 입력 SHA 전부 유지, 운영 c52 모델 SHA 유지, 학습9회 유지.
- 직렬화 수정 전후 예측 CSV SHA 동일. `evaluate_fixed.py`는 NumPy scalar의 JSON 변환만 보완하며 공식 지표/gate를 바꾸지 않았다. 재학습0.
- 예약18창 예측 사용 없음.
- 원본 영상은 size/mtime로 보호한다. 이는 전체 영상 내용 SHA 검증과 다르며, 이번 요청에서 전체 재해시는 필요하지 않았다.

## 판정 반박

- 공개 반전2→1은 정답복구가 아니다. 사라진 반전1개는 CONSTANT 오답이 됐고, 전체 공개 정답은 복구1개보다 훼손4개가 많다.
- 날짜1은 실제 F1·정답 복구 이득이 있으므로 '아무 효과 없음'이라고 하면 부정확하다. 그러나 새 반전53개와 날짜3 악화로 고정한 채택 조건을 통과하지 못했다.
- ZOD는 MacroF1이 올랐지만 등속 F1이 .088167→0, 총정답이58→54다. 가속·감속 F1 개선과 등속 전멸의 교환이며 일괄 개선이 아니다.
- 과거 public-only mirror 이득은 현재 데이터·분류기 조건에서 공개 성능 향상으로 재현되지 않았다. 이것이 모든 반전 증강의 불가능성을 뜻하지는 않지만, 이번 설정의 재탐색을 정당화하지도 않는다.

**결론: 사전 고정 공개상승·날짜비악화·새반전0의 세 gate가 모두 실패했다. 후보 폐기·예약자료 미사용·운영 유지가 맞다.** 후속 증강비율이나 TTA 탐색을 자동으로 이어가지 않는다.
