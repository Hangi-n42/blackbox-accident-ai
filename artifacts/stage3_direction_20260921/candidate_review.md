# Stage3 candidate feasibility review — 2026-09-21

AI 검토 에이전트의 기존 문서·코드 검토. 새 학습/추론/다운로드 없음. 최대 2개라는 상한을 채우려고 근거 약한 두 번째 후보를 추가하지 않았다.

## 결론: 한 후보만 제한 대조할 근거가 있다

**가감속 학습에서 실제 영상 수평반전 1:1 증강, 원래 scaler·손실 총량·분류기·평가·조향 고정.** 새로운 성공 방법이라는 주장이 아니라, 과거 부분 이득의 교란을 제거하고 현재 연구 기준에서 재검증하는 후보다. root가 제안한 후보를 독립적으로 과거 구현과 대조했다.

### 고칠 오류와 근거

고정 좌우 ROI의 장면 배치에 가감속 판정이 과도하게 의존하는 부분을 줄이는 것이 목표다. 영상의 좌우 반전은 같은 프레임 시각의 전진 가속/감속/등속/정지 상태를 바꾸지 않는다. 조향은 반전되는 별도 과제이므로 이번에는 조향 학습·출력을 원본 기준으로 고정한다.

관찰 근거는 두 종류다.

1. 기존 fixed ROI 표현은 차량/원천을 바꾸면 성능이 크게 달라졌다. 이 사실만으로 좌우 비대칭이 유일한 원인이라는 주장은 하지 않는다.
2. **수평반전은 완전히 새 아이디어가 아니다.** `research/train_stage3.py:35`의 `mirror_features`, `--mirror`가 이미 있다. 같은 public-only LOVO의 `research/stage3_validation_public.json`과 `_public_mirror.json`에서 가감속 F1은 linear **0.539394→0.590219**, ExtraTrees **0.636659→0.674431**, RandomForest **0.609470→0.653501**이었다. 현재 .808951 S3와 비교할 숫자가 아니다. 과거 공개 반복 노출 결과이며 손실량·scaler가 함께 변했으므로 순수 반전 효과로 확정할 수 없다.

### 과거 실패와 달라지는 가정

- ROI 가림 증강은 영상 정보를 삭제하고 표준화 평균으로 치환했다. 이번 후보는 전체 시공간 운동을 보존하고 좌우 위치만 반사한다. `stage3_roi_augmentation_20260920`의 실패를 비중만 바꿔 반복하는 것은 아니다.
- 광류 scale 증강(`research/stage3_scale_augmentation/decision.json`)은 기존 외부17개 조건에서 공개 이득이 없었고 복제 대조와 출력이 같았다. 이번 반전은 크기 확장이 아닌 spatial permutation/sign transformation이다.
- 과거 mirror 구현은 특징 대수 변환 후 표본을 단순 두 배로 늘리고 scaler도 재적합했다. 실제 영상의 반전과 ROI·고정 방사 중심의 이산 경계가 완전히 일치한다고 검증하지 않았다.
- 이번의 핵심 가정은 **정답을 보존하는 실제 영상 반사 제약이 현재 확대 학습 자료에서도 좌우 배치 의존을 줄이면서 원본 분류를 개선한다**이다. 과거 긍정 결과로부터 이 가정을 시험할 이유는 있으나 성공 보장은 없다.

### 실행 가능성과 변경 범위

현재 디코더/OpenCV DIS/NumPy/sklearn만으로 가능하다. 모델 다운로드, 새 패키지, 새 기하 추정은 필요 없다. 원본 특징과 기준 모델은 재사용하며 학습 원천의 flipped frame만 동일 DIS864 추출기로 재계산한다. 평가 입력은 원본이며 test-time flip/앙상블을 추가하지 않는다.

`FrameFeatureComputer`의 x 원점은 `w*.5`이고 ROI는 `int(fraction*w)`이다. 반사 좌표가 `w-1-x`이므로 기존 캐시의 ROI 역순·fx 부호/q20-q80 교환을 실제 반사 특징과 완전히 같은 것으로 취급하면 안 된다. 실제 영상 픽셀 반사로 구현하는 것이 명확하다. 모든 시간의 동일 반사이며 시간순서/센서/정답은 고정한다.

- 원본 scaler mean/scale 고정.
- 원본 한 행 가중치 .5, 대응 flip 한 행 .5. 클래스별 유효 손실량은 기준과 동일하게 검사.
- LogisticRegression C=.03/balanced/기존 solver·seed 유지. 조향 고정.
- 같은 outer train source 안에서만 증강. held source를 학습하지 않음.
- 공개 LOVO 5개 + 날짜 3개 + ZOD 진단용 전체 comma 1개 = 최대 9후보 fit. 기존 기준 재학습 불필요.
- 후보비율/seed/정규화/후처리 탐색 없음. feature mirror 대수근사와 실제영상flip을 후보2개로 경쟁시키지 않음.

### 폐기 조건

공개 개발 S3 개선, 클래스별 변화, 각 원천/날짜 F1 비악화, 사전 신규 반전 제한을 모두 root의 고정 contract로 평가한다. 정답 복구는 오답→정답만이며 A↔D에서 C오답으로 옮긴 것을 복구로 세지 않는다. 이전에 약속된 위험 제한을 더 느슨하게 만들지 않는다.

- 실행 검사가 실패하고 상한 내 바로 고칠 수 없는 경우 종료.
- 공개 S3 또는 정해진 외부/반전 gate 실패 시 설정 재탐색 없이 폐기.
- 공개 변화0·외부 일부만개선이면 채택 가능한 점수개선으로 주장하지 않음.
- 예약18창은 규칙/모델 고정 후 gate를 통과한 후보 한 개만 한 번 열고, 결과 기반 수정 금지.
- 실제 영상flip 정확성이 확보돼도 분류가 나쁘면 다음 좌표/ROI/비율 후보를 자동생성하지 않음.

## 제외한 대안

평활은 안정 구간 일부 이득이 있었지만 전환 gate를 실패했고 긴 등속 오인을 해결하지 못했다. 같은 설정을 확대 모델에 붙이는 것만으로 새 근거가 되지 않는다. 차량/원천 재가중치·편향 보정은 이미 frozen 대조와 내부 선택까지 실패했다. strict/usable 데이터의 50:50 확률 혼합, ordinal/hierarchical head, 추가 규제 탐색은 이번 검토에서 수치상 이득이나 오류 원인의 근거가 없어 권하지 않는다. 과거 unsafe 후보를 예약18창에 옮겨 위험 실패를 없애는 접근도 배제한다.

이번에는 **후보 수 1개**다. 최종 선택·위험 contract·실험은 root 담당이며 본 검토에서 실행하지 않았다.
