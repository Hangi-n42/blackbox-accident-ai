# Stage3 개선 실험 결과 — 2026-09-19

**공개 정답의 점수 개선은 확인했지만, 반전 오류와 날짜별 성능을 함께 통과한 후보는 없다. 운영 모델을 유지한다.**

가장 큰 공개 점수 이득은 새 모델이 아니라, 기존에 확보·검수한 자료의 학습 범위를 넓혔을 때 나왔다. DIS864와 선형 분류기를 유지하고 외부 1,083개 엄격 표본을 2,395개 사용 가능 후보 표본으로 확대하면 공개 S3가 **0.749301 → 0.808951 (+0.059650)**이다. 그러나 첫 날짜 진단의 반전은 **140 → 278**, 공개 반전은 **1 → 2**로 증가한다. 안정적인 개선/제출 채택으로 선언하지 않는다.

## 실제 수행 범위와 점수의 의미

- 공식 공개 5영상 50시각을 영상별 leave-one-out으로 평가했다. 각 학습에는 다른 공개 4영상의 40정답만 포함한다.
- 외부 comma 기존 23개만 사용했다. 기존 날짜 분할 3개의 평가 수는 1,612 / 1,167 / 561시각이다. 센서 기반 대체 정답이며 분할 사이 날짜가 반복돼 합산 독립 표본으로 볼 수 없다.
- 공식 식은 `S3 = .7 × 가감속 Macro-F1(4종) + .3 × 조향 Macro-F1(3종)`이다. GT STOPPED를 제외한 47시각의 조향 OOF를 모든 후보에서 동일하게 고정했다. 조향 F1는 0.850304다. [공식 평가 안내](https://dacon.io/competitions/official/236753/overview/evaluation), [공식 정답 정의 안내](https://dacon.io/competitions/official/236753/talkboard/417186).
- 따라서 아래 S3는 고정 조향과 새 가감속을 조합한 **개발 OOF 진단**이다. 새 제출 전체 실행 점수, 대회 종합 점수, private 점수 또는 독립 검증 결과가 아니다.
- 이미 여러 번 개발에 사용한 공개·외부 자료다. 정답을 예측에 맞춰 바꾸지 않았다. 회귀에 쓰는 센서도 학습 목표로만 사용하며 추론 입력은 영상뿐이다.

## 2. 실패 원인 점검과 내부 경로 조기종료 대조

확인한 사실:

1. DIS 신경망은 모든 학습 분할에서 가감속 F1=1.0이다. V-JEPA 신경망도 학습 F1 0.999097–1.0이다. 학습에 맞추는 능력은 충분하지만 외부 날짜로 일반화되지 않았다.
2. 가속도 보조회귀는 외부 날짜에서 단순 학습 평균 예측보다 MAE가 높았다. 아래는 경로·초기값별 MAE의 평균이다. 공식 종가속도 오차가 아니라 기존 센서 기울기 대체 신호 오차다.

| 회귀 방법 | 날짜1 MAE | 날짜2 MAE | 날짜3 MAE |
|---|---:|---:|---:|
| 학습 센서 평균 상수 | 0.4491 | 0.2019 | 0.2358 |
| DIS 보조회귀 | 0.5105 | 0.3831 | 0.4073 |
| V-JEPA 보조회귀 | 0.5026 | 0.3085 | 0.3059 |

3. 이 과적합 양상을 보고, **학습 원천 내부만** 나눠 epoch를 선택하는 추가 대조를 결과 확인 전에 별도 동결했다. 이후 전체 학습 자료로 다시 학습했다. 외부 평가/held-out 공개 정답으로 종료 시점을 고르지 않았다.
4. 내부 조기종료의 공개 평균 S3는 DIS 분류 0.646977 / 보조회귀 0.633342, V-JEPA 분류 0.672581 / 보조회귀 0.671908로 더 낮았다. 조기종료 하나로 해결되지 않았다. 내부 원천의 선택과 실제 목표 분포가 다를 수 있다는 한계가 남지만, 이를 유일한 원인으로 입증한 것은 아니다.

구체적 새 반전: DIS 보조회귀에서 `OPEN_005` sample180의 ACCELERATING이 모든 초기값에서 DECELERATING이 됐다. 선형 기준은 CONSTANT였다. `OPEN_003` sample60은 seed17/73에서 올바른 DECELERATING에서 ACCELERATING으로 바뀌었다. 상세 확률은 `dis_predictions.csv`와 변경 목록에 있다.

## 3. 학습 표본 범위만 바꾼 추가 대조

이 실험은 앞선 결과를 본 뒤, 실행 전에 `coverage_control/freeze.json`을 고정했다. 최초부터 독립적으로 계획된 테스트처럼 표시하지 않는다. 특징·선형 모델·C·평가 자료는 동일하다. 기존 정제 주석의 `label>=0` 시각 중 2Hz만 사용해, 분류 불명확·결측은 계속 제외했다. 새 라벨이나 임계값은 만들지 않았다.

| 학습 범위 | 공개 S3 | 공개 반전 | 날짜1 F1 / 반전 | 날짜2 F1 / 반전 | 날짜3 F1 / 반전 |
|---|---:|---:|---:|---:|---:|
| 기존 엄격 범위 기준 | 0.749301 | 1 | 0.631240 / 140 | 0.576443 / 25 | 0.268540 / 12 |
| 기존 엄격 표본 전부 | 0.749301 | 1 | 0.639266 / 133 | 0.547331 / 32 | 0.265925 / 11 |
| 검수된 사용 가능 후보까지 확대 | **0.808951** | **2** | **0.607414 / 278** | 0.484176 / 39 | 0.302424 / 16 |
| 위 확대 + 총 학습 손실량 맞춤 | 0.800063 | 2 | 0.629021 / 217 | 0.472428 / 43 | 0.294140 / 3 |

공개 평가용 외부 학습은 1,083→2,395시각이며 각 fold에 공개 40시각을 동일하게 추가한다. 기존 날짜 기준은385개이고, 엄격 전부는765/851/972개, 확대는1,661/1,960/1,986개다. 표본 수 증가에 따른 실질 규제 강도 변화를 분리하기 위해 확대 학습에서 총 표본 가중치를 기존 학습량과 맞춘 대조도 실행했다. 이 대조에서도 공개 S3 +0.050762가 남았다.

공개 예측에서는 `OPEN_005` sample60/120의 가속을 복구했지만, sample180과 `OPEN_003` sample180에 새 가속→감속 반전을 만들었다. 날짜1의 278반전 중 **Civic275 / RAV4 3**이다. 새 반전은 `comma_02` 76개, `extra_01` 44개, `expanded_14` 41개 등에 집중됐다. 이것은 서로 독립적인 사고 76건이라는 뜻이 아니라 연속 시각의 수다.

**해석:** 이번 자료에서는 강한 가감속·안정 구간만 고르는 기준이 공개 성능에 충분하지 않았다. 다만 범위 확대의 이득은 개발에 노출된 공개50개에서 확인된 것이며, 다른 날짜·차량에 안전하게 이전되지 않았다. 데이터 범위를 넓히기만 하면 해결된다는 결론도 지지되지 않는다.

## 4. 운영 기준과의 관계

과거 운영 학습은 외부 2,761시각과 공개 정답을 사용했고, 선택 당시 OOF S3는0.798298이었다. 이번 엄격 기준 0.749301과는 학습 범주/표본 및 캐시 조건이 다르다. 0.808951이 역사값보다 높다는 사실만으로 현재 운영 모델을 넘었다고 선언하지 않는다.

현재 운영 모델은 `accel` LogisticRegression과 `steer` RandomForest다. CAN transfer 회귀는 과거 실험이었으며 현재 운영 체크포인트에 들어 있지 않다. 원본 모델 SHA256 `c52ecd15cf68856f2a7b0b37b120c7a961b3bd8889a33af4ec47f8b9719bb3b3`를 마지막까지 보존했다. 조향 모델/Stage1/Stage2/제출 파일은 수정하지 않았다.

## 5. 실행·호환성·제한

- 기존 DIS 캐시 재사용. 실제 Mac 진입점에서 공개 1영상을 다시 추출해 캐시와 bit-exact 일치, 600프레임 약2.20초.
- 공식 V-JEPA EMA 체크포인트 strict load, encoder86,833,152파라미터 동결. 실제16프레임 CPU/MPS 상대 L2차이1.90e−6, 평균 절대차이1.34e−6. 특징 수치 비교이며 전체 모델의 수치 동등성 보장은 아니다.
- V-JEPA 28영상, 총16,785프레임 처리 완료. 특징 추출 총627.03초, 영상별 중앙값21.72초. 같은 `OPEN_001`은20.44초로 DIS 표본보다 약9.3배 길었다. 단일 실행·동시 작업의 영향이 있으며 L40S 제출 처리량은 검증하지 않았다.
- 초기 timestep은10Hz16프레임/1.6초, 공간 평균, 중앙 crop이다. 시간 토큰은 보존하지만 원래 공간 토큰 배치는 보존하지 않는다. 이 설정의 실패를 V-JEPA 전체 연구나 다른 시간창/공간 헤드의 불가능성으로 확대하지 않는다.
- 공식 dense 전환 정답이 없다. strict proxy에서 빠진 경계는 전환 지연 정확도를 확정할 수 없다. 전환을 개선했다고 주장하지 않는다.
- 경고는 공식 라이브러리의 deprecated API 안내였다. 실행/학습/평가/추가 대조는 exit0. 패키지는 별도 vendor에 설치했고 기존 환경을 업그레이드하지 않았다.
- 이번 분류·회귀 결과만으로 깊이/카메라 자세가 실패의 단독 원인이라는 추가 증거는 없다. 조건부 DA3/CoTracker/LFG 확장은 실행하지 않았다.

## 판정과 다음 우선순위

**부분적인 공개 점수 개선 확인, 안정적인 일반화 개선 미확인, 운영 교체 미채택.**

다음 실험은 새 encoder 추가보다, 이번에 이득이 확인된 기존2,395시각의 **차량·원천별 학습 비중**을 분리하는 것이 우선이다. 특징과 선형 모델을 고정하고, Civic에서 늘어난 반전을 줄이면서 공개 이득이 유지되는지 확인해야 한다. 가중치 선택은 외부 평가가 아니라 학습 내부의 여러 원천을 사용해야 한다. 단일 내부 경로 조기종료가 이미 실패했으므로 같은 방법을 그대로 반복하지 않는다. 효과는 아직 검증하지 않았으며, 후보 가중치를 공개50개에 반복 맞춰 채택해서는 안 된다.
