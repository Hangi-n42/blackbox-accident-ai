# Stage3 추적기 대조와 팽창 중심 안정성 분리 검증 — 2026-09-20

**두 실험 완료. DIS로 점을 연결하는 방식은 이번10구간에서 기존 실패를 복구하지 못했고, 팽창 중심 오차에 민감한 특징 구조가 별도로 확인됐다. 미채택, 모델 학습·운영 변경 없음.**

## 범위와 비교 조건

기존28창 중 사전에10창 선정: 실패5개(야간/주간 추적 부족, 중심 실패, 반창 중심 차이, 좌우 지지 부족)와 통과5개(A/D/C 및 검증 D/C). 이전에 확인한 개발 사례의 원인 진단이며 독립 평가 또는 대표성 있는 전체 자료 성능 비교가 아니다.

21프레임/2초,640px 폭 회색조, 원본 정렬시각, 시작 코너500개 이하, 수동 정적영역, 기존 기하/시간 특징/품질조건 고정. 센서는 결과 비교용으로만 사용하고 추적·중심 적합에 넣지 않았다. 회전 보정이나 분류기 변경은 수행하지 않았다. 원본 데이터 라이선스는 이전 comma.ai2018 MIT를 보존했다.

### 실험A — 추적 방식만 대조

- 기준: OpenCV pyramidal LK.
- 후보: 설치된 OpenCV4.10.0 DIS_FAST의 전후방 밀집광류에서 같은 점의 이동벡터를 보간해 프레임마다 이어 붙임. learned point tracker가 아니며 새 모델 다운로드 없음.
- 양쪽 동일 전후방오차≤1px, 같은21×21 패치의 보간 평균절대밝기오차≤20, 같은 영역/영상 범위 검사. LK 내부 상태검사는 유지하고 DIS는 유한값 여부 확인. 정의가 다른 LK 내부 err를 DIS에 그대로 복사하지 않았다.
- 기존 LK 내부 err 기준은 legacy 재현 대조로 별도 남겼다. 이번10창에서 common gate LK와 legacy의 생존점 수·결과는 일치했고, 이전 저장궤적이 있는 창은 좌표까지 정확 일치했다.
- 양쪽 모두 생존한 **같은 시작점만** 다시 골라 두 추적좌표를 비교하는 intersection 대조도 수행했다. 추적점 구성의 변화와 좌표 변화 영향을 구분하는 보조 대조다.

공식 API: https://docs.opencv.org/4.10.0/javadoc/org/opencv/video/DISOpticalFlow.html . DIS_FAST 기본값(finestScale2, patchSize8, stride4, gradientIterations16, refinementIterations5)을 저장했다. 초기 freeze의4.x 링크는 웹 도구에서 열리지 않아 동작하는4.10.0 공식 참조를 runtime_parameters.json에 추가했다. 설정은 변경하지 않았다.

### 실험B — 기존 궤적을 고정한 중심 검사

원래 legacy LK 궤적만 사용했다. DIS 결과와 결합하지 않았다.

1. 동일 점집합에서50회 재표집하여 팽창 중심 변동 측정(seed20260920).
2. 좌/우/위/아래 점 부분집합에서 중심을 따로 추정.
3. 선형 제약 행렬의 조건수, 기존 앞/뒤 절반 중심 차이를 함께 기록.
4. 기존 중심을 x/y 방향으로 각각±2/5/10px 이동시킨 뒤, **기존에 채택한 같은 점들**에서 u''/u'만 재계산. 새 점을 선택하거나 궤적을 다시 추적하지 않음.

재표집 산포는 중심의 실제 오차 또는 신뢰구간이 아니다. 점끼리도 공간적으로 연관돼 있다. 중심 위치 이동은 민감도 검사이며 실제 카메라 자세 보정이 아니다.

중심 재표집이 상대적으로 작아도 실제 센서와의 오차는 클 수 있다. 예를 들어 expanded_11 22.5초는 원래 기하 검사에 통과하지만 특징+.007287, 센서 a/v+.146363이다. 중심±5px의 작은 변동만으로 이 큰 차이가 전부 설명되지 않는다. 단안 모델 가정, 움직임/정적점 분리, 시간/영상 오차 등이 여전히 가능하며 하나의 원인으로 확정하지 않았다.

## 이번에 구분된 사실

1. **추적기만 바꾸는 것으로 이번 실패는 해결되지 않았다.** 일부 점 수·부분집합 MAE 개선과 전체 통과율 감소가 함께 발생했다.
2. **팽창 중심 오차에 대한 특징 민감성이 별도로 존재한다.** 궤적과 점을 고정해도 몇 픽셀 중심 변화로 약한 특징의 부호가 바뀐다.
3. **생존점 수가 많거나 기하 검사에 통과했다고 센서 상태를 정확히 반영하는 것은 아니다.** 영상 검수에서는 일부 영역에 하늘/구름/유리 반사도 남아 정적배경 가정이 불완전했다. 결과를 보고 영역을 변경하지 않았다.
4. **정확한 원인 비율은 확인 불가다.** 추적 정답·카메라 pose 정답이 없으므로 광류 오차, 회전, 정적점 오염을 수치로 완전히 분해하지 못했다. CoTracker 등 다른 추적기 전체를 평가한 것도 아니다.

## 판정과 후속 방향

DIS 연결 방식을 미채택한다. 특징을 분류기에 추가하지 않고, 이번 작은 개발 진단을 공식 점수 측정으로 부르지 않는다. 기존28창을 다시 평가한 것이 아니므로5/10→4/10을 이전6/28과 같은 분모처럼 비교하지 않는다.

추가한다면 추적기 이름을 계속 바꾸기보다, **단일 추정 중심의 역반경2차 미분을 사용할 때의 민감성을 낮추는 방법**과 **진짜 정적배경의 지지 확보**가 우선 검증 대상이다. 중심의 참값 근거 없이 영상을 보고 수동 조정하거나 센서 정답에 맞춘 중심을 쓰면 효과를 과장하게 된다. 회전 보정은 별도 근거/대조 없이 추가하지 않는다. 이번에는 후속 특징 개발까지 수행하지 않았다.
