# 첫 프레임 시각 상태 참조 A

새 legend/probe 출력 열람 전에 원본 f0, 실제 384×256 첫 타일, 기존 marked 입력 시트를 세 사례마다 직접 view_image로 다시 확인했다. 입력·표식·기존 라벨은 수정하지 않았다.

| 사례 | 상태 | 직접 보이는 근거 | 한계 |
|---|---|---|---|
| CCD_000688 | INSIDE | 같은 해치백이 자차 바로 전방 진행 통로를 차지하며 우측 통로 가장자리 연석·눈이 보임 | 도색 차선 없는 주차장 접근 통로 기준. 정밀한 차로 경계나 법정 차로 수는 확인 불가. 바퀴 접지부 전체는 가림. |
| CCD_000801 | INSIDE | 흰 더블캡이 왼쪽 점선의 보이는 연장과 오른쪽 도로 가장자리 사이 전방에 위치 | 교차로 접근부의 선 일부는 가림·소실. 작은 타일에서 세부 판독 제한. |
| CCD_000196 | INSIDE | 은색 세단이 왼쪽 차선 선과 오른쪽 갓길·가드레일 사이 전방에 위치 | 원거리 차량이 작고 압축돼 바퀴 픽셀 정밀 판독 제한. |

첫 타일의 노란 표식은 각 상대 상단에 보인다. 보이는 제목은 frame 0이며 상태 정답을 적은 캡션은 없다. 이 검수에서 확대·재렌더링은 하지 않았다. 현재 위치 상태 참조이며 최초 물리적 진입 시점이나 새 모델 응답을 판정하지 않는다.

이 검수자는 이전 marker 실험 숫자 결과와 기존 f0 GT를 이미 알고 있다. 따라서 model_predictions_seen:false는 **새 legend/probe 출력 미열람** 범위이며 완전히 새롭고 과거 정보에 노출되지 않은 리뷰어라는 뜻이 아니다. AI 시각 참조이며 인간 검수·정밀 분할 정답을 대체하지 않는다.
