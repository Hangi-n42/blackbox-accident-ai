# Stage3 ZOD 혼합 실패 원인 분리 대조 — 2026-09-20

**요청한 두 대조를 순서대로 완료했다. scaler 고정과 손실 배분 조정으로 일부 회복했으나, 기존 comma 기준보다 공개 개발 S3가 낮고 날짜별 손익도 일관되지 않는다. 두 후보 모두 운영에 채택하지 않았다.**

## 1. 평가 전 고정한 규칙

기존 comma2,395시각·ZOD637시각, 공개 LOVO의 기존40개 학습 정답, 각 날짜 분할, 모든 라벨과 DIS864 캐시를 그대로 사용했다. 새 다운로드·영상 디코딩·특징 추출은 없다. 기존 comma와 기존 혼합 모델/확률을 재사용했다. 조향 예측도 그대로다.

1. **scaler만 고정:** 각 평가 분할의 comma 기준 StandardScaler를 그대로 복사하고, 같은 혼합 행·balanced 가중치·분류기 설정으로 classifier만 학습했다. mixed scaler 재학습만 제거한 대조다.
2. **손실 배분 고정:** ①과 동일 scaler·같은 행을 사용한다. 기존 balanced 유효 가중치 `w_k=N0/(4*n0_k)`를 기준으로, 각 범주의 comma 손실 질량 중 20%를 해당 ZOD 범주에 균등 배분하고 comma에80%를 남긴다. 공개 학습 정답의 유효 가중치는 그대로 유지한다. ZOD에 없는 STOPPED는 기존 손실100%를 유지한다. 따라서 각 범주 총량은 `N0/4`, 전체는 `N0`다. 20%는 freeze.json에 평가 전 고정했으며 탐색하지 않았다.

여기서 N0는 해당 분할의 기존 학습 행 수다. 공개 LOVO에는 기존 정책대로 comma와 공식40정답을 포함한다. 분류기 설정 `C=.03, class_weight=balanced, max_iter=2000, random_state=42`를 유지하기 위해 sklearn1.5.2가 곱하는 balanced 계수를 sample_weight에서 역보정했다. 실제 유효 손실 총량·공개 가중치·scaler 배열 일치를 검사했다.

**20% 배분은 ZOD 전체를 일괄 약화하는 처리가 아니다.** 새 ZOD 평가용 모델에서 ZOD A/D/C 유효 손실 질량은 기존 혼합99.925/45.451/236.077에서119.750/119.750/119.750으로 바뀐다. 등속은 줄이고 가속·감속의 비중은 늘린다. 각 범주의 전체 손실은758.000에서 comma 기준598.750으로 복원된다. 따라서 ②는 총 손실 질량과 범주 안 원천 배분을 함께 바꾼 대조이며, 이 둘의 인과 기여를 각각 분리한 실험은 아니다.

## 5. 확인한 원인과 확인하지 못한 원인

- **scaler 재추정은 일부 악화에 기여했다.** 혼합 행·분류기·가중치를 그대로 두고 scaler만 복원했을 때 공개 S3가0.008383 회복됐다. 그러나 원래 gap을 해소하지 못하고 ZOD 가감속 정답도8개로 그대로다. scaler가 주된/유일한 실패 원인이라고 결론낼 근거는 없다.
- **손실 질량과 원천별 범주 배분도 성능에 영향을 준다.** 같은 scaler에서②는 공개 S3를 추가0.006140 회복하고 날짜1·2는 comma 기준보다 높아졌다. ZOD 가감속 정답도14개 회복됐다. 반면 날짜3 F1은 더 낮아지고 ZOD 등속과 가감속 간 손익 교환이 생겼다.
- 두 처리를 적용해도 공개 S3는 comma 기준보다0.028257 낮다. **혼합 실패는 scaler와 이 한 번의 가중치 통제로 해결되지 않았다.**
- 총 손실 질량 변화와 ZOD 비중 변화는②에서 동시에 바뀌었다. 따라서 어느 쪽이 얼마나 기여했는지는 확인 불가다. 카메라/FOV·도로/장면 분포·DIS 표현의 한계·proxy 정답 차이가 남은 원인 후보이지만 이번 대조는 이들을 직접 분리하지 않았다. 특정 후보를 확정 원인으로 쓰지 않는다.

## 6. 다음 진행 여부

**운영 채택과 ZOD 혼합 확대는 진행하지 않는다.** 두 후보는 실험 폴더에만 보관했다. 같은 개발 점수로20%를 조절하는 가중치 탐색도 하지 않았다. 다음 단계는 남은 공개3오답과 ZOD 가감속 실패에서 원천별 특징/정답 정합성을 검토하는 진단이다. 이 대조 결과만으로 새 모델·새 특징·추가 다운로드를 정당화할 수는 없다. 이번 요청 범위 이후의 새 실험은 실행하지 않았다.

모든 기존 ZOD 평가 영상은 **개발 진단용**이다. 결과가 좋은 날짜가 있더라도 독립 성능 개선·일반화 입증·채택 완료를 뜻하지 않는다.
