# Stage3 추적기·팽창 중심 실험 결론 및 다음 순서

작성: 2026-09-20. 평가·비전·데이터 전문가 3명이 독립 검토했고, 평가·비전 권고는 교차 검토했다. 이번 작업은 결과 분석이며 새 학습·추론·다운로드·운영 코드 변경은 없다.

## 1. 확인된 결론

현재 단일 팽창 중심(FOE)과 역반경의 2차 시간 미분을 이용한 가감속 특징은 학습에 넣을 근거가 부족하다. 추가 추적기 교체, 수동 중심 보정, 품질 기준 완화는 우선 작업에서 보류한다.

- 선택된 실패 5창과 통과 5창에서 LK→DIS 교체 후 품질 통과 5/10→4/10. 실패 복구 0개, 기존 통과 1개 악화. 살아남은 점은 498→557개로 늘었으므로 점 수 증가가 특징 신뢰도 개선을 보장하지 않는다.
- expanded_19 27.5초에서 공통 시작점 114개만 비교해도 반창 FOE 차이가 12.563→40.851px로 악화했다. 추가된 점만 제거하면 해결되는 문제는 아니다.
- 궤적을 고정한 FOE ±5px 검사에서도 특징 부호가 달라진 사례가 있다. 이는 특징 민감도이며 분류기 가감속 반전이나 공식 점수 변화가 아니다.
- 품질 통과 expanded_11 22.5초에서도 특징 +0.007287/s와 센서 a/v +0.146363/s가 크게 다르다. 중심 안정화만으로 충분하다는 근거가 없다.
- 직전 28창의 유효 검증 표본은 가속 0·감속 2·등속 1개, 속도가 대응하는 유효 검증쌍은 0개다. 후속 10창은 의도 선정이므로 6/28과 5/10 또는 4/10을 전체 통과율 변화로 비교할 수 없다.
- 수동 배경 영역을 사용한다. 수식 정확성 시험은 통과했지만 자동 입력에서 작동하는 특징은 아직 확보하지 못했다.

영상의 추적 정답·카메라 pose 정답이 없으므로 추적 오차, 회전, 깊이 변화, 동적 물체, 동기화가 각각 얼마나 기여했는지는 확인 불가. 모든 광류나 모든 learned tracker의 실패로 일반화하지 않는다.

실험 실행·감사 exit status 모두 0, 운영 파일 및 입력 보존 확인. 이번 두 기하 진단은 분류기를 학습·평가하지 않았으므로 점수 개선은 측정하지 않았다.

## 2. 현재 점수와 과거 반증

비교 대상은 현재 확대 학습 개발 기준: 외부 2,395개 시각, DIS 864차원, 선형 분류기. 공개 5영상/50행의 영상별 제외 평가 S3=0.8089509346, 가감속 Macro F1=0.7912280702, 고정 조향 Macro F1=0.8503042851. 이 결과는 반복 사용된 공개 개발 평가이며 독립/private 성능이 아니다. 운영 모델의 독립 평가 점수로도 바꿔 부르지 않는다.

대회 통합 문서의 S3=0.7×가감속 Macro F1+0.3×조향 Macro F1을 따른다. 반전은 별도 공식 벌점이 아니라 사용자 요구에 따른 위험 진단이다. 점수 상승과 반전 기준 미충족을 별개로 보고한다.

기존 RandomForest/ExtraTrees는 외부 2,761개·이전 특징 추출/라벨 조건에서 가감속 F1 0.723344/0.723110으로 선형 0.776009보다 낮았다. 최근 작은 시계열 MLP도 엄격 1,083개 조건에서 일반화에 실패했다. 따라서 비선형을 처음 시험한다거나 용량 부족이 입증됐다는 설명은 틀리다. 현재 2,395개·동일 DIS 조건의 제한된 boosting 대조는 검토한 기록에서 확인하지 못했다.

## 3. 권고 순서

### 1순위: 모델만 바꾸는 직접 점수 대조 한 번

가설: 기존 특징의 크기·시간 변화·영역 간 조건부 관계가 선형 결정경계보다 제한된 비선형 분류기에 적합한가. 확인된 원인이나 보장된 개선책이 아니라 저비용 단일 가설검사다.

고정: DIS864 캐시, 외부 2,395행, 공개 outer train40/held10, 라벨, 학습측 scaler, class-balanced 가중치와 원천 가중치, 공개 5개 영상 분할·외부 날짜 3개 분할, 조향. 공개 모델 학습과 외부-only 날짜 평가의 학습 범위를 혼동하지 않는다.

변경: LogisticRegression → HistGradientBoostingClassifier 한 설정. 설치 sklearn1.5.2에서 지원하며 신규 설치·영상 재추출 불필요.

사전 고정 제안값: max_leaf_nodes=7, max_depth=3, min_samples_leaf=30, max_iter=100, learning_rate=0.05, l2_regularization=1, early_stopping=False, class_weight=balanced, random_state=42. 검증된 최적값이 아닌 복잡도 제한용 시험값이다. seed·임계값·후처리·특징·정답을 동시에 바꾸거나 공개 평가 후 재탐색하지 않는다.

보고: 공개 S3·클래스별 F1·영상별 변화·학습/검증 차이, 외부 날짜/차량별 대체 정답 F1, 양방향 반전 수/비율, 새 반전과 정답 복구 및 연속 사건. 분모 없는 비율은 NA. 반전을 CONSTANT 오답으로 옮긴 것을 정답 복구로 세지 않는다.

판정: 공개 점수 상승 여부를 먼저 수치로 보고한다. 운영 후보 판정은 별도로 새 공개 반전, 외부 강한 반전/범주 손실을 검토한다. 공개만 개선하거나 외부 날짜 간 손실을 상쇄한 결과는 일반화 개선으로 선언하지 않는다. 이 단일 대조가 실패하면 같은 50개 정답에서 모델 이름·하이퍼파라미터 탐색을 확대하지 않는다.

### 2순위: 독립 원천의 가감속 판정 자료 보강

기존 23원천과 공개 50정답은 개발 노출 자료다. 기능 시험에는 충분하지만 새 특징의 일반화를 확정할 자료는 부족하다. 이미 보유한 자료에서 미노출 원천 확보 가능 여부부터 확인하고, 없으면 필요한 조건을 보고한다.

기능 확인용 최소 제안: 미사용 연속 주행 2경로에서 각각 같은 속도대의 가속·감속·등속 3개씩, 총 18개 비중첩창. 동기화 센서와 보이는 정적 배경이 필요하다. 교차 차량 주장을 하려면 차량도 분리한다. 18개는 통계적 충분성이 검증된 표본수가 아니며, 대회 공식 정답을 대체하지 않는다. 결과를 보고 쉬운 창만 선정하지 않는다.

### 3순위: 새 특징은 공동 카메라 궤적 후보 한 개로 제한

조건부 후보: 동결 DA3-Small의 같은 창 공동 pose로 camera center 궤적을 얻고 상대속도 변화 q=(v·a)/(v·v)를 만든다. 단일 FOE·장기 코너 생존을 직접 요구하지 않는 장점은 있으나, Stage3 가감속 성능이 입증된 모델은 아니다.

먼저 Mac 소규모 실행, 창 내부 scale 일관성, 입력 순서/참조점 변경 안정성, 등속 가짜 가감속과 A/D 가용성을 한 번 검사한다. 서로 독립 scale인 창을 이어 미분하지 않고, 센서 속도로 추론 특징을 보정하지 않는다. STOPPED 및 분모가 작은 구간은 별도 처리 필요. Mac 지원과 실제 추론 비용은 아직 미확인이다.

통과할 때만 원래 선형 분류기에 특징 블록 하나를 추가하는 대조로 이동한다. HGB+새 특징을 한꺼번에 적용하지 않는다. 실패하면 크기·보정값 탐색으로 연장하지 않는다. 성공한 창만 뽑아 평가하지 않고 기존 평가 행 전체에서 결측·fallback까지 포함해 보고한다.

## 4. 전문가 의견 차이와 종합 판단

세 전문가는 현재 FOE 역반경 특징의 확대를 보류하는 데 동의했다. 데이터 전문가는 새로운 자동 카메라 이동 표현을 우선 제안했고, 평가 전문가는 직접 점수 비교와 새로운 원천 보강을 우선했다. 비전 전문가는 교차 검토 후 현재 자료의 얕은 HGB 단일 대조를 비용과 직접 판정 가능성으로 먼저 하는 데 동의했다. 위 순서는 성공률이 입증된 최적 순서가 아니라 비용·판별력·기존 실패 이력을 고려한 실행 판단이다.
