## 2. 확인된 실패 기전과 미확정 원인

### 목표와 선택 기준의 불일치
OPEN_001 내부 차량별 proxy F1 평균은 차량 균등에서 +.008424였으나 전체 공개 S3는 -.017365였다. 공개 가속9/감속8/정지3의 혼동행렬 행은 모든 후보에서 같았고 등속30의 결과만 달라졌다. 선택된 정책은 OPEN_001 sample60, OPEN_005 sample420 두 등속을 감속으로 바꿨고 복구한 공개 정답은 없었다. 혼동행렬 행 일치 자체를 모든 후보의 개별 예측 동일성으로 확대하지 않는다.

즉 학습 출처의 균등화가 실제 목표 오류를 고친다는 가정이 이번 비교에서 성립하지 않았다. 이것은 센서 정답이 잘못되었다거나 공식 정답과의 규칙 차이가 유일한 원인이라는 증거는 아니다. 공식 가감속 기준은 CAN 종가속도 등을 사용하며 세부 임계값이 비공개다. comma는 속도 변화에서 만든 대체 정답이다. 직접 대응된 OPEN_001의 가감속10개는 모두 CONSTANT라 가속/감속 경계의 동등성을 검증하지 못한다.

### 희소 원천을 지나치게 강조
expanded_19의 CONSTANT는 학습1개(sample105)뿐인데 49.375배 가중치를 받았다. a=.0886987m/s², v=16.095557m/s로 명백한 오라벨 증거는 없다. 하나의 시각을 원천 전체 범주의 대표로 크게 취급한 설계가 문제다. 그러나 상한4에서도 실패했으므로 극단 가중치만을 완전한 원인으로 제시할 수 없다.

### 오류를 고치기보다 다른 범주로 이동
상한 후보 날짜1 반전은278→199지만 CONSTANT F1은.5501→.4328이다. 날짜3의 새 반전19개는 전부 expanded_21 감속32.1–38.7초 구간에 집중된다. 새 반전 |a| 최솟값은 날짜별 .631/1.338/.591m/s²로 후보 경계±.3 부근이 아니다. 임계값 부근의 애매한 정답만으로 설명할 수 없다. 시간 동기화/센서 정의의 다른 문제를 모두 배제했다는 뜻은 아니다.

### 속도·출처와 범주의 혼동 가능성
CONSTANT 학습 속도 중앙값은 Civic29.36/RAV4 29.68m/s인데 날짜1 Civic CONSTANT 평가 중앙값은15.48m/s다. A/D 학습 중앙값은10–17m/s다. 분포 연관은 관측되었지만, 분류기가 속도나 장면을 가감속의 대리 단서로 이용했는지는 아직 인과적으로 확인되지 않았다. 기존 DIS 고정 격자 통계는 깊이·회전·동적 객체를 물리적으로 분리하지 않는다. 그렇다고 회전 보정이 반드시 해결책인 것은 아니다.

## 3. 평가 해석에서 바로 고칠 점

- 내부 일부 차량 그룹은 가감속 정답이0개다. 예: OPEN_001 inner_3 RAV4는633개 모두 CONSTANT. 이때 반전율0을 평균하면 관측하지 않은 위험을 안전성 증거처럼 읽을 수 있다. 앞으로 분모0은 N/A, 반전 건수/해당 정답 수와 차량·날짜별 값을 함께 보고한다. 이 보고 정비를 이유로 가중치 탐색을 재개하지 않는다.
- 날짜3은 STOPPED가0개라 고정4범주 Macro-F1 최고값이.75다. 날짜 간 절대값 차이를 일반화 성능 차이로 단정하지 않는다. 같은 날짜/동일 표본의 후보 전후 비교는 유효하다.
- 인접10Hz 시각은 독립 사건이 아니다. 연속 오류 구간을 병기한다. 날짜 분할도 일부 겹친다.
- 공개50개와 외부23개 원천은 반복 개발에 노출됐다. 새 독립 검증 자료가 아니다. 공식 공개 산식은 유지하고, 대체 정답 진단을 공식 종합 점수로 부르지 않는다.

## 4. 전문가 교차 검토와 최종 권고

평가 전문가는 공식 정답에 맞춘 저차원 보정을 권했다. 데이터 전문가는 처음에는 기하 특징을 우선했으나, 교차 검토 후 분포 차이가 기하 원인의 인과 증거는 아니라는 점과 비용을 근거로 보정1회 선행에 동의했다. 비전 전문가는 속도-범주 분포 차이를 확인한 후 같은 배경점 특징 검증을 먼저 하는 쪽을 권했다. 전원 합의라고 표현하지 않는다.

최종 권고: **기존 특징·분류기를 고정한 공식 정답 기반 클래스 편향 보정을 딱 한 번 비교한다.** 이것이 가장 높은 점수를 보장하는 방법이라는 근거는 없다. 현재 직접 관측된 공식 등속 오분류를 겨냥하고, 적은 비용으로 추가 실험 방향을 결정할 수 있어 먼저 추천한다. 글로벌 편향으로 장면별 강한 가감속 반전이 해결된다는 주장은 하지 않는다.

### 비교 설계

1. DIS864, 외부2395개, 선형 모델/스케일러/학습 방식, 조향을 고정한다. 차량·원천 가중치는 기존 균등으로 되돌린 기준을 사용한다.
2. 공개5영상 중1영상10개를 outer 평가로 봉인한다. 다른4영상40개에 대해 다시 영상별 내부 교차 검증을 수행한다. 각 내부 모델은 외부2395+공개3영상30개로 학습하고 나머지1영상10개 logits를 만든다.
3. 이렇게 생성한40개의 미학습 영상 예측만으로 4범주 점수에 더할 클래스 편향을 적합한다. 합0 제약으로3자유도, 0에 강하게 수축하는 고정 L2 규칙을 사전 기록한다. 정규화/적합 규칙은 outer 결과를 보기 전에 고정하고 단일 설정만 실행한다. 학습에 쓴40개를 같은 모델로 다시 예측해 보정하지 않는다.
4. 외부2395+공개4영상40개로 학습한 동일한 outer 기본 모델에서 편향0/학습 편향만 비교한다. 새 encoder, 평활, 차량 가중치, 임계값 탐색은 섞지 않는다. 보정은 정규화 log-loss 적합이며 Macro-F1 상승을 보장하지 않는다. 기존 시간 평활 실험과 다르게 범주 간 결정경계만 바꾼다.
5. 공개 S3·가감속 Macro-F1·범주별 혼동행렬·양방향 반전·기존 정답의 새 오류·영상별 이득을 보고한다. 동일한 날짜 학습 원천만 사용해 내부 공개 OOF 보정도 다시 구성한 뒤 날짜 holdout에 기준/보정을 함께 비교한다. 외부 날짜 모델에 공개 정답을 넣는 경우 기존 external-only 결과와 새 기준을 같은 조건이라고 부르지 않는다. 공개 원천과의 미확인 중복 한계도 유지한다.
6. 단일 설정에서 공개 개선이 없거나 반전 감소가 단지 CONSTANT 이동으로 얻어진 경우 보정 방향을 중단한다. 새 반전·특정 영상에 집중된 이득·날짜별 악화는 따로 보고하고 운영 승격을 보류한다. 공개50개를 보며 편향/정규화 반복 탐색을 하지 않는다. 독립 원천 확인 없이 일반화 성공을 선언하지 않는다.

## 5. 보정 다음의 표현 실험

보정이 실패하면 가중치/편향 탐색을 끝내고, **같은 속도대의 정적 배경점 시간 변화 특징**을 검증한다. 속도별 명확한 등속 음성대조와 같은 속도 가속/감속 대조를 학습 원천에서 먼저 선정한다. 추론 입력은 영상만이며 센서는 진단·학습 정답으로만 사용한다.

기존 OpenCV 추적부터 시작하고 전후방 추적 오차, 가림, 동적 객체, 팽창 중심의 안정성을 검사한다. 같은 점도 등속 접근 시 깊이가 줄어 광류가 증가하므로 단순 광류 시간차분을 가속도로 취급하지 않는다. 비전 전문가의 후보는 직선 병진/고정 회전/정적 점 조건에서 팽창 중심 거리 r의 역수 u=1/r를 시간 적합해 얻는 u''/u'다. 이상 조건에서 r=k/Z, u=Z/k이므로 그 비율은 a/v에 대응한다. 이는 검증 전 연구 후보이며 절대 m/s² 복원이 아니다. 정지/저속, 작은 도함수, 회전, 움직이는 물체, 추적 실패는 결측/신뢰도 부족으로 남긴다.

여러 속도대 등속에서 체계적인 가속 편향이 없어야 하며, 같은 속도 A/D 부호 대조를 통과해야 한다. 통과할 때만 기존 DIS·선형 분류기에 특징 하나를 추가한 대조로 진행한다. 회전 보정은 그 이후 별도 대조다. 기존 affine 잔차를 정확한 회전 보정이라고 재명명하지 않는다. 검증 통과 전 DA3/CoTracker 대형 모델 다운로드나 전체 재추출을 추천하지 않는다.
