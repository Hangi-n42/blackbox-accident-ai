# Stage3 비전/모델 전문가 검토

## 사실
- 가중치 실험은 DIS864/선형 모델/표본과 클래스별 손실총량을 고정했다. 첫 날짜 반전 감소가 다른 날짜와 공개 Macro-F1로 이어지지 않았고 capped 원천 가중치에서도 동일했다.
- 기존 affine 공통/잔차 확장, 긴차분 삭제, 하단 제거, 회색조 RAFT 교체가 모두 일관된 개선을 만들지 못했다. 이는 각 해당 구현 조건의 결과다.
- 신경망은 학습 F1 약1이지만 외부 날짜 F1은 낮고, 연속 가속도 보조회귀도 외부에서 학습 평균보다 MAE가 높았다. 센서를 보조정답으로 추가하는 것 자체가 일반화 해법이라는 주장은 기각된다.
- V-JEPA 실제 어댑터는 10Hz16프레임 비중첩창, 438px short-side 후384px중앙crop, 24x24 공간토큰 평균, tubelet2프레임→10Hz 보간이다. 전체 공간구조와 원본 주변부를 버리며 인접창 문맥은 공유하지 않는다. 공간/시간 정보가 충분히 보존된 모든 V-JEPA 접근을 평가한 것은 아니다.
- 내부 proxy 기준의 차량균등 선택은 공개 CONSTANT 2개를 DECELERATING으로 바꿨다. 내부 proxy F1 이득 +.008424가 공개 S3 -.017365와 공존했다. 공식 범주는 종가속도/CAN 비공개 규칙, comma는 속도의 평활 기울기로 만든 대체 범주다.

## 해석의 한계
가중치 실패만으로 깊이/회전/광류 오차가 원인이라고 결론낼 수 없다. 현재 모델은 고정격자 통계를 직접 분류하므로 관측의 혼합을 표현에서 분리하지 않는 것은 사실이지만, 정답 차이/자료 다양성/영상 표현 중 원인 비율은 식별되지 않았다. V-JEPA의 공간 평균이나 짧은창이 실패의 원인이라는 주장 역시 아직 가설이다.

## 다음 1개 추천
**공식·센서 대체 정답을 한 범주로 합친 데 따른 효과를 먼저 분리하는, DIS 고정의 정답 출처 대조 + 소수 파라미터 보정.** 최적 성능을 보장하는 방식이 아니라 현재 근거에서 가장 작은 비용으로 직접 검증 가능한 후보다.

1. 같은2395개 proxy/공개40개와 동일DIS864를 사용하고 외부전용, 공개전용, 단순합동 기준을 각각 분리 보고한다. 공개전용40개 성능은 안정된 기준이 아니라 외부 전이의 방향을 확인하는 대조다.
2. 유일한 개선 후보는 합동 선형모델의 예측확률에 적용하는 저차원 class-bias 보정(4종 중 기준1개 고정→3자유도). 새encoder/신경망/가중치탐색을 동시에 하지 않는다. 정규화 강도는 학습측에서 사전 고정하고 held-out 공개영상은 사용하지 않는다.
3. 보정용 확률은 각 outer public fold의 다른4영상에서 추가 inner leave-one-video-out으로 생성한다. 자기 라벨을 이미 학습한 확률에 보정기를 맞추지 않는다. 이때 각 내부base는 proxy2395+공개3영상30개, 내부heldout1영상10개를 예측한다. 40개의 out-of-fold 확률에만 bias를 맞추고, 최종base는 proxy+공개4영상으로 다시 적합한다.
4. 외부 날짜도 동일한 최종 파이프라인을 적용해 양방향 반전과 F1을 따로 보고한다. proxy 검증 개선을 공식 목표 개선의 필수 동치로 간주하지 않되, Civic의 새 반전을 숨기지 않는다.
5. 중단: 보정이 단지 가감속을 CONSTANT로 보내 반전만 줄이고 Macro-F1을 개선하지 못하거나, 공개5fold 중 특정영상 하나의 소수 시각에만 이득이 집중되면 미채택. 다른 bias/threshold를 공개50개 보며 재탐색하지 않는다. 운영 승격은 별도 미사용 원천 검증 없이는 확정하지 않는다.

### 이 후보가 하지 못하는 일
- 높은 확신의 Civic 반전이 장면 표현 때문이라면 class bias로 해결되지 않는다. 실패 시 원인을 정답 불일치로 확정할 수도 없다.
- 공개50개의 label/source/domain 표본이 매우 작아 낮은 파라미터 수도 과적합할 수 있다.
- 미세 시간창, 깊이/pose, 같은점 추적은 이 검증 뒤에도 별도 후보이며 당장 대형모델을 추가할 근거는 없다.

## 다음 단계의 표현 후보가 필요해질 때
새모델을 곧바로 다운로드하지 말고 기존 V-JEPA의 동일 원본 4~6개 짧은창에서 중앙crop/공간평균이 실제 도로관측을 어느 정도 소실시키는지, 창경계 feature jump가 예측오류에 집중되는지 먼저 무라벨 진단한다. 진단 전부터 전체28개를 공간토큰 재추출해 대형헤드를 학습하면 또 표현/차원/최적화 효과가 섞인다. DA3는 상대깊이/pose가 해당오류에서 실제 센서 변화와 일치하는 소수표본 증거를 만든 후에만 비교한다.
