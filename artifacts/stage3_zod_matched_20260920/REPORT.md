# Stage3 동일 센서 상태의 comma–ZOD 특징 대조 — 2026-09-20

**센서상 거의 같은 감속인데 고정 영역 DIS의 시간 변화 부호가 반대로 나타나고, 운영 모델도 반대 범주를 출력한 구체 사례를 확인했다. 다만 데이터셋 전체에서 특징 의미가 일관되게 반대라는 결론은 지지하지 않는다.** 새 모델·특징·학습·다운로드 없이 기존 자료를 재사용했다.

## 1. 선정과 정답 확인

예측이나 특징값을 보기 전에 센서만 사용해12쌍을 고정했다. 가속4쌍·감속2쌍·등속6쌍이며 comma7개 영상/ZOD9개 영상이다. 이는 독립 성능 평가가 아닌 개발 진단이다. 기존 ZOD 학습/평가 역할을 다시 섞어 학습한 것이 아니며, 양쪽 기존 역할 자료를 진단 후보로만 사용했다.

- 기존 엄격한 센서 proxy 정답이 있는 중심 시각의 앞뒤0.5초, 총11시각을 비교했다. 예측을 보고 정답을 바꾸지 않았다.
- 차속 차이≤1m/s, 가감속 차이≤0.15m/s², 1초 차속 궤적RMSE≤1m/s, 가감속 궤적RMSE≤0.2m/s²를 적용했다. 실제 A/D6쌍의 최대 차이는 속도0.379m/s·가감속0.0934m/s²였다.
- 같은 ZOD 영상·범주에서1쌍만 사용하고 중심1초 창이 겹치지 않게 했다. 다만 긴 특징 계산 창은 겹칠 수 있으며 같은 영상/차량 반복이 있어12쌍을 독립 표본12개라고 해석하면 안 된다.
- 영상 끝단3.5초는 제외했다. 긴 시간 특징을 위해 ±3초의 모든 센서값이 유효하고 속도RMSE≤1.5m/s·가감속RMSE≤0.25m/s²인지를 별도로 기록했다. 조건 통과는 D01과 C01~C04의5쌍뿐이다. 가속에서는 이 조건을 만족하는 짝을 찾지 못했다.
- 기존 aligned speed로1초 기울기를 재계산해 저장 정답과 일치함을 확인했다. A/D 모든 창의 실제 시작·끝 속도 변화 부호도 일치했다. 이는 독립 센서 검증이 아닌 기존 파생 계산의 재검산이다. CAN와OxTS 계측 차이·하드웨어 지연·대회 비공개 임계값은 여전히 검증되지 않았다.
- 비교 가능한 다른 route의 comma 자료를9쌍에 보조 대조로 붙였다. 나머지3쌍은 기준을 완화하지 않고 대조 없음으로 남겼다.

### 가장 가까운 감속 쌍 D02

comma expanded_01/33.4초와 ZOD000036/10.9초는 속도7.566/7.551m/s, 기울기−1.042/−1.053m/s²다. 중심1초의 원시 차속은 각각1.022/1.041m/s 감소했다. 운영 모델은 comma11시각 모두 감속, ZOD11시각 모두 가속을 출력했다. 연구 comma 기준 모델에서도 같은11 대11 오판을 확인했다.

우측 중간 고정영역 ROI7(x=.73~.97,y=.50~.72)의 radial p80 특징을 직접 대조했다. 다음 값은 물리적 종가속도가 아니라 화면 움직임에서 계산한 값이다.

| 값 | comma | ZOD |
|---|---:|---:|
| 앞쪽1.5초 평균 특징 | +0.700897 | +0.145570 |
| 뒤쪽1.5초 평균 특징 | +0.235655 | +0.194505 |
| 3초 차분 특징 | **−0.155081** | **+0.016312** |

캐시의 해당 차분이 `(뒤 평균−앞 평균)/3`과 수치적으로 일치함을 검산했다. **센서상 둘 다 감속하지만 이 화면 특징의 변화 방향은 반대다.** 고정 영상영역의 통계가 같은 물체/깊이를 계속 추적하는 값은 아니라는 점이 핵심이다.

기준 comma 분류기의 평균 A−D logit은 −3.347→+2.077로 이동했다. 변화+5.424 중3초 차분 블록 기여가+3.641이다. ROI7 radial p80 단일 항목 기여는+1.185다. 모든864항의 합이 실제 logit 변화와 일치한다. 이것은 **고정 선형 모델 내부의 정확한 점수 분해**이지 해당 영역을 삭제하면 성능이 오른다는 인과 실험은 아니다. 운영 모델에서는 별도 A−D값이 −3.689→+2.426이며, 앞의 기여 수치를 운영 모델 값으로 사용하면 안 된다.

영상에서 comma의 해당 영역은 가까운 주차 차량에서 도로/차선으로 이동하며, ZOD는 잔디·도로 가장자리와 교차로 차선이 차지한다. 장면 구성과 원근 조건이 다름을 관찰했지만, 깊이·조향·카메라 회전의 개별 영향은 측정하지 않았다.

**중요한 제한:** 이 쌍은 ZOD 센서 결측 때문에 완전한6초 조건을 통과하지 않았다. 공통 유효값만 따로 본 사후 진단에서는 차속50/61시각 RMSE0.142m/s, 가감속45/61시각 RMSE0.142m/s²로 가깝다. 끝부분까지 같다고 보장할 수 없으며, 이 보조 결과로 최초 완전성 조건을 통과한 것으로 바꾸지 않았다.

### 가속 쌍 A02와 시간 이력 영향

comma extra_01/24.6초와 ZOD000033/8.3초는 속도10.097/10.019m/s, 가속도+0.969/+1.063m/s²다. 운영 모델은 comma11시각 모두 가속, ZOD는10시각 감속·1시각 가속으로 출력한다. 기준 comma 모델은 ZOD를 가속2/감속4/등속5로 나눠 출력하며 중심은 등속이다. 

이 쌍의 공통 유효6초 일부에서는 가감속RMSE0.567m/s²로, 긴 이력이 실제로 다르다. 영상에서도 곡선 도로·주변 차량·반사/역광 조건이 다르다. 따라서 이 사례의 긴 특징 차이를 데이터셋 출처만의 효과로 해석할 수 없다. 기준 모델의 점수 변화는 원시 블록과3.1초 평균 블록에서 크게 나타나며, D02처럼 모든 실패가 긴 차분 하나에 집중되지는 않는다.

### 긴 이력 조건을 만족한 D01

D01은 차속15.603/15.501m/s, 기울기−0.552/−0.532m/s²이며6초 조건도 통과했다. 운영 모델 중심 출력은 comma감속/ZOD등속이다. 기준 모델의 D−C 평균 margin은+0.765→−0.427로 바뀐다. 영상은 넓은 시가 도로와 나무가 가까운 좁은 도로로 다르다. 센서 이력을 어느 정도 맞춰도 다른 특징·판단이 나오는 사례지만, 완전히 같은 운동 궤적이나 같은 촬영 조건은 아니며 일반화를 입증하는 표본 수가 아니다.

## 3. 데이터셋 전체의 의미 반전인가?

**그 결론은 아니다.** A01·A04는 양쪽 운영 출력이 모두 가속이고, A03은 comma 중심등속/ZOD가속이다. 원천이 바뀌면 항상 한 방향으로 틀리는 규칙을 발견한 것이 아니다.

comma 기준 scaler로 표준화한864특징의 RMS 거리를 비교했다. 다른 route comma 대조가 가능한9쌍 중8쌍은 cross-dataset 거리가 더 컸지만, cross/within 거리비의 중앙값은1.136배다. C01에서는 cross 거리가 오히려 within의0.597배다. **comma 내부에서도 센서상 같은 상태의 특징 차이가 크다.** 이 수치를 데이터셋 원인에 대한 통계적 유의성이나 도메인 분류 정확도로 해석하지 않는다.

특징 거리는 모델의 판단 방향과도 다르다. D02는 전체 RMS가0.771로 일부 정상 쌍보다 작아도 분류기에 중요한 방향의 차이가 있어 반전한다. 반대로 A03/A04는 큰 특징 차이가 있어도 가속 방향 자체가 유지되는 경우가 있다. 전체 거리만 줄이는 처리를 개선책으로 확정할 근거가 없다. 기준 comma 분류기는 이 comma 원천으로 이미 학습했고 ZOD는 학습하지 않았으므로, 양쪽 정답 수 차이에는 학습 노출 차이도 있다. 예측 수를 독립 일반화 성능 비교로 해석하지 않았다.

등속6쌍도 포함했으며 C01~C04는6초 조건을 통과했다. 기준 분류기는 comma에서도 등속을 가감속으로 잘못 분류하는 사례가 있다. 기존 표현의 모호함이 ZOD에서만 새로 생긴 것은 아니다. 등속의 모든 짝을 새 정밀 평가 자료로 삼은 것이 아니며 상세 예측은 results.json에 보존했다.

## 4. 확인된 범위와 다음 판단

1. **확인:** 동일 방향·비슷한 크기의 센서 가감속을 갖는 두 원천에서 고정영역 영상 특징의 시간 변화가 반대 부호가 될 수 있다. 그 차이가 고정 분류기의 반대 예측으로 연결되는 사례를 확인했다.
2. **확인:** 고정 ROI 통계는 영상의 같은 위치를 비교한다. 해당 위치의 대상·거리 조건이 바뀌는 상황에서 실제 차량 가감속과 일대일로 대응하지 않는다. 사례 D02에서 변화 위치와 실제 장면을 연결했다.
3. **미확인:** 출처 자체가 원인인지, 깊이/조향/카메라/장면/긴 이력/센서 proxy 차이 중 무엇이 지배적인지의 개별 인과 효과. 가속은 완전6초 매칭이0쌍이고 감속도2원천뿐이다.
4. **진행 판단:** ZOD 비중을 늘리거나 전체 특징의 부호를 뒤집는 처리는 정당화되지 않는다. 다음에는 기존 실패쌍의 시간 이력·회전·고정 배경 조건을 더 통제해 특정 시간차/영역의 신뢰성을 검사해야 한다. 이번 결과만으로 영역 삭제·추적기/모델 교체·점수 개선을 주장하지 않는다. 이번에는 학습이나 개선 코드를 실행하지 않았다.
