# Stage3 정지 배경점 선별 대조

**결과: 실행 완료(exit 0), 유효 이동 추정 0/160쌍, 유효 가감속 특징 0/8구간. 가감속 오차 개선 여부는 판정 불가.** 정지 배경점만 남겨도 잘못 예측했다는 결론이 아니다. 기존 기준을 유지하면 추정에 필요한 대응점 수·공간 분포를 확보하지 못했다. 이번 선별 범위에서 점 제거만으로 현재 특징을 구제하지 못했다.

## 실제 수행

- 기존 comma 6구간·ZOD 2구간의 168프레임 전체를 AI가 RGB로 검수했다. 원래 정답/센서/분할은 그대로 유지했다. 새 추정 결과를 보고 영역을 고르지 않았다. 검수자는 이전 결과를 알고 있으므로 맹검·독립 평가를 주장하지 않는다.
- 영상 전체에서 차량(주차 여부와 무관), 차체, 하늘, 잎사귀, 불명확한 영역을 제외했다. 확실히 보이는 도로·일부 건물·중앙분리대·가드레일의 보수적 내부 영역을 정했다. 모든 정지점을 빠짐없이 표시한 정밀 분할은 아니다.
- 168프레임의 마스크/선택점 오버레이도 확인했다. `expanded_19_275`의 건물 후보 띠는 오버레이에서 울타리 식생을 포함해 PnP 평가 전에 삭제했다. `zod_000026_161` f5/f11은 와이퍼로 전체 제외했다. 마지막 두 프레임의 우측 근접 차량도 제외했다. ZOD2 우측 가드레일은 트럭이 벗어난 f8부터 사용했다.
- 마스크 경계를 3픽셀 축소하고 대응점의 시작·끝이 모두 승인 영역에 있을 때만 기존 DIS 점을 남겼다. 주석은 **AI가 영상으로 검수한 정지 표면 후보**이며 사람 검수/공식 정답/개별 대응점의 3D 정지 보증이 아니다. 그림자·반사·유리 흔적과 대응 오차 가능성이 남는다.
- 깊이24캐시, K, 시간 간격, 양방향 PnP, RANSAC/LM, seed42, 최소30인라이어, x/y 분포 기준, q 계산, 유효쌍16/20 기준을 그대로 재사용했다. 새 점 생성·추적기 교체·깊이 추론·학습·다운로드·임계값 탐색 없음.

## 결과

기존 점 34,705개 관측 중 1,747개(5.03%)가 남았다. 이는 여러 프레임에 걸친 대응점 관측 수이며 독립적인 3D 점 수가 아니다.

세 깊이 조건(정순·역순·중간 참조) 모두 각160쌍에서 유효쌍0, q8개 모두 null이었다. 기존 정순 유효쌍이 있던 경우에도 이전 종합 특징 안정성은 이미 0/8이었다. 이번에 공식 분류 결과가 추가로 악화되었다는 의미는 아니다.

정순 기준 탈락 이유:

- **146/160쌍:** 최소30개보다 적은 점. 그중21쌍은 0개.
- **나머지14쌍:** PnP 계산은 되었으나 모두 공간 분포 기준 실패. 1쌍은 인라이어 수 기준도 실패.
- 따라서 센서 q와의 비교 MAE, 부호 복구, 등속 안정성 비교는 계산할 유효 분모가 없다. 결측을 q=0 또는 정답 복구로 취급하지 않았다.

## 왜 배경점이 부족했는가: 필터를 변경하지 않고 계수

같은8px 격자에서 승인 마스크 안의 원천 프레임 후보는 총 31,195개였다. 그중 기존7px 패치 명암 표준편차≥4 조건을 통과한 점은 3,266개(10.47%)였다. 기존 깊이 신뢰도 조건만 적용하면 30,945개(99.20%)가 통과했다. 두 원천 필터를 모두 통과한 점은 3,139개였다.

**이번 승인 영역에서는 깊이 신뢰도보다 영상 질감 조건이 배경 후보를 많이 제거했다.** 이는 실제 계수 결과다. 이후 기존 양방향 광류·도착점 검사까지 통과해 승인 원천 영역에 남은 점은 1,794개, 양 끝 승인 영역 조건까지 적용하면 1,747개다. 도착점·양방향 검사 각각의 영향은 분리하지 않았으며 원천 필터의 탈락률은 중첩되므로 더하지 않는다.

차량·하늘·차체를 없애도 남은 도로에서 충분한 고대비 대응점이 생기는 것은 아니다. 이번 마스크가 보수적이고 대부분 도로 평면에 치우쳐 있어 점 수뿐 아니라 깊이·공간 분포도 제한됐다. 단순히 30개/분포 기준을 낮추면 해결된다고 주장할 근거는 없다.

## 검증과 한계

24개 기존 대표쌍을 재실행해 기존 결과와 일치함을 확인했다. 모든160쌍의 저장 인덱스가 승인된 양 끝 영역의 원본 부분집합인지 검증했다. 전체 마스크 재생성 일치, 와이퍼 프레임0점, 보호 해시 일치를 확인했다. 운영 모델·원본·정답·이전 결과는 변경하지 않았다.

첫 실행은 0개 대응점을 기존 OpenCV remap에 넘겨 중단(exit1)되었다. 새 실행기에 0개를 결측으로 반환하는 처리만 추가했다. 기존 기하 함수·추정 임계값은 변경하지 않았다. 실패 로그와 당시 freeze/부분 선택 결과는 `attempt1/`에 보존했다. 최종 실행·필터 계수·검증은 exit0.

이번 결과로 **정지 배경이 충분히 주어진 경우의 정확성**이나 **모든 정지 배경 방식의 가능성**을 부정할 수 없다. 보수적 마스크 밖에도 사용할 수 있는 배경점이 존재할 수 있다. ZOD 렌즈 모델과 무왜곡 근사의 차이, 영상 깊이의 시간적 스케일 오차도 이번에 해결/분리하지 않았다. 과거 노출 개발 자료이므로 독립 점수 근거가 아니다.

## 진행 판단

현재 조합에 자동 배경 분할 모델을 추가하거나 학습·제출로 확대하지 않는다. 배경 마스크만 추가하는 방식의 개선 근거가 확보되지 않았다. 이 경로를 다시 다루려면 우선 **보이는 정지 구조에서 충분히 넓게 분포한 신뢰 가능한 대응점을 확보할 수 있는지**를 확인해야 한다. 그 전에는 분류기나 깊이 모델 교체보다 계측 자체가 선행 조건이다. 이번 요청에서는 다른 추적기/샘플링 방식으로 실험 범위를 확장하지 않았다.

## 산출물과 재현

- `freeze.json`: 고정 설정·입력 해시·판정 규칙.
- `masks.py`, `masks/`: 정규화 폴리곤과 프레임별 마스크.
- `review/`, `overlays/`: 168프레임 RGB 검수 및 선택점 근거. f20에는 다음 프레임 쌍이 없어 outgoing point0으로 표시된다.
- `selected/`: 원본 DIS 대응점 인덱스. 원본 출처·센서 시각은 `../stage3_depth_pnp_20260920/manifest.json`을 참조한다.
- `results.json`, `summary.json`: 전체 3조건×160쌍 결과·결측과 사유.
- `filter_audit.json`, `filter_totals.json`: 기존 필터 계수.
- `checks.json`, `run.log`, `attempt1/`: 검증·실행 기록.
- `SOURCE_LICENSE.txt`, `DA3_LICENSE`: 기존 출처·조건 보존.

실행: 프로젝트 가상환경으로 `masks.py` → `run.py` → `filter_audit.py` → `report.py`. 완료 산출물의 덮어쓰기를 막기 위해 `run.py`는 freeze가 있으면 중단한다. 재현 실행은 별도 새 artifact 폴더에서 수행한다.
