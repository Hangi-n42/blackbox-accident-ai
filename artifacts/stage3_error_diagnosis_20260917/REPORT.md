# Stage3 지속 등속 오인 진단

## 확인 결과

**현재 모델은 차속이 거의 일정한 구간에서도 광류 크기·방사 방향 변화와 긴 시간창 특징을 근거로 가속/감속 쪽 점수를 높인다.** 0.5초 출력 평활만으로 이 문제를 해결하기 어렵다는 근거다. 다만 관찰한3개 사례만으로 모든 오류의 물리 원인을 확정하지 않는다.

주변 차량 이동이 유일한 원인이라는 근거는 없다. 주요 기여 영역에 차선·도로·하늘/나무·야간 조명·보닛/대시보드가 함께 포함됐다. 차량 객체만 제거하면 해결된다고 결론내리지 않았다.

## 방법과 검증

기존 오류 중 두 차량·주간/야간의3구간을 분석했다. 각 구간에서 연속된 같은 종류의 등속 오인 중 가장 긴 구간의 중앙 시각을 선택하고, 시간상 가장 가까운 올바른 등속 예측을 비교점으로 삼았다. 오답을 조사하기 위한 의도적 표본이며 오류율 추정용 무작위 표본이 아니다.

현재 모델은 StandardScaler→4범주 LogisticRegression이다. 기존 특징 추출로 확률을 재현했고, 세 영상 모두 기존 확률과 일치했다. `(오답 범주 계수−등속 계수)×표준화 특징 + 절편 차이`를 계산해 실제 로짓 차이와 일치함을 확인했다. 따라서 아래 수치는 근사 중요도가 아니라 해당 선형 모델의 정확한 점수 분해다. 그러나 서로 상관된 특징의 기여도는 물체별 인과관계 증명이 아니다.

기존3개 짧은 영상만 특징을 다시 계산했다. 모델·프롬프트·운영 규칙 변경, 학습, 제출, 추가 다운로드는 없었다. 모델 해시 보존 확인과 분석 실행 exit0.

|---|---|---:|---|

오류의 연속 구간은 각각12.3~13.6초,18.1~19.4초,49.9~51.4초다. 10Hz 샘플의 중심 시각 범위다.

### 시간 문맥과 정답 경계

기존 특징은 원시 광류와5/15/31점 평균,15점 평균의±5/±15프레임 차분이다. 광류 프레임 간 계산과 보간까지 포함하면 약±2.3초 문맥을 사용할 수 있다. 새0.5초 평활 이전부터 긴 시간 문맥이 들어가 있다.

- extra_00: 해당 ±2.3초의47시각 모두 기존 센서 범주가 등속. 속도31.483~31.566m/s, 가속도−0.104~+0.042m/s².
- extra_02:47시각 모두 센서 범주 등속. 속도30.597~30.749m/s, 가속도−0.040~+0.149m/s².
- comma_04:39시각 등속,8시각 경계 보류. 가속도−0.286~+0.070m/s². 이 사례에는 긴 문맥에 약한 감속 경계가 섞이는 문제가 남는다.

따라서 앞의 두 사례를 단순히 현재 시각의 라벨과 긴 문맥이 어긋난 문제로만 설명할 수 없다. 센서 동기화 지연을 새로 완전히 검증한 것은 아니며 범주는 비공개 공식 기준이 아닌 기존 대체 정답이다.

### 정확한 점수 분해 예시

오답−등속 로짓 차이가 양수면 해당 오답이 등속보다 선호된다.

- extra_00: 비교점 대비 오답−등속 점수 차이 +1.527. 이 중31점 평균 묶음의 차이는+1.550, 크기 채널 합계 차이는+2.567. 다른 특징이 일부 상쇄한다. 시간 묶음과 채널 묶음은 같은 특징의 다른 분해이므로 서로 더하면 안 된다.
- extra_02: 비교점 대비 차이+2.742. 긴 차분 묶음의 차이는+1.833. 오류 시각 자체에서 긴 차분 기여는+2.936이며 총 가속−등속 로짓은+2.358이다.
- comma_04: 비교점 대비 차이+0.522. 긴 차분 차이는+0.657. 다만 비교점이7.8초 떨어져 있어 독립 변수 통제 비교가 아니다.

하단 차체 영역은 모든 사례에서 양의 기여가 관측됐지만, 각 ROI는 차체와 도로가 섞인다. 한 프레임의 영상 주석으로 전체 시간창의 화소 기여를 분리할 수 없다. 보닛만이 원인이라는 표현은 사용하지 않는다.

## 코드에서 확인한 구조적 한계

- 고정된12개 영역의 광류 통계를 사용한다. 차체/도로/주변 차량을 의미적으로 분리하는 마스크는 없다.
- 방사 광류의 기준점은 화면의 고정 좌표다. 프레임별 소실점이나 자차 회전 보정은 하지 않는다.
- 광류 크기는 영상 내 움직임 신호다. 이를 실제 차속/종가속도와 같은 물리 계측값으로 취급할 수 없다.
- 본 분석에서 좌표·클래스 순서·추론 재현 오류는 발견하지 않았다. 확인한 것은 현 특징과 분류기가 잘못된 근거 조합에 높은 점수를 주는 사례다.

## 다음 개선 실험 제안

**차체가 섞인 하단 영역의 영향을 분리하는 대조 실험을 먼저 한다.** 원본 특징을 사용하는 기준과, 하단4개 ROI를 제외한 특징을 사용하는 후보를 동일한 원천 분할·라벨·학습 설정으로 비교한다. 기존 모델 입력만 갑자기 잘라내는 방식은 학습 분포를 바꾸므로 개선 효과로 해석하지 않는다. 새 후보에는 재학습이 필요하며 이번에는 실행하지 않았다.

평가는 주간/야간·등속/가감속을 나눠 보고, 고정된 공개 정답과 기존 전환 구간 진단도 유지한다. 현재 추가 평가구간은 감속 정답이1시각뿐이라 그대로 채택 기준 전체를 충족하는 검증셋이 되지 못한다. 기존 확보분에서 감속·전환 구간을 보완해야 한다. 이 대조 실험이 실패하면 하단 영역 가설을 낮추고 긴 시간 차분 및 회전/배경 이동 분리 여부를 별도 실험으로 다룬다. 여러 변경을 한꺼번에 넣지 않는다.

## 산출물

- selection.json / freeze.json: 선정 방식·원본·모델·코드 해시.
- results.json: 센서/확률/시간·공간·채널별 정확한 로짓 분해.
- sensor_context.json: 약±2.3초의 센서 범위와 범주 구성.
- feature_details.json: 개별 특징의 값·학습 표준화 척도·기여.
- *_review.jpg: 오류/정답 비교 및 짧은 영상 문맥. 빨간 ROI는 비교점 대비 오답 점수 증가 기여 상위3영역으로, 물체의 원인 확정 표시가 아니다.
- *_features.npz / diagnose.py / execution.log: 분석 특징·재현 코드·실행 결과.
