**PASS — CCD_000688·CCD_000801·CCD_000196.** 각 사례의 low·upsampled·high 9개 입력과 원본 f0 3개를 직접 view_image로 확인했다. 새 모델 결과는 보지 않았다.

low는 384×256이고 upsampled/high는 1152×768이다. 두 큰 입력의 frame 0 헤더·패딩·장면 경계와 표식 위치·상대 두께가 유지됨을 시각 확인했다. 정확한 mask/layout 일치는 읽은 input_checks.json의 기존 픽셀 검사 결과로 뒷받침되며, 이 검수에서 별도 픽셀 검사를 재실행하지 않았다. 새로운 지시·정답 상태 라벨은 보이지 않는다.

upsampled에는 저해상도 픽셀 확대의 계단이 보이고 high에는 원본에 실제 존재하는 세부가 보인다. 그러나 원본의 압축·색 얼룩·유리 반사·흐림·가림·명암 한계도 남는다. high는 원본을 1152×648로 리샘플한 장면이므로 모든 aliasing을 제거하거나 완전한 원본 픽셀을 유지한 것은 아니다. 이 통과는 입력 QA이며 모델 성능 향상을 뜻하지 않는다.

입력·참조 파일 수정 및 추가 모델 호출 없이 이 두 QA 기록만 새로 작성했다.
