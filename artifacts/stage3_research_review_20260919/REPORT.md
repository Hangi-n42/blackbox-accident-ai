# Stage3 점수 개선 재정의와 연구 검토 — 2026-09-19

사용자 지시: 이 작업의 역할은 앞으로 Stage3 점수 개선에 집중한다. 이번에는 공식 요구사항 재확인, 실패 원인 분석, 적용 가능한 연구 검토와 제안만 수행했다. 모델 변경·학습·가중치 다운로드·제출은 없다.

## 1. 홈페이지에서 재확인한 과제

10Hz 실차 주행영상만 입력한다. 디코딩된 N프레임 각각에 ID,sample_index,accel_label,steer_label을 출력하며 sample_index=0..N-1이다. 가감속은 ACCELERATING/DECELERATING/CONSTANT/STOPPED, 조향은 LEFT/STRAIGHT/RIGHT. 조향은 차선 변경 여부가 아니다. 사고시점·진입방향·회피공간은 이 작업 범위 밖이다.

공식 정답은 영상과 동기화한 CAN 신호로 생성한다. 가감속에는 차속·종가속도, 조향에는 조향각을 사용한다. 세부 전처리/임계값/전환 조건은 비공개다. CAN은 추론 입력으로 제공되지 않는다.

공식 평가 이미지도 직접 추출·확인했다(official_stage3_formula.png, 흰 배경 판독용 formula_readable.png).

S3 = 0.7 * MacroF1_accel(4범주) + 0.3 * MacroF1_steer(3범주)
전체 점수 중 S3 비중=0.4. 따라서 가감속 개선의 전체 점수 계수는0.28, 조향은0.12.
조향 평가는 정답 STOPPED 시각을 제외한다. 예측 STOPPED로 채점 대상을 바꿀 수 없으며 모든 시각의 steer_label을 출력해야 한다. 반전 오류 별도 가중 벌점이나 전환시점 허용오차는 Stage3 공식 산식에 없다.

## 3. 실패의 원인: 관측과 추론 구분

확인된 구조/실험 사실:
1. 영상12격자의 광류 분위수/평균/차분864개를 선형 분류기로 연결한다. 동일 장면점을 장기간 추적하지 않고 깊이·객체·자차운동을 식별하지 않는다. 광류모델을 바꿔도 이 요약과 분류 구조는 남는다.
2. 최근 통제 실험은385학습 표본에864~1788특징. 연속시각은 독립사건이 아니고 원천은2차량뿐이다. 차원 증가와 중복 정보가 일반화를 악화시킬 수 있으나 이것만이 원인이라고 인과적으로 입증하지 않았다.
3. strict proxy는13787시각 중5450만 명확 범주로 사용한다. >.5m/s² 가감속, <.1m/s² 등속, 정지<.1m/s, 이동>1m/s 및1초 안정 조건은 대회 공식 기준이 아니다. 미약한 가감속·서행·전환을 많이 제외한 평가로 전체10Hz 성능을 알 수 없다.
4. 기존 모델의 proxy 기준(.3m/s, .25m/s²,2도)과 최근 진단 기준도 다르다. 서로 다른 목적의 숫자를 하나의 목표함수로 취급해서는 안 된다.
5. 공개50개는 운영 학습에 노출됐다. 새 통제 모델에 넣지 않았다고 해서 운영 모델과의 점수 차이를 같은 학습 조건의 비교로 볼 수 없다.
6. 반전 오류를 중시하는 것은 사용자 요구와 타당한 위험 관리다. 다만 각fold/차량/방향 단1개도 증가 불가라는 자동 조건은 공식 MacroF1과 다르다. 평균 상승만으로 채택해서도 안 되지만, 점수 상승과 위험 증가를 수치로 따로 보고해야 한다. 과거 탈락을 소급해 승격하지 않는다.

가장 강한 현재 해석: 작은 원천 다양성, 센서 범주와 목표 정답의 불일치, 시간·기하 정보가 섞인 특징과 학습목표가 함께 제약한다. 영상 품질 한 가지 또는 작은 카메라 흔들림 단독 원인은 입증하지 못했다. 광류와 실제 가속도는 동일 물리량이 아니다. 단안 장면/깊이/카메라 변화에 따른 관측의 모호성도 존재한다.

## 4. 최신 연구와 정확한 적용 범위

### V-JEPA 2.1 (2026-03), frozen ViT-B/16 80M
- 공식: https://github.com/facebookresearch/vjepa2 ; 논문 https://arxiv.org/abs/2603.14482
- 시간적으로 일관된 dense video 특징을 학습하며 영상 분류·영상 분할·깊이 등으로 평가했다.80M distilled 모델과 공식 체크포인트가 공개돼 있다. 논문의1B/2B 최고성적을80M 모델의 성능으로 인용하지 않는다.
- 적용: RGB 시간창→동결된 공간/시간 토큰→작은 프레임별 상태 헤드. 기존의 수작업 광류 통계가 버리는 공간·시간 정보를 보존하는 후보다. 대회3/4범주 헤드는 새로 학습해야 한다. 행동명 분류 체크포인트를 가감속 예측기로 그대로 사용하지 않는다.
- 가감속 자체의 검증 모델은 아니다. 소량 자료로 encoder 전체를 미세조정하지 않는다. 먼저 동결 특징의 별도 비교만 수행한다.
- MIT 중심 공식 코드, 일부 Apache2.0. 공식 체크포인트와 해당 배포 조건을 함께 기록한다. 임의 HF 변환판의 상충하는 라이선스 표기를 근거로 선택하지 않는다.
- Mac: 공식 문서는 decord의macOS 문제를 명시하며 MPS 지원PR81은 확인시점 미병합이다. 기존PyAV 프레임 텐서와 encoder만 호출하는 별도 어댑터, CPU/MPS 수치 비교가 필요하다. 이번에 실행 검증했다고 주장하지 않는다. https://github.com/facebookresearch/vjepa2/pull/81

### Depth Anything 3 (2025-11), DA3-Small 80M
- 공식: https://github.com/ByteDance-Seed/Depth-Anything-3 ; https://arxiv.org/abs/2511.10647
- 여러 단안 이미지에서 깊이·카메라 내외부 파라미터를 추정하며 실제카메라 파라미터 입력은 선택 사항. Small/Base는Apache2.0. 공개pose/depth 평가가 있으나 Stage3 성능 증거는 없다.
- 적용: 같은 짧은창의 관측 프레임들에서 카메라 회전과 병진의 변화·신뢰도를 얻어 가감속/조향에 보조 입력. 기존affine2D잔차와는 다른3D 사전학습 정보다.
- Small은 metric 모델이 아니다. 서로 다른 창의 임의 스케일 병진을 그대로 차분해m/s²라고 부르지 않는다. 같은 창의 상대변화와 일관성 검사부터 시작하고, 카메라yaw도CAN조향각과 같은 값으로 복사하지 않는다.
- Mac 공식 CUDA 경로/의존성 확인 및 짧은 입력의 CPU/MPS 호환 검사가 선행돼야 한다. 렌더링/GS/SLAM 전체를 구축할 필요는 없다.

## 5. 제안하는 실행순서

1. 점수 기준 정렬(추가 데이터 없이): 기존공개5영상leave-one-video-out/출처중복제외와comma차량·날짜검사를분리해보고한다. 후보선택/임계값은학습측에서정하고heldout공개라벨로튜닝하지않는다. 같은공개OOF를여러번선택에쓴한계도기록한다. S3를주지표,범주별F1/반전율/연속오류/전환은보조로기록한다. 임계값미확정시각을공식정답으로승격하지않고센서연속값오차로평가한다. 조향도독립검증되지않은387/387만으로해결됐다고취급하지않는다.
2. 영상특징고정, 감독신호비교: 기존DIS864에서작은시계열헤드를가감속분류만학습한조건과,동일헤드에속도변화/가속대체신호보조회귀를추가한조건을비교한다. 원래linear조건도유지해헤드구조변경과감독변경을단계별분리한다. 분류불확실구간은분류loss에서제외하되유효센서가있으면연속값회귀에사용한다. 가속도는원시속도단순차분이아닌현재검증된전처리·valid mask를사용하고 공식종가속도와동일하다고표시하지않는다. CAN은학습정답으로만쓴다. 조향은기존헤드를고정한후별도실험한다.
3. 주된표현변경후보: V-JEPA2.1-B 동결특징. 같은표본·라벨·학습목표·헤드규모조건을유지해DIS기반과비교한다. 먼저분류전용조건끼리,그다음보조회귀추가조건끼리비교해encoder와목표함수변경을한번에섞지않는다. 시간토큰을통째로평균해장면한개라벨로만들지않고10Hz각시각에정렬된출력을학습한다. 새로운표현에서성능이없으면대규모미세조정으로확대하지않는다.
4. 특정기하혼동이남을경우: DA3-Small의관측창pose/깊이/신뢰도만별도추가. 이후추적필요시CoTracker3을분리평가한다. 속도/조향센서와의기본일관성및전환정렬이실패하면분류기에투입하지않는다. VDA/LFG는앞선병목이확인될때만후순위.
5. 최종채택: 동일학습자료로전체학습한후보와운영기준을구분해보고하고공식S3,클래스별점수,반전양방향,차량/날짜별편차,전환,시간/메모리를확인한다. 위험허용정책은다음결과를보기전에고정한다. 점수상승만보고안전문제를숨기지않고,한두시각진단악화만으로공식점수개선을없던것으로부르지도않는다. 독립검증부족이최종병목이면추가수집은두차량의인접프레임보다다른촬영조건·정지/서행·가감속전환을포함한동기화영상/센서가우선이며이번에다운로드하지않는다.

RAFT RGB 대조는이전회색조결과의적용범위를확인하는작은보조시험으로남긴다. '다른광류를계속바꿔보는것'을주된연구방향으로두지않는다. 기대점수상승수치는현재근거로제시할수없다.
