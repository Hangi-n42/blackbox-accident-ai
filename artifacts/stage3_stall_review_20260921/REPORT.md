# Stage3 개선 정체 원인 — 전문가 교차 검토, 2026-09-21

## 결론

정체된 것은 모든 실험의 숫자가 아니라 **다른 원천에서도 유지되고 반전 위험을 설명할 수 있는, 채택 가능한 점수 개선**이다. 기존 광류 특징은 장면과 촬영 조건이 바뀔 때 같은 차량 상태에 다른 판정 근거를 제공한다. 이를 보완하려던 기하 특징도 실제 속도 변화보다 대응·깊이·카메라 추정 오차에 민감했다. 여기에 정답/검증 범위의 한계와, 중간 검사 통과율을 목표처럼 따라간 실험 설계가 겹쳤다.

단순히 데이터 양, 분류기 크기, Mac 연산 장치 중 하나가 공통 원인이라는 증거는 없다. 각 원인의 전체 오류 기여율도 확인 불가다. 특정 도메인 차이와 표현의 한계가 관찰됐다는 것과, 모든 다른 표현·모델이 실패한다는 주장은 구분한다.

## 검토 범위와 기준

이번에는 영상 기하·추적, 데이터·평가, 실험 전략의 AI 전문가 에이전트 3명이 기존 보고서·수치·관련 코드를 따로 검토했다. 사람 전문가 검수나 새로운 독립 실험은 아니다. 주 에이전트는 운영 경로, 이전 개선/실패 기록, 전문가 판단의 근거를 대조했다. 원본·기존 보고서·모델·정답 수정, 학습, 추론, 다운로드는 하지 않았다.

운영 `model/stage3/motion_model.joblib`, V7 소스, V8 패키지 소스의 SHA256은 모두 `c52ecd15cf68856f2a7b0b37b120c7a961b3bd8889a33af4ec47f8b9719bb3b3`로 이번에 재확인했다. V8 Stage3는 V7과 동일하며, 새 특징은 운영에 들어가지 않았다. V8의 기존 실행 보고서는 2,998행 출력·기준 예측 동일을 확인한 것이며 새 점수 측정 보고서가 아니다.

[공식 평가 페이지](https://dacon.io/competitions/official/236753/overview/evaluation)를 다시 열어 Stage3 비중 0.4와 정지 프레임 조향 평가 제외·전 프레임 출력 요구를 확인했다. 저장된 공식 산식 이미지도 재확인했다: `S3 = 0.7 × 가감속 Macro-F1 + 0.3 × 조향 Macro-F1`. 신규 반전 개수와 기하 검사 통과율은 별도 진단 지표다. 공식 산식의 점수와 사용자 요청의 반전 위험 관리는 모두 보고하되 하나로 혼동하지 않는다.

## 1. 기존 표현이 실제 가감속과 촬영 조건을 충분히 분리하지 못한다

실제 Stage3 경로는 폭 256px의 회색조 DIS 광류를 12개 고정 영역의 중앙값·20/80백분위로 요약하고, 시간 평균/차분과 결합해 864차원을 만든다. 같은 물리적 배경점을 지속적으로 추적하는 구조가 아니다. 같은 영역으로 다른 거리의 도로·차량·구조물이 들어오는 변화도 특징에 포함된다.

직접 근거:

- 같은 입력에서 RAV4 학습 모델과 Civic 학습 모델의 결과가 크게 갈렸다. RAV4 원천 F1은 해당 원천 학습 모델 .971558, Civic 모델 .511513; Civic 원천은 RAV4 모델 .627083, 해당 원천 학습 모델 .972081이었다. 높은 같은 원천 점수에는 학습과 인접 구간이 포함되므로 일반화 성능이 아니다. 차량·카메라·경로·범주 구성이 함께 달라 순수 카메라 효과라고 단정하지 않는다.
- 속도와 가감속이 비슷한 감속 쌍 D02에서 우측 영역의 긴 차분은 comma −.155081, ZOD +.016312였다. 운영 출력도 중심 11시각에서 감속 대 가속으로 갈렸다. 이 사례의 완전 6초 센서는 일부 결측이므로, 차이가 전부 출처 때문이라는 인과 증거로 쓰지 않는다.
- 더 엄격한 완전 시간 이력 대조에서는 감속 1쌍·등속 3쌍만 확보했다. 운영 모델의 등속 정답은 9/66이었다. 시간 이력 불일치 하나로 오판을 설명할 수 없지만, 연속 66시각을 독립 66사례로 세지 않는다.

따라서 현재 분류기가 쓰는 정보의 신뢰성 문제가 관찰된다. 그 정보로 어떤 분류기도 성공할 수 없다는 이론적 불가능성이나 특정 장면 요소의 인과 기여율은 입증하지 못했다.

## 2. 데이터를 섞거나 모델 용량을 높여도 해결되지 않은 이유

ZOD 기존 혼합에서 가속·감속 89시각의 정답은 comma 기준 39개에서 8개로 줄었다. 등속을 더 맞히는 대신 가감속을 놓치는 교환이었다. scaler를 comma 기준에 고정하고 손실 배분을 통제해도 공개 개발 S3는 .808951 대비 .780694로 낮았다. scaler 변경은 악화에 일부 기여했지만 유일한 원인은 아니다. 손실 총량과 원천 배분은 두 번째 대조에서 함께 바뀌었으므로 기여율을 따로 확정하지 않는다.

같은 특징의 제한된 HGB 대조는 학습 F1을 선형 .808~.845에서 .947~.976으로 올렸지만 공개 개발 S3는 .808951→.740018이었다. 날짜1은 좋아지고 다른 날짜는 나빠졌다. 시험한 설정에서는 학습 적합 능력보다 일반화가 문제였다. 이 결과는 모든 비선형 분류기나 사전학습 표현을 기각하는 증거가 아니다.

데이터가 없었던 것도 아니다. 자료 확대의 이득은 실제 존재했다. 필요한 것은 단순히 더 많은 인접 프레임이 아니라, 같은 운동 이력에서 촬영·장면 효과를 분리할 수 있는 구간과 별도 효과 확인 자료다. 현재 엄격한 원천 간 6초 매칭에서 가속은 0쌍이었다.

## 4. 정답과 평가가 개선 판단을 제한한다

공개 공식 정답은 5영상 50시각이며 운영 모델 학습과 반복 개발에 노출됐다. 운영 재평가 S3 .849724는 학습 노출 진단값이고, 연구 모델의 LOVO S3 .808951와 동일 조건 점수가 아니다. LOVO에서도 같은 공개 묶음으로 후보를 반복 선택했으므로 독립 검증이라고 부르지 않는다.

comma/ZOD의 속도 기반 범주는 센서 대체 정답이다. 공식 CAN의 비공개 임계값·평활·경계 처리와 같다고 검증되지 않았다. 다만 명확한 안정 구간에서도 큰 오류가 있어 정답 경계 문제만으로 전부 설명되지 않는다.

이것은 새 특징의 물리적 오류를 만들어낸 직접 원인과 구분해야 한다. **어떤 개선을 믿고 채택할 수 있는지 판단하는 제약**이다. 평가 불확실성을 모델 실패 원인 전부로 돌리지 않는다.

## 5. 실험 설계에서 제가 바꿔야 하는 부분

1. 특징 기여가 큰 영역을 발견한 뒤, 그 영역을 지우거나 가리면 좋아질 것이라는 가설을 여러 차례 시험했다. 기여 분해는 고정 모델의 계산 설명이지 제거의 인과 효과가 아니다. 정상 구간의 유용한 신호까지 없앨 수 있음을 결과가 보였다.
2. 대응점의 실제 좌표 오차를 측정하기 전에 점 수·합의·PnP 통과율을 개선하는 진단이 연쇄적으로 이어졌다. 중간 수치가 좋아져도 최종 가감속 정확도와 연결된다는 보장이 없었다.
3. 한 번에 요소를 하나 고정/변경한 것은 유효한 통제지만, 고정한 요소 자체가 틀린 경우에는 원인을 충분히 분리하지 못한다. 배경 마스크·카메라 모델·깊이의 정확성이 그 예다.
4. 점수 상승, 새 반전, 다른 날짜 악화, 독립 검증 부족을 모두 ‘실패’로 축약하면 실제 진전과 위험의 구분이 사라진다. 반전 관리는 유지하되 공식 지표와 별도 축으로 수치화해야 한다.

실제로 하단 ROI 제외는 당시 Civic F1 .535488→.675979와 동시에 반전 81→98을 만들었다. 학습 범위 확대도 같은 Civic 평가에서 .541226→.627083의 이득이 있었다. 따라서 “아무것도 개선되지 않았다”는 설명은 틀리다. **개선이 다른 조건까지 유지되지 않거나 새로운 오류와 교환돼 채택을 못한 것**이다.

## 판단과 다음 진행 조건

현재 DA3+DIS/LK+PnP 조합의 학습 확대, 같은 공개 정답으로 가중치/격자/필터 추가 탐색, 더 큰 모델을 성공 근거 없이 교체하는 작업은 권하지 않는다.

기하 접근을 더 확인한다면 **대응점의 실제 위치 정확도에 대한 한 번의 제한된 판정**이 우선이다. 공급 성공과 합의 실패 대표 2구간의 초·중·말 3쌍씩, 원본 해상도에서 식별 가능한 도로 표시/건물 점을 센서값과 추적기 결과를 가린 채 지정하고 독립 검수한다. 불확실 좌표는 범위로 남기며 수량을 맞추지 않는다. 사람 검수가 없으면 AI 준거로 명시한다. 이것은 새 모델이나 S3 개선 실험이 아니다.

- 합의 통과점조차 정확하지 않거나 원영상에서도 검수할 수 없다면 현재 교집합 공급 방식 확장은 종료한다.
- 한 추적기의 정확성이 확인되면 그 선택을 고정할 근거가 생긴다. 충분히 정확한 대응이 확인된 뒤에도 센서와 이동 신호가 맞지 않으면 점 공급 튜닝을 중단하고 기하 가정의 문제로 범위를 좁힌다.
- 학습 대조로 돌아갈 조건은 내부 검사 통과가 아니라, 고정된 오류/정상 구간에서 센서 변화와 일치하는 추가 영상 단서 확보다. 이후 기존 분류기·자료·조향을 고정하고 특징 하나만 추가해 S3/범주 F1/새 반전/정답 복구를 함께 비교한다. 개선 보장은 없다.

기하 진단을 점수 검증보다 항상 앞세울 필요는 없다. 실험전략 담당은 이미 공개 개발 이득이 관찰된 자료 확대 후보를 별도 예약 구간에서 확인하는 방안을 우선적인 판단으로 제시했다. 확보 보고서와 후속 ROI/DA3 보고서에는 신규 2경로·6영상·A/D/C 각6개, 총18창을 예측 없이 예약한 기록이 있다. 이번에 실제 예측하지 않았으며 최신 사용 이력과 비교 체크포인트 고정이 선행되어야 한다. 같은 차량의 새 경로이고 센서 대체 정답이므로 공식 S3나 새 차량 일반화 검증이라고 부르지 않는다. 운영 모델과 연구 모델은 학습 조건이 다르므로 실용적인 후보 비교와 학습량의 인과 효과도 구분한다.

종합 우선순위는 다음과 같다.

1. 기존 결과로 평가 가능 범위와 예약18창의 노출 이력·비교 대상을 확정한다. 새로운 센서 매칭이나 전체 재검사는 하지 않는다.
2. 미사용 상태가 확인되면 이미 완성된 후보의 새 경로 이득을 한 번 검증하는 것을 점수 개선 판단의 우선 작업으로 둔다. 결과로 해당18창을 반복 튜닝하지 않는다. 자료를 계속 예약하기로 한다면 점수 개선의 별도 확인이 보류된 사실을 명시한다.
3. 기하 방식에 추가 작업을 배정한다면 위의 대응 좌표 검수 한 번과 종료 조건으로 제한한다. 새 모델·격자 탐색을 자동으로 이어가지 않는다.

세 전문가는 정체 원인에는 같은 방향의 결론을 냈지만, 다음 작업의 우선순위는 같지 않았다. 영상기하 담당은 대응 정확도 검수, 데이터 담당은 해석 가능한 평가 범위 고정, 실험전략 담당은 예약 구간의 기존 후보 검증을 강조했다. 이를 모두 새 실험 목록으로 확대하지 않고 점수 검증과 조건부 원인 검사로 나누었다.

위는 후속 제안이며 이번에 실행하지 않았다. 기존 운영 모델은 유지한다.
