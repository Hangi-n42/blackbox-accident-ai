# Stage3 개선 정체: 데이터·평가 독립 검토

검토일: 2026-09-21. 기존 문서·저장 지표·혼동행렬 검토만 수행했다. 새 학습·추론·다운로드·정답 수정은 하지 않았다. AI 에이전트의 기술 검토이며 사람 전문가 인증이나 새로운 독립 검증이 아니다.

## 결론

**데이터를 더 확보했는데도 동일한 표현으로 다른 촬영 조건을 함께 설명하지 못하며, 현재 평가·진단 자료로는 어떤 촬영 요인이 주원인인지 충분히 분리할 수 없는 상태다.** 확정된 것은 원천이 달라질 때의 큰 성능 하락과 혼합 시 범주 간 손익 교환이다. 카메라/FOV, 장면 깊이, 회전, 센서 정의 중 특정 하나가 지배적 원인이라는 결론은 아직 성립하지 않는다. 또한 모든 실험이 제자리였다는 서술은 틀리다. 학습 확대에는 실제 개선이 있었다. 정체한 것은 일관되고 채택 가능한 추가 개선이다.

## 1. 대회 목표와 현재 측정의 차이

저장된 대회 공식 내용 통합본 `대회_통합_정보.md` 2.4/5절에 따르면 영상만으로 10Hz 전 프레임의 가감속 4범주·조향 3범주를 출력한다. 가감속 정답은 CAN 차속·종가속도 전처리로 생성되지만 세부 임계값은 비공개다. S3는 가감속 Macro-F1 70% + 조향 Macro-F1 30%이며, 조향 평가만 GT STOPPED를 제외한다. 이번 검토에서는 홈페이지 갱신 여부를 다시 조회하지 않았다.

- 공개 개발 정답은 5영상·50시각(A9/D8/C30/STOP3). LOVO는 해당 영상 직접 학습을 막지만, 같은 50개로 후보를 반복 선택한 영향까지 제거하지 못한다.
- 외부 comma/ZOD는 센서로 만든 대체 정답이다. 엄격 평가 구간은 A > .5, D < -.5, C 절댓값 < .1 m/s² 등으로 불명확한 경계를 제외한다. 대회의 숨겨진 규칙을 복원한 정답은 아니다.
- 엄격하고 안정된 구간은 물리적 진단에는 유용하지만 실제 전 프레임의 약한 가감속·전환·결측 주변을 대표하지 않는다. 진단 F1 상승이 공식 전 프레임 점수 상승을 보장하지 않는다.
- `artifacts/submissions/v8_20260920/stage3_public/report.json`의 PASS는 2,998행·이전 출력 동일·파일 불변 검사이며 `score_calls: []`다. 점수 개선 증거로 쓰면 안 된다.

## 2. 확인된 실패 구조

### A. 학습 원천 의존성이 매우 크다

`stage3_model_difference_20260917/results.json`의 동일 입력 비교:

| 입력 | RAV4 학습 F1 | Civic 학습 F1 |
|---|---:|---:|
| RAV4 2,204시각 | .971558 | .511513 |
| Civic 3,246시각 | .627083 | .972081 |
| 공개 50시각 | .629377 | .371209 |

높은 대각선 값은 학습 원천과 인접 프레임을 포함하므로 일반화 점수가 아니다. 공개 등속 30개에서 RAV4 모델은 27개 정답, Civic 모델은 0개 정답이었다. 공통 고속 27≤v<34m/s에서도 교차 원천 등속 오류가 RAV4 입력 922/1,180, Civic 입력 268/765였다. 따라서 속도대 부족만으로 설명되지 않는다. 차량·카메라·도로·범주별 배경이 함께 달라, 이 비교만으로 “차량 자체”가 원인이라고 단정할 수 없다.

### B. 양을 늘리는 것은 도움이 되지만, 범주·조건의 정보량이 핵심이다

`stage3_training_basis_20260917/REPORT.md`: 같은 Civic 3,246시각에서 RAV4 학습 218→437시각 확대는 F1 .541226→.627083, 정답 1,871→2,157을 얻었다. 반전은 161→164로 증가했다. 데이터 확대가 무효였다는 결론도, 점수 상승이 모든 오류의 개선이라는 결론도 모두 틀리다.

최근 ZOD 학습 637시각은 A70/D31/C536/STOP0이고, 평가 472시각은 A35/D54/C383/STOP0이다. 평가 시각 472개는 영상 7개·차량/날짜 4그룹의 연속 관측이다. 프레임 수를 독립 사건 수처럼 취급하면 근거를 과장한다. STOP이 없는 ZOD 고정 4범주 F1과 4범주가 있는 comma F1의 절댓값도 무비판적으로 비교할 수 없다.

### C. 혼합 결과는 실제 가감속을 복구하기보다 등속 쪽으로 옮겼다

`stage3_zod_20260920/comparison_metrics.json`의 혼동행렬을 확인했다.

- ZOD C 정답: 19/383→181/383.
- ZOD A/D 정답: 39/89→8/89. D 정답은 10→0.
- 가감속 반전 21→9지만 사라진 12개는 전부 다른 오답으로 이동했다.
- 공개 개발 S3 .808951→.766171, 기존 오답 복구 0개·새 오답 5개.

이는 범주 간 손익 교환이 확인된 결과다. `balanced`를 사용했으므로 단순히 C 표본이 많아서 총 클래스 손실이 컸다는 설명은 부정확하다. 클래스 내부 원천·배경 구성, scaler, 전체 손실 질량이 함께 달라졌다.

### D. scaler와 손실 배분은 일부 원인일 뿐이다

`stage3_zod_controls_20260920/metrics.json`의 공개 S3는 comma .808951 → 혼합 .766171 → comma scaler 고정 .774554 → 범주 손실/원천 배분 통제 .780694다. 첫 대조는 scaler 효과를 분리해 .008383 회복을 확인했다. 둘째는 추가 .006140을 회복했지만 여전히 comma보다 .028257 낮다.

둘째 대조에서는 전체 손실 질량과 범주 내 ZOD 비율을 함께 바꿨으므로 두 효과를 각각 확정할 수 없다. 날짜1·2 F1은 일부 회복해도 날짜3은 악화하며, ZOD A/D 정답도 22/89에 머문다. 이 한 설정의 실패를 모든 혼합·모든 분류기의 불가능으로 확대해서는 안 된다.

### E. 특징의 조건 의존성은 확인됐지만 원인별 통제가 부족하다

`stage3_zod_matched_20260920/REPORT.md`: 센서상 비슷한 감속 D02에서 DIS ROI7의 3초 차분 부호는 comma -.155081, ZOD +.016312였다. 운영 출력은 각각 11/11 감속과 11/11 가속이다. 다만 이 짝은 완전 6초 센서 조건을 통과하지 못했으므로 “같은 전체 운동인데 출처 때문에 반전”으로 확정할 수 없다.

이후 `stage3_zod_context_20260920/summary.json`은 완전 시간 이력 대조를 A0쌍/D1쌍/C3쌍으로 확인한다. 이 88시각에서 D 정답 21/22, C 정답 9/66이다. 시간 이력을 맞춰도 등속 오류가 남지만 카메라 회전·깊이·장면 구성은 같지 않다. **현재 확보량보다 원인 분리에 적합한 짝의 부족이 진단 병목이다.** 이미 확인한 오류를 다른 그림과 기여도로 반복 설명하는 것만으로 이 공백은 해소되지 않는다.

## 3. 우리 해석에서 경계해야 할 오류

1. 특징 기여의 정확한 logit 합산은 모델 계산 설명이다. 물리 원인이나 해당 특징 삭제 효과의 증명이 아니다.
2. 외부 정답은 불완전하지만 그것이 실패의 유일 원인이라는 증거도 없다. `stage3_official_bias_20260919`는 센서 -1.46~-1.01m/s²의 명확 감속에서도 작은 전역 bias가 새 반전을 만들었음을 보여준다.
3. 원천별 학습 점수 .97과 교차 점수 차이는 표현·학습의 일반화 문제 근거다. 분류기 용량 부족 또는 과다 중 하나를 확정하는 근거가 아니다.
4. 반전 감소, 점수 상승, 채택은 별개다. 안전성 gate로 거절된 실제 평균 개선을 “개선 0”이라고 기록해서도 안 된다.
5. 공개 50개와 현재 comma/ZOD를 계속 재사용하면 조건별 원인을 보는 개발 진단은 가능하지만 독립 개선을 입증할 수 없다. 추가 미사용 검증 원천이 없다는 사실은 현재 실패의 원인과 분리해서 기술해야 한다.

## 4. 다음 검증 하나 — 평가 구성 결정, 아직 실행하지 않음

데이터·평가 관점의 다음 작업은 **기존 센서·분할·카메라 metadata만으로 원인 대조에 적격한 창을 한 번 확정하는 것**이다. 새 학습·영상 추출·다운로드 없이 기존 매칭과 결측 결과를 재사용하고, 후보 창마다 원천·범주·±3초 센서 완전성·회전 신호 또는 카메라 보정 가능성을 한 행에 기록한다. 특히 엄격 비교의 A0쌍이 해소 가능한지, 아니면 현재 자료로 원인 분리가 불가능한지를 결정한다. 이미 부적격으로 판명된 창의 재검산은 하지 않는다.

이는 같은 센서 매칭을 다시 실행하거나 원하는 수량을 채우자는 제안이 아니다. 다음 기하/특징 검증이 어떤 원인을 분리하고 어느 범주까지 해석할 수 있는지 **평가 가능 범위를 먼저 고정하는 결정**이다. 기존 자료에 가속 적격 쌍이 없다면 해당 인과 주장은 확인 불가로 남기고, 현존 정상/오류 창의 개발 진단으로 범위를 제한한다. 새 대규모 자료 확보로 우회하지 않는다.

추후 추가 자료를 요청하더라도 이 표에서 확인된 공백의 조건만 제시해야 한다. 이 단계에서 추가량을 임의로 정하거나 다운로드를 권하지 않는다. 현재 자료가 반복 노출됐다는 사실은 별도 유지하며, 작은 창의 신호 검증을 독립 점수 개선으로 승격하지 않는다.
