# Stage2 독립 AI 조정 검수

**6건 모두 실제 자차 상대와 최초 실제 접촉은 확인 불가이다. 엄격 점라벨은 collision/entry/direction/space 각각 0건이다.** 비충돌 판정이 아니며, 근접·시야 흔들림을 접촉 발생 또는 접촉 시간구간으로 바꾸지 않았다. 공통 관측 코호트가 없으므로 `overall_ai_proxy_S2=null`이고 공식 점수는 없다.

`type=ai_expert_adjudication`, `human_review=false`, `model_predictions_seen=false`, `model_inference_executed=false`. 두 검수 기록을 대조한 뒤 핵심 native PNG 25장을 `view_image`로 직접 확인했다. 조정자가 전체 영상을 연속 재생하거나 오디오를 검수한 것은 아니다. 두 검수의 전체 시간축 검수 기록은 별도 근거로 고려했다.

현재 원본 6개 SHA-256이 각각 PTS 파일에 명시된 원본 SHA와 일치했다. 직접 본 25장은 원본을 순차 디코딩해 원본번호/native PTS/time base/초를 대조했고, PNG의 RGB 픽셀이 해당 원본 프레임과 정확히 일치했다. 00028의 time base는 `1/19584`, 나머지는 `1/15360`이다. 검수 입력 records/review와 protocol의 최종 해시는 [source_verification.json](source_verification.json)에 보존했다.

00024의 f621에서는 택시 후방과 후드가 가까이 보이지만 실제 접촉면은 가려진다. f960의 흰 세단은 별도 차량이다. 00025는 f564/f604의 회전 장면에서 세단과 후드 아래 접촉면 및 첫 바퀴와 경계 연장선의 접점이 보이지 않는다. 00026은 상향 시야와 하단 흐림으로 바퀴·노면·접촉면을 판독할 수 없다. 00027은 f0의 여러 차량과 f585 전방 차량의 동일성 및 시작부터 같은 차로라는 조건을 확인할 수 없고, 근접 장면에서도 범퍼 접촉면이 가려진다. 이 관측으로 접촉 없음 또는 공간 0/1을 확정하지 않는다.

**00028:** 첫 native 프레임에서 Nissan SUV는 노란 중앙선 오른쪽과 우측 연석 사이의 자차 통행 차로에 이미 있다. 두 검수의 조건부 규칙값 `f0 / native PTS 0 / 0초`를 유지한다. 이는 그 SUV가 실제 자차 사고 상대라고 별도로 확인될 때 적용할 규칙값이다. 물리적 최초 진입은 시작 이전 시점 미상이다. f610/612/614/616의 가까움·시야 높이 변화는 접촉 존재나 접촉 시간구간을 확정하지 않는다.

**00029 불일치:** A는 물리 진입 시점/구간을 unknown으로 두었다. B는 `f570–585 / native PTS 291840–299520 / 19.0–19.5초`를 조건부 추론 구간으로 제시했다. 조정자는 f555/563/567의 차량·점선 상대 위치와 이후 f570/572/578/582/585/590을 직접 비교했다. f570 이후 바퀴에 대응하는 점선은 공백·차체 가림으로 불완전하며, f585에도 바퀴 높이의 동일 경계를 직접 읽기 어렵다. **f570은 진입 전이고 f585는 진입 후라는 양끝 조건을 확정하지 못했다.** 따라서 채택한 물리 진입값/구간은 unknown이고, B의 제안은 `disputed_inference_preserved_not_adopted`로 그대로 기록했다. 이를 새 단일 프레임이나 더 넓은 정답 구간으로 대체하지 않았다. 그 구간에 대한 거리·정확도 채점도 허용하지 않는다. f604의 실제 접촉면은 하단/우측 시야 밖이며 f999의 청회색 SUV는 별도 차량이다.

두 검수에서 선택한 근접 재검토 범위는 서로 다르지만 둘 다 접촉 구간을 뜻하지 않는다. [records.json](records.json)은 각 범위를 원문 구조로 보존하고 `is_contact_interval=false`를 명시한다. 네 엄격 타깃의 unknown 상태에는 두 검수가 동의하며, 실질적인 조건부 판정 차이는 00029의 진입 추론이다.

라벨 수는 분리했다. **엄격 점라벨 0개, 엄격 접촉 구간 0개, 조건부 규칙 진입값 1개, 화면 위치 관측 4개, 미채택 진입 추론 구간 1개**이다. 조건부로 채택한 진단 필드는 총 5개이나 실제 사고의 정답 5개가 아니다. 특히 화면 LEFT/RIGHT 관측은 최초 물리 진입 방향의 확정 정답이 아니다. 실제 접촉 시각과 전체 이동 가능한 공간을 확인하지 못하여 공간 라벨은 조건부에서도 0개이다.
