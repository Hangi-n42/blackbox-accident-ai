# 단일 보조합 제거 대조 — 독립 검토

2026-09-19. **판정: 저장된 코드·규약·결과가 일치하며 개발용 사전 조건 통과를 재확인했다. 생산 채택과 독립 일반화 개선은 입증하지 않았다.** 추가 후보·VLM/GPU 추론·원본 디코딩은 수행하지 않았다. 이 검토에서 작성한 파일은 review.md뿐이다.

## 검토 범위와 재검산

protocol.json, run.py, run.log, results.json 및 core_v2의 연결 manifest/freeze를 읽었다. Python 3.12.14, NumPy 2.2.6의 기존 Mac 실행 환경에서 14건의 동결 특징 배열을 다시 계산했다. 36개 직접 의존 파일의 SHA를 대조했다. core freeze의 전체 11,218개 파일과 원본 이미지 전수를 다시 해시·디코딩한 검토는 아니다.

- protocol.json에 묶인 실행 코드·평가 manifest·분해 결과·가설 근거 해시가 현재 파일과 일치했다. results.json의 protocol SHA도 일치했다.
- 실제 동결 baseline `_scores_from_features(features)`로 재계산한 base/new 점수 **28개 배열의 dtype·bytes가 캐시와 정확히 일치**했다. 결과 원응답에 기록된 배열 해시도 같았다. 이는 캐시 특징에서 점수로 가는 계산 검증이며 영상→광류 특징을 새로 재현한 검증이 아니다.
- 후보는 기존 식과 같은 median/MAD×1.4826, floor 1e-3, 하한0으로 uncapped jerk를 직접 계산한다. 첫 점수0과 기존 NumPy argmax 동률 처리를 유지한다. residual·appearance를 뺀 뒤 반올림하는 방식이나 초기 jerk 추가 보정이 아니다.
- 후보 **14개 배열의 해시·승자가 저장 결과와 일치**했다. dtype·길이·유한성·원본 번호의 유일성과 정렬을 확인했다. 후보 점수는 기존 합성 점수보다 크지 않았다.
- 14건 모두 기준 `baseline_prediction`을 사용했고, 진입·방향·공간의 **값이 정확히 보존**됐다. 전체 JSON 파일의 byte 동일성을 뜻하지 않는다. 후보 출력을 보고 진입 후보나 공간 문맥을 다시 생성하지 않았다.
- 사례별 PTS 오차·허용오차 판정·gained/lost와 코호트별 평균을 독립 재계산했다. 확인 명령은 exit 0이었다.

## 인과·통계 해석의 한계

1. protocol.json은 가설이 이미 노출된00007의 점수 역전에서 나왔다고 명시한다. 한 사건에서 착안한 규칙이 그 사건을 고친 결과이므로 새 독립 증거로 취급하지 않는다. stored protocol→results의 파일 시각 순서는 사전 동결 기록과 부합하지만 외부 공증된 사전등록을 뜻하지 않는다.
2. 입증 범위는 **현재 고정 특징·정규화·개발자료에서 두 보조항을 함께 제거하면 선택이 어떻게 바뀌는가**다. jerk가 물리 접촉의 충분한 단서라거나 보조항이 일반적으로 해롭다는 결론은 아니다. residual과 appearance의 개별 효과도 분리하지 않았다.
3. 사람9건은 단일 검수 초안·개발 노출 자료다. 00007의 시각 검토를 새 공식/독립 정답으로 바꾸지 않는다. 공개5건의 무회귀도 비공개 일반화나 통계적 유의성의 증명이 아니다.
4. 큰 카메라 움직임·첫 관측 jerk·샘플 간격 혼입은 남는다. 보조항이 유효한 약한 접촉 증거를 주는 새로운 사건에서는 제거가 손실을 낼 수 있다.
5. 다른3출력을 복사했으므로 그 항목의 문맥 불일치는 해결하지 않았다. 전체4회 질의 파이프라인 재실행·Linux/CUDA NF4 실행·독립 사고 확인은 하지 않았다. 전체 S2 상승이나 제출 준비 완료를 주장할 수 없다.

**후속 처리:** 규약대로 이 한 후보의 결과를 보존하고 이번 탐색을 종료한다. 결과를 보고 부분 가중치·시간창·사례 예외를 추가하지 않는다. 이 검토는 생산 모델 교체를 승인하지 않는다.
