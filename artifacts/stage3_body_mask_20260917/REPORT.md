# 차체 경계 표본 검수 및 보수적 차체 마스크 실험

## 결론

**후보 미채택.** 차체로 관찰되는 안쪽만 광류 통계에서 제외했으나 동일 자료로 재학습한 대조군보다 비교/공개 성능이 낮아졌고 전환 검사도 악화했다. 운영 모델·조향·실행 코드는 유지했다. 차체 제거가 등속 오인의 해결책이라는 가설을 현재 근거로 지지하지 않는다. 이번 보수적 고정 마스크의 실패이지 모든 차체 분리 방법의 실패를 입증한 것은 아니다.

## 1. 경계 검수

기존10개 comma 입력과 공개5개 입력 각각의 시작 부근/중간/끝 부근3프레임, 총45프레임을 AI가 시각 검수했다. 주간/야간, 두 차량, 도로/정차 장면을 포함했다. 전체 프레임의 픽셀 정답 검수나 사람 주석은 아니다.

확인: 기존 하단 ROI(y=0.72~0.93)는 도로/차선과 보닛/대시보드가 섞인다. 고정 직사각형 전체 제거는 순수 차체 제거가 아니다. 야간의 반사와 어두운 경계는 정밀 구분이 어렵다.

후보 경계는 모든 입력에 동일한 정규화 좌표를 사용했다:

- x: [0,0.15,0.5,0.85,1]
- y: [0.90,0.86,0.84,0.86,0.90]
- 선형 보간한 선 아래만 제외. ID별/차량별 정답표나 출력 정답에 따라 바꾸지 않았다.

검수 표본에서 차체로 확인되는 안쪽을 선택했다. 경계 위의 차체 일부는 남겨 도로를 잘못 제거할 위험을 줄였다. 이 경계는 완전한 차체 segmentation이나 다른 카메라 설치의 보편적 경계가 아니다. 비교/public 입력의 외형도 검수에 포함됐으므로 독립 평가라고 주장하지 않는다. 예측 점수를 보기 전에 경계를 고정했다.

원본/마스크 표본은 review_0~4.jpg와 mask_overlay_0~4.jpg. 최종 오버레이 가운데2개 시트18프레임도 다시 확인했다. 최초 원본 시트는45프레임 전부 확인했다. 빨간 영역은 제외하는 차체 안쪽이며 노란 수평선은 좌표 안내다.

## 2. 후보 구현

이미지를 검게 덮거나 잘라내지 않았다. 기존 원본에서 DIS 광류를 그대로 계산하고, ROI의 median/q20/q80 통계를 계산할 때 마스크 화소만 제외했다. 인공적인 검은 경계가 광류에 생기지 않도록 한 선택이다. 반면 전체 프레임에서 계산된 광류이므로 차체 움직임의 주변 영향까지 완전히 제거한 것은 아니다.

12개 ROI·4개 채널·3개 통계·6개 시간 묶음, 총864차원을 유지했다. 하단 ROI 화소의 약62.5~74.5%를 보존했다(검사한144/192 높이 기준). 하단4개 ROI 전체를 삭제했던576차원 후보와 다르다.

15개 영상 모두 상단/중간8개 ROI에 해당하는576개 시간 특징이 기존값과 비트 단위로 일치했다. 이 확인은 동일 입력·특징 추출에서 의도한 하단 통계만 바뀌었음을 검증한다. 빈 ROI의 0대체는 금지했고 모든 특징은 유한값이었다.

## 3. 학습·평가 통제

이전 대조 실험의 분할·정답·유효 마스크·학습 설정을 그대로 사용했다.

- 학습: RAV45개 구간,2Hz218시각. 가속39/감속65/등속84/정지30.
- 비교: Civic5개 구간,10Hz유효1,897시각.
- 공개: 희소 정답50시각. 새 학습에는 포함하지 않았다.
- 모델: StandardScaler + LogisticRegression(C=.03, balanced, max_iter=2000, seed42).
- 기존 전체864특징 재학습 대조군과 예측은 해시 확인 후 재사용. 후보만 동일218라벨로 학습했다. 스케일러는 학습 자료에만 fit했다.
- 후보는78iterations에 수렴. 평활·조향 변경·threshold 튜닝 없음.

기존 운영 모델은 학습 자료가 다르므로 여기의 재학습 대조군과 같은 모델이 아니다. 모든 자료가 과거 개발/운영 모델 학습에 노출됐으며 두 차량만 포함한 제한된 실험이다.

가속↔감속 반전 감소만으로 후보를 채택하지 않았다. 비교 Macro F1·등속F1·공개 비감소·전환 비악화 조건은 실패했다.

## 5. 전환 진단

이전과 동일한 Civic센서 대체 전환37개 및 교정된 사건 대응 규칙을 사용했다. 공식 전환 정답은 아니다.

- 양쪽 모두 검출한18개: 센서 구간 밖 평균 거리0.5833→0.6667초.
- 전환 검출 실패17→18개.

직전 하단전체제외 실험의 공통 검출8개와 분모가 다르므로 평균 거리를 후보끼리 직접 비교하지 않는다. 원시 사건별 결과를 transitions.json에 보존했다.

## 해석과 다음 방향

차체 기여가 컸다는 이전 로짓 진단은 해당 특징이 모델 결정에 쓰였다는 증거였으며, 이를 제거하면 성능이 좋아진다는 인과적 증거는 아니었다. 이번 통제 실험에서는 보수적 제거가 비교 성능을 떨어뜨렸다. 마스크를 계속 조절해 같은 비교 점수에 맞추지 않는다.

상단/중간 특징이 같고 하단 통계만 바뀌었는데 악화했으므로 이 후보의 측정 실패를 다른 코드 변경으로 설명할 근거는 없다. 차체 신호가 유효한 카메라 움직임 단서를 주었는지, 남은 차체/도로의 통계 분포 차이인지, 소량 학습·도메인 차이인지는 분리되지 않았다.

후속 연구가 필요하다면 공간 마스크 가설을 일단 내려놓고, 이전에 큰 기여가 확인된 긴 시간 차분 특징을 동일 조건으로 분리하는 대조 실험을 검토한다. 이번에는 추가 후보를 실행하지 않았다.

## 보존·검증·산출물

모든 실행 exit0. 코드·운영 모델·원래 정답 해시 보존,대조군 체크포인트 동일,15개 입력의상단/중간 특징 일치,무한/결측/빈ROI 검사 통과. SciPy solver옵션 폐기 예정 경고만 있었고 수렴 실패는 없었다. dependency 변경·추가 다운로드·제출은 없었다.

- boundary_review.json / review_manifest.json: 표본·경계·AI검수 한계.
