# f561−f0 방향미분 검수 A

**국소 산술 진단은 PASS다. 현재 방향에서는 L2 규제가 목표 비교의 개선을 돕고, 시작 프레임이 목표인 두 사례의 손실이 반대한다. 이 사실을 전역 원인이나 다음 실험의 개선 보장으로 해석하지 않는다.**

d는 고정 특징의 x[00000,f561]−x[00000,f0]를 단위 정규화한 방향이다. 직접 비교의 점수 미분은 +4.663041로, +d 이동이 이 비교의 margin을 높인다. 각 참조 선호쌍 D의 gradient는 −D·sigmoid(−D·w)/(4n), L2 gradient는 0.1w다. 따라서 손실의 방향미분이 음수이면 해당 방향을 돕고, 양수이면 반대한다. 결과의 winner/loser는 모델의 실제 승패가 아닌 참조 선호 순서다.

직접적인 f561>f0 선호쌍의 방향미분은 −0.086724275다. 두 before-start 사례는 각각 11개 쌍 모두 반대한다. 그러나 00000 안에서도 f561>f841, f561>f748, f561>f1028의 세 쌍은 반대한다. 한 비교를 개선하는 이 방향이 같은 사례의 모든 비교를 개선하는 방향도 아닌 것이다. 이를 참조 오류나 학습 전체의 모순이라고 부르지 않는다.

data 항 +0.032275484와 L2 항 −0.032275475가 상쇄된다. 전체 gradient norm도 9.195e−8로 작다. 최적점 근처에서 합이 거의 0인 것은 예상되는 사실이며, 이번에 추가로 확인한 내용은 어떤 항들이 반대 방향으로 작용하는지다. 이 방향의 반대 항은 규제가 아니므로 λ를 더 낮추면 문제가 해결된다고 주장할 근거는 없다. 다른 방향이나 새 최적점에서의 규제 효과는 이 계산만으로 판단할 수 없다.

코드는 pair→사고→data+L2 합을 원래 목적의 gradient와 대조한다. 검토자는 저장 JSON으로 단위 norm, 각 gradient 내적, 쌍별 합과 전체 합을 1e−15 범위에서 독립 재확인했다. 새 fit·가중치 변경·특징 제거·모델 호출·CCD 접근은 없었다.

후속 하나는 **first_candidate_indicator 계수만 0으로 고정한 train-only 1회 재학습**을 의존성 진단으로 제안한다. 기존 14특징 값과 PCA·정규화는 그대로 두고 w13=0 제약만 추가한다. λ0.1, 53쌍, 참조·후보·가중치 평균·0 초기화·L-BFGS-B 설정을 유지하며 나머지 13계수만 자유롭게 둔다. 기존 점수 분해에서 이 항이 00000의 특정 비교 부호를 뒤집었으므로, 다른 항의 보상을 허용한 뒤 그 의존성을 직접 확인하는 목적이다. 개선을 예상하거나 의미적 지름길을 확정하는 제안은 아니다.

이 제약은 현재 d 전체를 재현하지 않는다. d의 firstflag 성분은 −0.775918이며 다른 특징 성분도 포함한다. before-start 성능 손실과 상대시간 등의 대체 사용 가능성이 있고, 기존 14자유도 LP의 top1 가능성이 w13=0 제약에도 성립한다고 가정할 수 없다. 비교는 같은 학습 4건의 선택·허용 집합 소속·참조 시간오차·paired MAE·전체 쌍 margin을 모두 보고해야 한다. 고정된 좌표의 gradient는 0일 필요가 없으므로 수렴은 자유 좌표 또는 projected gradient/KKT 조건으로 판단해야 한다.

후속 실험은 미실행 제안이다. 이번 결과는 노출된 약한 참조 4건과 한 국소 방향에 한정되며, 전역적 해결 불가능성·사고 이해·일반화·공식 점수 근거가 아니다. 기존 입력·참조·모델은 그대로이고 신규 expert_review.json/md만 작성했다.
