# 동일 예측 원인 분석

**결론: 복사·모델 로딩 오류가 아니라, 같은 원천·특징·분류기 구조에서 학습한 두 결정 함수가 이번 18개 입력을 같은 범주로 분류했기 때문이다. 파라미터와 확률은 달랐지만 어느 사례도 1위 범주가 바뀌지 않았다.**

## 확인 방법

기존 predictions.csv, 저장 DIS864 특징, 두 checkpoint만 읽었다. 영상 재추출·새 평가 사례·학습·후보 조정은 없다. 기존 입력과 모델의 동결 해시를 확인하고, scaler와 선형 가중치로 z=(x-mean)/scale, logits=zWᵀ+b, softmax를 계산해 저장 확률을 atol 2e-6 이내로 재현했다. 실제 Pipeline의 float32 중간 연산과 수식 검산의 float64 차이를 허용한 것이다. 18개 저장 예측의 분석이지 추가 성능 실험이 아니다.

## 1. 두 모델은 원천이나 표현 방식이 크게 다른 비교가 아니다

- 운영: 역사적 comma 2,761시각 + 공개 정답 50개.
- 연구: 수정된 선별/정답 기준의 comma 2,395시각, 공개 정답 제외.
- 학습 comma route ID는 두 모델 모두 23개이며 23개 전부 겹친다. 행 단위 입력·정답이 전부 같다는 뜻은 아니다.
- 둘 다 같은 DIS864 특징과 StandardScaler/LogisticRegression 구조다. C=.03, balanced class weights, L2, lbfgs, max_iter=2000 등 분류기 설정도 같다.
- 따라서 ‘확대학습’이라는 연구상의 이름을 운영보다 더 많은 새 원천을 학습했다는 의미로 읽으면 안 된다. 이번 두 모델 사이에는 그런 원천 확대가 없다.
- scaler 차이를 보정하여 운영 표준화 좌표로 두 가중치를 옮긴 뒤, 범주 쌍의 차이 벡터를 비교했다. 코사인 유사도는 가속/감속 0.878557, 가속/등속 0.867996, 감속/등속 0.877525; 전체 6쌍 범위 0.867996~0.920799다. 두 분류 방향이 유사하다는 근거이며, 절편·경계 위치·전체 공간의 동등성을 증명하지 않는다. 높은 차원의 상관된 특징에서 개별 가중치를 독립적인 물리적 중요도로 읽지 않는다.

## 2. 확률 변화가 1위 범주를 뒤집지 못했다

확률의 최대 절대차는 0.130922, 평균 절대차는 0.027721이다. 이는 데이터에 대한 별도 보정이 검증된 확신도가 아니라 모델 softmax 출력이다.

|---|---|---|---|---|
| RAV4 clip10 34.5초 | 가속 | 등속 .7126 / 가속 .2856 | 등속 .7807 / 가속 .2176 | 잘못된 등속 우위가 더 커짐 |
| RAV4 clip12 28.5초 | 감속 | 등속 .9122 / 감속 .0387 | 등속 .9755 / 감속 .0130 | 감속 근거가 여전히 크게 뒤짐 |
| Civic clip60 24.5초 | 감속 | 가속 .5436 / 감속 .2909 | 가속 .4973 / 감속 .3530 | 정답 쪽으로 움직였지만 가속이 여전히 1위 |

- RAV4 9개는 양쪽 모두 등속이다. 1위와 2위 확률 차이는 운영 최소 .359678, 연구 최소 .563140으로 이 묶음에서는 근소한 동률 문제가 아니다.
- RAV4 가감속 오답 6개 중 5개에서 연구 모델의 오답-정답 logit 차이가 더 커졌다.
- Civic에는 근접 경계 사례도 있지만 역시 1위가 바뀌지 않았다. 연구의 최소 1·2위 차이는 .027927이다. **18개 동일은 모델이 어디서나 같다는 증거가 아니다.**
- 공통 오답 11개 중 오답-정답 logit 차이가 줄어든 것은 3개, 커진 것은 8개다. 줄어든 3개도 차이가 0을 넘지 않아 정답 복구가 없었다.

## 3. 계산 내부에서 어떤 특징이 같은 오답을 지지했는가

저장 선형 함수에서 `(오답 계수 - 정답 계수) × 표준화 특징`을 합산했다. 아래는 상관된 특징의 대수적 분해이며, 특징 제거 실험이나 물리적 원인 확정이 아니다. 각 모델의 자체 평균을 기준으로 한 분해이므로 서로 다른 모델의 개별 항 크기만으로 인과 효과를 비교하지 않는다.

- RAV4 clip10 34.5초의 등속-가속 점수: 운영은 15·31프레임 평활 블록이 +0.769/+1.426, 두 시간차분 블록은 -.579/-.210이다. 연구는 평활 +.526/+1.532, 시간차분 -.125/-.320이다. 양쪽 모두 일부 시간차분이 가속을 지지하지만 전체 등속 우위를 상쇄하지 못한다. 최종 차이는 +.914→+1.278로 남는다.
- RAV4 clip12 28.5초의 등속-감속 점수: 화면 하단(y=.72~.93) 블록의 합이 운영 +2.209, 연구 +2.436으로 같은 오답 방향에 기여한다. 이것만으로 하단이 차체인지 노면인지, 그 영역을 제거하면 좋아질지는 판단하지 않는다.
- Civic clip60 57.5초의 정지-가속 점수: 원시/평활 블록이 양쪽 모두 정지 방향이며, 시간차분 블록도 +.231/+.014와 +.298/+.141로 이를 뒤집지 못한다. 이번 입력의 현재 표현과 가중치 조합이 실제 속도 10.242m/s의 가속을 정지로 읽는다. 영상 자체에 가감속 정보가 없다는 증명은 아니다.

## 확인된 원인과 확인되지 않은 원인

**확인:** 같은 23개 학습 원천, 같은 영상 표현과 분류기 설정, 유사한 분류 방향, 같은 오류를 지지하는 점수 구성, 모든 18개에서 유지된 argmax 순위. 따라서 연구 모델이 이번 공통 오류를 해결할 새로운 판별 능력을 보이지 않았다는 결론은 가능하다.

**미확인:** 야간 조명·글레어·원근·차체·다른 차량·센서 지연 중 어느 것이 실제 실패 원인인가. 이번 두 모델은 학습 행·정답·공개 정답 포함 여부가 함께 다르므로 특정 학습 변화의 인과 효과도 분리되지 않는다. 등속 학습 행이 많다는 이유만으로 원인을 단정할 수 없으며 양쪽 모두 class_weight=balanced를 사용한다. 18창은 두 경로에 묶인 소표본이다.

운영 기준 유지 판단은 변하지 않는다. 임계값을 움직이면 해결된다는 근거가 없고, 이 분석으로 새 모델이나 특징을 자동 제안하지 않는다. 필요한 것은 공통 오답을 실제로 구분하는 추가 정보의 검증 근거다. 예약 자료는 이미 개발 노출 상태이며 원본·모델·정답·좌우반전 폐기 결정은 그대로다.
