# 자동 시작 상태 gate 사후 검토 A

동결 후보는 채택하지 않는다. 8개 원응답은 모두 정상 JSON OUTSIDE였다. INSIDE만 f0으로 바꾸는 정책이 한 번도 활성화되지 않아 네 출력이 그대로 남았다. 기존/보정 모두 확정 정답0·오답7·불확정1이고 같은 참조 시점에 대한 정확도·MAE 변화는 정확히0이다. 개선 최소1건 조건을 실패했다. [평가](evaluation.json)는 공식 S2 점수가 아니다.

[독립 검증](independent_verification.json) PASS 기록도 확인했다. 동결2056파일, 신규16 processor,96캐시 재생이 확인됐고 gate 모두12토큰 후 EOS로 끝났다. 형식 오류나40토큰 제한으로 잘린 결과가 아니다. 본 역할은 별도 수치/텐서 검증을 다시 실행하지 않고 그 기록을 읽었다.

실제8개 gate PNG를 직접 확인했다. 688/801/196은 f0의 가까운 상대와 우측 문맥의 차체·적재물 대응이 보인다. 801/196에는 초기 같은 차로 관계를 읽을 도로 구조도 남아 있다. 따라서 052의 상대 부재만으로 전체 OUTSIDE를 설명할 수 없다. 검수자의 대상 대응은 모델의 실제 대응 성공을 증명하지 않는다. 688 무차선 통로,728/1237 작은 상대·가림 한계도 유지한다.

052 문맥 f46/48/49에는 실제 상대가 없지만 UNCERTAIN 대신 OUTSIDE를 확정했다. 사전 규칙은 이 사례의 INSIDE 확정만 실패로 정했으므로 unsupported_identity_commit=0은 원평가와 일치한다. 이0은 불확실성 처리가 성공했다는 증거가 아니다. 사후 기준·참조 변경은 하지 않는다.

확정되는 직접 원인은 OUTSIDE만 반환해 gate가 작동하지 않은 정책상 경로다. **왜 OUTSIDE만 냈는지, 같은 상대 오식별인지 올바른 상대에 대한 바퀴·차로 관계 오판인지는 state-only 응답으로 확인 불가**다. 확대·자동 문맥·별도 질문을 함께 바꿔 개별 효과도 미분리다. 모델 전반의 능력 부재를 단정할 수 없다.

후속 우선순위는 하나다. **기존12후보 생성은 유지하고 자유생성 번호 선택을 학습 가능한 시계열 선택기로 교체하는 개발을 준비한다.** 이미 진입한 f0과 영상 중 최초 진입을 함께 학습 대상으로 삼는다. 표식·범례·해상도나 같은 질문의 미세 조정을 반복하는 것과 다른 구조 변경이며 효과는 미검증이다.

첫 실행 작업은 기존 확보 원본에서 사람이 판독 가능한 사고를 골라 실제 상대의 연속성, f0 상태, 최초 경계 접촉 범위·미상을 주석하고 원영상 그룹 단위 학습/검증 분할을 고정하는 것이다. 현8건의 노출된 AI참조만으로 학습·독립 검증할 근거는 부족하다. 넓은 구간을 임의 중간점 정답으로 만들지 않고 확실한 후보 전후 관계만 학습하거나 제외한다. 검증에는 시작 전/영상 중, 상대 부재·가림을 포함하고 참조·채택 기준을 응답 전에 고정한다. 같은12후보에서 baseline과 구간 정확도·오차·잘못된 f0 선택을 쌍별 비교하고 상대 식별 실패를 별도 집계한다. 실제 제출 CUDA 경로와 다른3출력 보존까지 검증하기 전에는 교체 근거가 없다.

과거 노출이 있는 AI 사후 검토이며 사람의 독립 정답·일반화 검증이 아니다. 추가 호출·학습·범위 확대 없이 신규 expert_outcome_review.json/md만 작성했다. 기존 동결 파일과 참조는 변경하지 않았다.
