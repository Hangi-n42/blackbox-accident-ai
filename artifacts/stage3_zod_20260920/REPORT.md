# ZOD Stage3 데이터 검증 및 학습 대조 — 2026-09-20

요청한 5개 구간 검증 → 현재 운영 모델 진단 → 학습용 25개 선별 → comma 대 comma+ZOD 비교 → 미학습 구간 평가를 수행했다. **이번 혼합 모델은 미채택이다.** ZOD 등속 분류는 나아졌으나 가속·감속 구분과 공개 개발 S3가 악화됐다. 운영 모델과 기존 자료·결과는 보존했다.

mini·infos·OxTS는 제공자 Dropbox content hash와 전체 SHA256을 검증했다. 영상 압축파일 46.56GB 전체 대신 필요한 ID까지 압축 앞부분 4.483GB만 받았다. 영상은 선택한 멤버의 SHA256을 기록했고 학습/평가에 쓰는 6,567프레임을 실제 디코딩했다. **부분 압축파일은 제공자 전체 해시 검증 통과로 표시하지 않았다.** 선별된 33개 원천 이미지 6,633개에서 학습/평가 간 동일 바이트 중복은 없다. 이미 받아 놓은 제외 구간 000006·000007도 삭제하지 않았다.

초기 vehicle_data 압축파일 탐색은 파일 순서가 영상과 달라 필요한 파일 0개를 추출했다. 이를 차량 신호 확보 성공으로 세지 않았다. 9.59GB 전체 차량 신호 묶음은 받지 않았고, mini의 두 구간으로 CAN 교차 검증을 제한했다. 새 대규모 영상 전체 다운로드나 LiDAR/Radar 다운로드는 수행하지 않았다.

## 정답과 시간 정렬 판정

- 원본 영상은 JPG 시퀀스다. 프레임별 UTC 촬영 시각으로 10Hz 그리드의 가장 가까운 프레임을 선택했다. 첫 5개 최대 정렬 오차는 약 0.0494초다. 프레임 ID와 원본 경로를 보존했다. 영상의 해상도·FOV·왜곡을 새로 보정하지 않았다.
- OxTS UTC 변환은 공식 devkit의 `315964800 + timestamp + leapSeconds`를 따랐다. `ego_motion.json` 속도는 원본 OxTS를 **메타데이터의 원래 시각**에 보간한 값과 일치한다.
- 000000/000002에서 유효 10Hz 속도와 차량 CAN 속도의 최대 차이는 각각 0.0681/0.0997m/s, 1초 속도 기울기 RMSE는 0.0151/0.0147m/s²다. 두 스트림에서 모두 범주가 정해지는 121/155시각은 범주가 일치했다. 모든 영상에 CAN 교차 검증을 확장한 것은 아니다.
- 가감속 라벨은 기존 comma와 같은 11점·1초 차속 기울기로 만들었다. 이동 중 `A>0.3`, `D<-0.3`, `C abs<0.2m/s²`, 정지 속도 `<0.2m/s`; 알려진 범주 사이 전환 ±0.3초는 결측이다. 평가는 A>0.5/D<-0.5/C abs<0.1, 이동 속도>1m/s, 정지<0.1m/s 및 11점 안정성 기준을 추가했다. **대회의 비공개 CAN 전처리 임계값을 복원한 것이 아닌 센서 대체 정답**이다.
- North/East velocity·XY 유효성, 시간 공백, 유한 값, 속도 표준편차, pose 이동량과 속도 일치 검사를 적용했다. 결측 속도는 NaN, 모호한 라벨은 -1로 보존했다. raw accelerationZ에 중력에 가까운 성분이 있어 원시 가속도를 범주 정답으로 복사하지 않았다.
- 일반 `isValid` 필드의 의미는 devkit에서 확인하지 못했다. 이 필드가 0인 자료를 일반 유효성 통과라고 표현하지 않는다. 명시적인 속도 관련 플래그와 별도 일관성 검사를 사용한 **조건부 proxy 실험**이다. 센서 하드웨어 지연과 사람 정답은 검증하지 않았다.
- 예측 전 QA 초안에서 이중 보간 시각을 잘못 비교한 부분을 수정했다. 속도 std≤0.1m/s 초안은 CAN과 일치하는 000002도 전부 제외해, 거친 오류 배제용 시험 상한 0.5m/s로 수정했다. 초안은 `qa_draft_pre_prediction/`에 보존했으며 이후 라벨·임계값을 예측에 맞춰 바꾸지 않았다. 이 상한은 측정 정확도 보증이 아니다.
- 육안 표본에서 와이퍼, 젖은 도로, 역광, 근접 트럭, 어안 왜곡이 관찰됐다. 영상은 정상 디코딩·시간 순서·장면 연속성 검사에 사용했고 육안으로 정밀 가감속 정답을 새로 붙이지 않았다. 오류 대표 000014/000036도 추가 4프레임 검사했고 정답은 바꾸지 않았다.

판정: **파일 무결성은 전체 수신 archive 통과/영상 부분 archive 제한 있음. 주석은 센서 대체 정답으로 조건부 사용 가능. 한정된 학습 대조는 실행 완료. 대회 정답 수준의 신뢰성·전체 범주 학습 준비 완료는 아님.** 정지 구간은 이번 선별분에 없다.

## 고정한 대조

- 기존 학습 comma 23개 원천의 2,395시각 유지. 후보는 ZOD 25개에서 637시각(A70/D31/C536/STOP0)만 추가해 총 3,032시각.
- 동일 DIS FAST, grayscale width256, 864차원, `StandardScaler + LogisticRegression(C=.03, class_weight='balanced', max_iter=2000, random_state=42)`.
- scaler는 동일 학습 규칙에 따라 각 학습 자료에서 재추정했다. class_weight도 동일 balanced 공식에 따라 달라진다. 구조·특징·임계값·하이퍼파라미터 탐색은 없었지만, 고정된 scaler/총 손실 질량 대조는 아니다.
- 새 ZOD 평가에서는 두 모델 모두 공식 공개 정답을 학습하지 않았다. 공개 개발 평가는 기존과 동일하게 외부 자료+나머지 4영상의 40개 공식 라벨로 각 LOVO 학습을 수행했다. 조향 예측은 기존 값으로 고정했다. 기존 comma 3개 날짜 분할도 그대로 유지했다.
- 기존 운영 모델(c52ecd15…)과 최근 연구의 comma 확장 학습 기준 모델은 다르다. 운영 모델의 새 ZOD proxy F1은 별도 0.083892이며, 아래 데이터 추가 대조의 baseline은 **comma 2,395시각으로 학습한 기준**이다.
- 운영 모델은 첫 5개 pilot의 등속 211개 중 54개만 정답, 가속 5개는 모두 감속으로 예측했다. 이 pilot은 등속 편중이며 이후 학습용으로 사용되어 독립 평가가 아니다.

## 분할과 해석 한계

차량+UTC 날짜 그룹은 학습/평가 간 분리했고 동일 이미지 바이트 중복도 없다. 그러나 같은 도로를 다른 날 지난 영상이 포함된다. 000037은 학습 경로와 GPS상 약 1.1m까지 가까워진다. 따라서 전체 묶음을 새로운 도로 독립 평가라고 부르지 않는다.

모델 결과를 읽기 전 별도 정의한 GPS 경로 최소 거리>2km 집계에는 000014/000015/000016이 포함된다. 실제 최소 거리는 34.76/200.70/50.32km다. 이 세 영상 351시각에서도 관측 세 범주 F1은 0.140420→0.184573으로 오르지만, 가속/감속 F1은 둘 다 0으로 하락한다. 따라서 전체 결과가 단순한 학습 도로 중복만으로 설명되지는 않는다. 두 날짜·한 차량에 불과하고 동일 카메라/데이터 수집 환경이라는 한계가 남는다.

472시각은 독립 실험 472개가 아니다. 실제 기여 영상 7개/차량·날짜 그룹 4개이며 정지와 정밀 전환부가 빠져 있다. 이번 결과를 일반화 입증으로 표현하지 않는다. 이번 평가 결과를 확인했으므로 이후 이 묶음에 맞춰 튜닝하면 개발 자료로 취급해야 한다.

## 결론과 다음 실험 제안

**이번 데이터 혼합법은 미채택.** 신규 데이터 확보·정제와 학습 실행은 완료했지만 점수 개선 목표는 달성하지 못했다. 기존 모델과 ZOD 학습 후보를 서로 다른 파일로 보관했다.

확인된 현상은 새로운 카메라 영역의 등속 보정과 가감속 손실이 동시에 발생했다는 것이다. 기존 영역에서도 등속 구분이 악화됐다. 이것을 단순히 '등속 수량이 많아서'라고 확정할 수는 없다. 이미 class_weight='balanced'를 사용했고, 데이터 추가로 scaler·특징 분포·클래스별 배경 구성·총 학습 손실 질량이 함께 바뀌었다. 카메라/FOV와 동적 객체 차이는 영상에서 관찰했지만 각각의 인과 기여는 이번 한 번의 대조로 분리되지 않았다.

다음 후보는 **추가 전체 다운로드나 새 모델 대신, 같은 특징·분류기에서 소스×범주 학습 기여도를 통제하는 한 번의 대조**다. comma scaler와 기존 클래스별 총 손실 질량을 고정하고, ZOD에 의한 특정 조건의 영향만 제한하는 방식으로 자료 혼합과 재표준화 영향을 분리할 수 있다. 효과가 보장된 제안은 아니며 이번 작업에서는 실행하지 않았다. 기존 8개를 다시 쓰면 개발 대조로 표시하고, 채택 확인은 별도 미사용 구간으로 해야 한다.
