# 신규 CCD 12건 예측 미노출 검수 묶음

선정은 SHA256(전체 CCD_ID) 순서와 ego=Yes/원천 그룹 제외만 사용해 영상 취득 전에 고정했다. 공개 2그룹과 기존 12그룹을 제외했으며 신규 12건도 서로 다른 그룹이다. 시각 판독이나 결과에 따른 교체는 하지 않는다.

HTTP Range 취득 5,839,443바이트; 원본 MP4 합 5,752,273바이트. 전체 600프레임의 파일 SHA와 native PTS를 검증했다. 각 클립은 0부터 시작하는 50프레임, 시각 0.0~4.9초(10Hz)다.

이 묶음은 공급자 사고 시작 라벨과 모델 예측을 포함하지 않는다. 판단 불가 필드는 unknown으로 유지한다. AI 검수는 사람 인증 정답이 아니며, source group 분리만으로 완전한 사건 독립성을 보증하지 않는다. 기존 자료 1,822프레임과의 별도 중복 검사에서 지정 범위의 중복 제외는 없었다. 완전한 사건 독립성 인증은 아니다.
