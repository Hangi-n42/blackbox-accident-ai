# Post-result interpretation review B

고정 gate PASS는 이 개발 실험에서 유효하다. 개선은 사전 진입 1건의 제출 인코딩 교정에 한정되며, 영상 중 진입 시점 선택 개선이나 공식 S2 향상을 입증하지 않는다.

이 검수는 결과를 본 뒤 수행한 AI 해석 검수이다. 신규 모델 호출 0회이며 입력·참조 라벨·독립 검수 기록은 변경하지 않았다.

| 사례 | 관측 | 해석 |
|---|---|---|
| CCD_000052 | state INSIDE, entry f17(1.7s)→f0. 직접 본 f0 표식은 가장 가까운 녹색 세단이 아니라 그 앞의 동일 사고 상대를 지칭한다. 독립 검수의 전체 시퀀스 추적과 일치. | 대회 already-inside 제출 규칙 및 동결 before_start 0/0 참조에서 확정 개선 1건. 물리적 진입 시각을 0초로 복원한 것은 아니다. |
| CCD_001237 | state OUTSIDE; f24 유지. 참조 f8~21. | 2.4초 예측의 참조 구간 대비 오차는 0.3~1.6초로, inclusive 0.3초 기준에서 단일 정오를 확정할 수 없다. 같은 예측 유지이므로 paired 변화는 정확히 0. |
| CCD_000540 | state OUTSIDE; f44 유지. 참조 f32~37. Q3 후보 [0,4,9,13,17,22,26,31,35,39,44,48]에 f35가 실제 포함. | f44는 참조 모든 시점보다 0.7~1.2초 늦어 확정 오답. f35는 참조 양끝에서 최대 0.3초 차이여서 고정 허용 오차 내 확정 정답 후보였다. 후보 누락은 원인이 아니다. |
| CCD_000643 | state UNCERTAIN; f15 유지; 참조 상태·시점 UNKNOWN. | 불확실성 응답 및 fallback 작동을 관측했다. 정답/오답 또는 시점 정확성은 주장하지 않는다. |
| CCD_000022 | state OUTSIDE; f12 유지; 참조 상태·시점 UNKNOWN. | 모델 OUTSIDE를 새 참조 라벨로 수용하지 않는다. 상태/시점 정확성을 주장하지 않는다. |

052의 개선은 같은 상대에 대한 제출 인코딩 교정이며 물리적 진입 시각 복원이 아니다. baseline 질문에도 다음 문구가 이미 있었다:

> If it was already inside this lane at the first image, select the first image.

baseline Q3에도 already inside라면 first image를 고르라는 규칙이 이미 존재한다. 새 규칙의 효과가 아니라 별도 상태 질의·사고 상대 표식·단일 첫 프레임 구성·큰 입력·후처리 override를 결합한 정책 효과. 각 요인의 단독 인과는 분리되지 않았다.

raw 번호 44만으로 다른 상대를 지칭했는지, 바퀴/경계 판독에 실패했는지, 늦은 큰 움직임을 선택했는지 확정 불가. 현재 정책은 OUTSIDE면 baseline을 그대로 복사하므로 이 사례의 불변은 새로운 시점 재판독의 실패 결과가 아니다.

53 calls = baseline 48 + state 5. Timing 분모 3건에서 확정 이득 1, 손실 0, paired accuracy +1/3 및 MAE -0.5667초. 이 변화는 모두 052 한 건에서 발생했다. 영상 중 진입 2건은 그대로다.

- 7건 표식 불가 fallback과 12건 다른 3필드 불변은 정책 구성에 따른 보존이며 새 판독 성능의 증거가 아니다.
- 상태 참조 3/3 일치에서 UNKNOWN 2건을 빼고 보고해야 한다. UNKNOWN을 오답 또는 정답으로 간주하지 않는다.
- timing 평가 분모는 12가 아니라 3. 사전 진입 개선의 근거는 단 1건이며 영상 중 진입 2건은 무변화.
- A/B 개발 AI 참조와 B 동료 조정은 사람 전문가 정답도 제3 독립 검수도 아니다.
- 사고 후 전체 영상을 보고 수동 지정한 동일 상대 표식은 privileged information이다. 자동 상대 검출/추적 및 실서비스 성능을 입증하지 않는다.
- 새 그룹으로 사전 고정한 실험이라는 장점은 있으나 소표본·표식 가능성·참조 가능성의 제한이 남는다. 공식 S2는 산출되지 않았다.

540 다음 진단은 제안만 하며 실행하지 않았다. f31/f35/f39에서 같은 상대의 바퀴-차로 경계 관계를 분리해 질문하는 진단은 현재 남은 시점 선택 문제에 맞는다.

- 현재 540 사례는 원인 탐색용 개발 사례로 유지한다. 성공하더라도 독립 성능 개선으로 부르지 않는다.
- 고정된 동일 상대·같은 프레임·같은 원본 번호·바퀴/차선이 함께 남는 시야를 사용하고, '경계 밖/첫 바퀴 경계 접촉 또는 안쪽/판독 불가'의 상태 정의를 실행 전에 정한다.
- 첫 비교에서는 렌더 크기·표식·해상도·후처리·후보 집합을 고정하고 후보별 상태 질문과 직접 시점 질문의 효과만 비교한다. 확대를 시험하려면 별도 고정 요인으로 분리한다.
- f31/35/39는 참조 구간 전/중/후를 둘러보는 진단 점들이다. 참조 구간 중간인 f35의 정확한 접촉 전후 상태를 기존 interval만으로 점 라벨화하지 않는다. 필요한 개별 상태 참조는 신규 응답 전 별도로 시각 검수하고 UNKNOWN을 허용한다.
- 후보별 상태 전이가 관측되어도 연속 추적·바퀴 경계 인식의 내부 원인이 확인됐다고 단정하지 않는다. 이후 검증은 미사용 사례·사전 고정 정책으로 별도 평가한다.

모델에 참조 f32~37 또는 정답 후보 f35를 알려주거나, f44에서 임의로 고정 프레임 수를 빼서 교정하지 않는다.
