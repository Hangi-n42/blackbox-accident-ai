# Stage3 학습 차량이 다른 두 모델의 차이 진단

## 결론

가장 강한 근거는 **동일 특징·분류기 구조가 학습한 차량/주행자료에 따라 서로 다른 판정 경계를 학습했다**는 것이다. 두 모델 모두 학습 차량·주행구간을 잘 맞히지만, 다른 차량 및 공개영상에서 오류가 크게 늘어난다. 특정 긴 차분 묶음 하나나 경계 라벨만으로 이 현상을 설명할 수 없다. 차량 자체, 촬영환경, 도로, 밝기, 범주분포가 함께 달라 어느 하나가 원인인지는 아직 분리되지 않았다.

모델 학습/변경, 라벨 수정, 새 영상 특징 추출, 다운로드는 하지 않았다. 기존23구간864특징 캐시를 두 고정 모델에 적용해 같은 입력끼리 비교했다. 기존 차량 외 예측 전체와 일치함을 확인했다. 원본·운영 파일과 라벨/모델을 보존했다. 최종 비교 exit0.

## 1. 같은 입력에서 확인한 차이

|평가 입력|RAV4 학습 모델 F1|Civic 학습 모델 F1|
|---|---:|---:|
|RAV4 11구간 2,204시각|.971558 (학습 원천)|.511513 (다른 차량)|
|Civic 12구간 3,246시각|.627083 (다른 차량)|.972081 (학습 원천)|
|공식 공개50시각|.629377|.371209|

학습 원천 점수는 일반화 성능이 아니다. 실제fit시각과 그에 인접한 같은주행시각이 들어 있다. 실제fit시각만의F1도 RAV4 .982290/Civic .991099로 높다. 공개50은 두체크포인트의학습에들어가지않았지만이미개발에노출돼 독립평가는아니다. 두차량5,450시각은 센서대체정답이다.

|같은 입력|둘다정답|RAV4모델만정답|Civic모델만정답|둘다오답|
|---|---:|---:|---:|---:|
|RAV4|833|1,312|19|40|
|Civic|2,131|26|1,037|52|

RAV4등속1,217시각에서 Civic모델은688감속/265가속/264등속이다. Civic등속1,035시각에서 RAV4모델은236감속/212가속/586등속/1정지다. 따라서 문제가 한쪽방향에서만 나타나지 않는다.

공개등속30시각은RAV4모델27정답, Civic모델0정답(감속28/가속2). 반대로공개감속8시각은RAV4모델3정답/등속오류5, Civic모델8정답이다. Civic모델의높은감속적중만보고우수하다고할수없다. 등속까지감속으로밀리는편향과함께봐야한다.

## 2. 속도·표본수 차이만으로 충분히 설명되는가

RAV4등속 학습241시각의속도5/50/95백분위는27.06/29.81/33.22m/s, Civic등속207시각은14.65/31.33/33.14m/s다. RAV4의저속등속표본부족은실제공백이다. Civic저속(<20m/s)등속150시각에서RAV4모델은127오류다.

하지만공통고속대역27≤v<34m/s에서도RAV4영상등속1,180시각중Civic모델922오류, Civic영상등속765시각중RAV4모델268오류다. **속도범위부족하나로설명되지않는다.** 이는속도구간으로나눈관찰이지도로/영상구성까지통제한인과실험이아니다.

두모델은기존동일한balanced class weight설정이다. 그러므로단순클래스개수차이만으로학습가중치가결정된다고설명하면틀린다. 각범주가포함하는독립주행·속도·조향·영상조건의대표성은여전히다르다. RAV4정지30시각한route문제도남아있지만현재주된등속/감속오류를이것하나로설명하지않는다.

## 3. 공통오류와 한쪽오류의 문맥 차이

기존1초안정마스크는고정하고,각평가시각주변±23시각의47시각이모두같은대체정답·유효센서인지추가진단만했다.

- 둘다오답92시각 중20시각만전체문맥이같은범주/유효센서/충분한길이를만족했다. 나머지72는조건을충족하지않는다.
- 각차량에서해당차량모델만정답인2,349시각 중1,461시각은전체문맥동일/유효조건을만족한다.

따라서공통오류의상당수는변화가섞인문맥과연관되지만,차량간성능차이는안정구간에서도크다. 실제센서지연을검증한것은아니며,센서대체라벨의1초창과영상특징의더긴문맥차이가공통오류에영향을줄가능성은남는다. 라벨을예측에맞춰바꾸지않았다.

원본HEVC에서는decoder PTS가없으므로null로보존했다. 기존동기화frame_index/frame_time에대응해프레임을추출했으며새PTS를만들지않았다.

## 5. 다음 실험으로 연결되는 결론

**이제긴차분제거·시간창탐색을반복할근거는없다.** 다음분리실험의우선대상은학습자료구성이다. 같은864특징/분류기를유지한채,두차량의다양한주행으로학습하되평가route를통째로분리하는구성이차량한쪽학습보다오류를줄이는지확인할수있다. 이번에는실행하지않았다.

이비교에서는새혼합모델만기존전체학습모델과비교하면안된다. 양쪽기준도동일한보류route를제외해재학습해야한다. 같은차량내route보류는새차량일반화검증이아니며같은도로의공간중복도확인해야한다. 현재두차량·개발노출자료로는독립적인새차량성능을입증할수없다.

이렇게자료구성효과를먼저분리하면,특징문제와대표성부족을구분할근거를추가할수있다. 공통경계오류는별도진단으로두고정답기준을완화하지않는다. 카메라영역/물체/조명원인을확정하려면같은움직임과환경을대응시킨통제가더필요하다.
