# Stage3 차량·원천 가중치 실험 — 2026-09-19

**제안했던 가중치 조정은 이번 조건에서 개선에 실패했다. 후보 전부 미채택이며 운영 모델을 유지한다.** 첫 날짜의 반전 감소와 공개 점수 유지, 다른 날짜의 비악화를 동시에 충족한 조건이 없었다.

이번 비교 기준은 직전 자료 확대 실험의 **개발 후보 S3 0.808951**이다. 운영 모델의 과거 OOF0.798298이나 엄격 표본 기준0.749301과 혼동하지 않는다.

## 수행한 실험

- 기존 외부23개 영상의 사용 가능 대체 정답2,395시각, 공개5영상50정답을 그대로 사용했다. 공개 각 fold는 외부2,395+다른 공개4영상40개 학습이다.
- DIS864 특징, 정답, 2Hz 학습 시각, 10Hz 평가 시각, unweighted StandardScaler, LogisticRegression C=.03/class_weight=balanced를 고정했다.
- 가중치만 변경했다. 외부 **각 클래스별 총 가중치**, 전체 가중치, 공개 학습 표본의 가중치1을 유지했다. 따라서 표본 수 증가나 클래스 비중 변경, 전처리/규제 강도 변경을 가중치 효과와 섞지 않았다.
- 기존 외부 날짜3분할 평가1,612/1,167/561시각을 사용했다. 동일 날짜가 분할 사이 반복되므로 독립 표본을 합산한 성적으로 보지 않는다.
- 공개 S3는 가감속 OOF와 기존 조향 OOF를 합성한 개발 지표다. 조향은47개 non-STOPPED에서 F1 0.850304로 동일하게 유지했다. 공식 식 `.7×가감속Macro-F1 + .3×조향Macro-F1`을 적용했다. Private/대회 전체/독립 점수가 아니다.
- 기준 모델은 기존 체크포인트를 재사용했고 **모든 held-out 시각의 확률까지 이전 결과와 정확히 일치**했다. 새 다운로드·디코딩·특징 재추출·라벨 수정은 없었다.

가중치 정의:

1. 차량 균등: 외부 각 클래스 안에서 차량별 총 학습 비중을 동일하게 만든다.
2. 차량·원천 균등: 차량별 비중을 동일하게 한 뒤, 그 차량·클래스에 존재하는 원천별 비중을 동일하게 만든다. 없는 원천·클래스 표본은 생성하지 않는다.
3. 중간 비중: 원래 가중치와 차량·원천 균등 가중치를0.5씩 혼합한다.
4. 추가 상한 대조: 위 결과 이후 확인된 학습 가중치 집중 문제를 점검하기 위해 **새 결과 전에** 별도 설정을 고정했다. 차량·원천 가중치에[0.25,4]상한/하한을 적용하고, 클래스별 총 가중치는 원래와 같도록 학습 자료만으로 보정했다. 다른 상한값을 탐색하지 않았다.

## 평가 정답으로 후보를 고르지 않았는가

외부 각 학습 분할 안에서 차량·날짜를3개 내부 fold로 나눴다. 동일 차량의 동일 날짜에 속한 원천은 항상 함께 이동한다. 내부 학습에서 모든 클래스가 유지되는지 확인했다. scaler와 모델 학습, 가중치 계산에는 내부 검증 원천을 넣지 않았다.

내부의 차량별·fold별 평균 대체 정답 F1를 최대화하되, 차량별 평균 반전율 증가≤1%p, 내부 fold F1 감소≤0.02, 평균 F1 비감소를 만족하도록 고정했다. 동일하면 기존 균등 표본 가중치를 우선했다. 외부 날짜 정답과 held-out 공개 영상 정답은 선택 함수에 들어가지 않는다.

선택 결과는 날짜1과 공개5개 fold에서 **차량 균등**, 날짜2/3에서는 **원래 표본 가중치**였다. 최대4배 후보를 추가해도 선택은 같았다. 내부 선택은 결과 파일을 만들기 전에 각 fold별로 저장했다.

예를 들어 OPEN_001을 외부 평가로 둔 학습 자료에서는 차량 균등의 내부 평균 F1 이득이+0.008424였지만, 최종 공개 OOF S3는−0.017365였다. 학습측 proxy 기준에서 선택한 이득이 공개 정답으로 이어지지 않았다. 이 결과를 근거로 공개 평가에서 가장 좋아 보이는 다른 후보로 사후 교체하지 않았다.

## 왜 단순 균등화로 해결되지 않았는가

확인된 사실은 다음과 같다.

- 원천 균등 가중치는 표본이 적은 원천·클래스 조합을 크게 강조한다. OPEN_001의 학습 fold에서 최대 가중치가49.375였고, 가중치의 Kish 유효 표본 수는2,435→776.34로 줄었다. 이는 가중치 집중도 지표이며, 연속 프레임이 독립 표본이라는 의미가 아니다.
- 중간 비중도 최대25.1875배였다. 최대4배 대조에서는 이 집중을 억제하고 같은 유효 표본 수 지표를1,495.47까지 회복했지만, 공개 점수와 다른 날짜의 반전을 동시에 개선하지 못했다.
- 클래스 비중·전체 손실량·특징·모델·정답을 고정해도 결과가 날짜마다 달랐다. 현재 시험한 차량/원천 균등화 정책만으로 일반화 문제가 해소된다는 근거는 없다.
- 내부 평가에서는 유리했던 차량 균등 정책도 공개 평가에서 불리했다. 센서 대체 정답과 공식 정답의 차이, 원천 다양성 부족, 영상 표현의 한계 중 어느 하나가 단독 원인인지는 이 실험으로 확정할 수 없다.

모든 재가중치 기법이 불가능하다는 결론은 아니다. 다만 이번 외부 평가 점수를 보면서 가중치나 상한을 더 탐색하면 같은 작은 평가 자료에 맞추는 문제가 커지므로, 이번 실험에서는 여기서 멈췄다.

## 채택 판정과 보존

고정한 부분 개선 기준은 공개 점수 비감소, 공개 반전 비증가, 기존 정답에서 새 공개 반전 없음, 날짜별 F1 비감소, 날짜·차량별 반전 비증가 및 날짜1 Civic 반전 감소다. **이를 통과한 후보는0개**다. 과거 엄격 표본 안전 기준까지 요구한 운영 승격 기준도 통과하지 못했다.

운영 모델 SHA와 기존 입력/정답/특징/결과를 보존했다. 실행2개와 최종 감사는 모두exit0. 주 실험의 학습·평가 약34.64초, 상한 대조 약10.04초이며 문서 작성/분석 시간은 포함하지 않는다.
