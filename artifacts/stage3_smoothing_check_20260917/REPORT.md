# 0.5초 가감속 평활 추가 검증

## 결론

**기본 파이프라인에 적용하지 않고 현재 기준을 유지한다.** 다른 주행의 안정 구간에서는 소폭 개선했지만, 사전의 전환 구간 비악화 조건은 통과하지 못했다. 이 결과만으로 후보가 일반적으로 나쁘거나 좋다고 단정할 수 없다.

후보·모델·라벨·0.5초 창은 변경하지 않았다. 학습·제출·다운로드·전체 데이터 추론은 하지 않았다. 원래 파일과 앞선 결과를 보존했다. 실행 및 채점 수정 검사 exit 0.

## 범위와 선정

앞선 5개 주행 route를 제외하고, 차량별 남은 route에 고정 문자열+segment SHA256 순서를 적용해 2개씩 총4개를 선정했다. 선택에 모델 예측을 사용하지 않았다. 모델 학습에는 이미 쓰인 자료로 독립 검증셋은 아니다.

- Civic: 2018-05-03--09-25-46/24, 2018-05-02--11-42-52/0.
- RAV4: 2018-07-27--06-50-48/10, 2018-08-01--21-13-49/10.

기존 전문가 CAN 정렬/결측 결과를 재사용하고 이전과 같은 보수적 안정 구간 마스크를 적용했다. 새 4구간만 기존 10Hz 변환·모델 함수로 처리했다. 기존 5구간은 저장한 확률을 재사용했다. MIT comma.ai 2018 출처는 comma_cases.json에 보존했다.

## 안정 구간 결과

| 항목 | 기준 | 후보 |
|---|---:|---:|
| 추가4구간 1,199시각 Macro F1 | 0.704199 | 0.706075 |
| 정답 수 | 1,122 | 1,130 |
| 등속 오류 | 76 | 68 |
| 가속↔감속 반전 | 0 | 0 |
| STOPPED recall | 1.0 | 1.0 |

오류12시각을 수정하고 정답4시각이 악화했다. 다른 오답으로 바뀐6시각도 있다. Civic 묶음 F1은0.726605→0.726319로 소폭 낮아졌다. 전체 평균 개선을 모든 차량의 개선이라고 해석하지 않는다.

클래스 분포: 등속884, 정지170, 가속144, 감속1. 감속과 급격한 전환 일반화에 매우 부족하다. 고정4클래스 Macro F1이므로 클래스가 없는 개별 구간 F1이 낮아지는 점에도 주의해야 한다. 연속시각1,199개는 독립1,199사건이 아니다.

## 전환 검사: 정밀 정답이 아닌 센서 대체 구간

기존5구간+추가4구간에서 총75개 전환 구간을 예측 전에 고정했다. 앞뒤에 각각5시각 이상 유효한 같은 센서 범주가 있고 그 사이 간격이2초 이내인 경우다. 경계는 구간으로 보존했으며 공식 CAN 범주/전환 시점 정답으로 표시하지 않았다.

예측에서는 이전 범주가3시각 지속된 뒤 새 범주가3시각 지속되는 첫 지점을 찾았다. 탐색은 센서상 직전/직후 범주의 연속 구간 안에서, 경계 주변 최대±2초로 제한한다. 검출 실패를 점수에서 숨기지 않고 별도 집계했다.

| 전체75개 전환의 교정된 진단 | 기준 | 후보 |
|---|---:|---:|
| 둘 다 검출한38개: 센서 구간 밖 평균 거리 | 0.1921초 | 0.2053초 |
| 전환 검출 실패 | 37 | 34 |

후보가 늦어진6건·빨라진12건·동일20건이다. 평균 부호 있는 시각 이동은−0.0289초여서 ‘평활이 전반적으로 늦어진다’는 결론은 아니다. 센서 구간 밖 거리가 평균0.0132초 증가했다는 수치는0.1초 샘플 해상도의 평균이며, 통계적 또는 실제 물리적 악화를 입증하지 않는다. 센서 지연·범주 기준도 미확정이다. 다만 사전에 고정한 비악화 조건은 통과하지 못했다.

추가4구간만 보면19전환 중 둘 다 검출7개이며 거리는0.3000→0.2857초, 실패12→10이다. 전체 전환 결과와 구분해서 기록한다.

## 채점 감사

초기 ±2초 검색이 인접한 다른 전환을 연결하는 오류를 발견했다. comma_04의7.2~7.7초 가속→등속 사건에 앞선5.5초의 실제 등속 구간을 매칭해, 후보가2.5초 앞당겨졌다고 계산했다. 원래 센서값을 확인해 다른 사건임을 확인했다.

후보 확률·정답 구간은 바꾸지 않고 탐색을 각 사건의 직전/직후 연속 범주 구간으로 제한했다. 이 인접 사건 오매칭을 방지하는 회귀 검사와 미검출 검사가 통과했다. 초기 `report.json`의 전환 수치와 판정 대신 **transition_scoring_audit.json** 및 **transitions_corrected.json**을 사용한다. 초기 결과는 감사용으로 보존했고 안정구간 점수는 수정되지 않았다. 교정 후에도 전환 거리 비악화 조건은 미통과다.

## 다음 행동

이번 후보의 기본 적용은 보류한다. 임의로 창 크기를 바꿔 재시도하지 않는다. 다음 검증이 필요하다면 감속과 가감속 전환을 충분히 포함하는 기존 주행 구간을 먼저 확보하고, 센서 전환 기준/시계 오차를 확인해야 한다. 장시간 지속되는 등속 오인은 앞선 검사에서도 해결되지 않았으므로, 기본 모델의 광류·주변 객체 문맥을 별도로 진단하는 것이 다음 개선 과제다. 추가 데이터 전체 다운로드는 필요하다고 판정하지 않았다.

## 주요 산출물

- freeze.json / execution_freeze.json: 사전 선정·후보·검사 규칙·해시.
- comma_cases.json / *_labels.npz: 추가4구간과 안정구간 정답 마스크.
- report.json: 안정구간별 결과(전환 항목은 아래 교정본으로 대체).
- transition_scoring_audit.json / transitions_corrected.json: 최종 전환 결과와 오류 수정 근거.
- predictions.csv / scored_rows.csv / changed_rows.csv / *_probabilities.npz: 예측·변화·확률.
- prepare.py → prepare_video.py → run.py → audit_transitions.py: 기존 도구를 사용한 재현 순서. 새 출력 폴더에서 실행한다.
