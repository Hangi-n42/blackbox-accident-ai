# 다음 개선 후보: 학습 전용 공간 영역 가림 증강 1개

판정: 실행 가능한 저비용 **미검증 가설**로 선정. 이번 작업에서는 학습·채택하지 않았다. 최신 관찰에서 최적 방법임이 증명된 것은 아니다.

## 오류와 연결

완전6초 센서 이력을 맞춘 뒤에도 등속 오답이 comma/ZOD 양쪽에 남았다. 고정 영역의 장면 구성과 화면 움직임은 실제 가감속과 일대일 대응하지 않는다. 기존 모델에서 영역 하나의 표준화 특징을 중립값으로 바꾸면 오답 복구와 정상 정답 손상이 모두 발생한다. 이는 특정 ROI를 영구 제거할 근거가 아니며, 영역별 단서에 대한 민감성을 확인한 것이다.

가설: **학습에서 특정 위치의 단서가 없어도 정답을 맞추도록 하면, 국소적인 차량·배경 변화에 대한 의존을 줄일 수 있는가?** 실제 객체 제거가 아닌 특징 수준의 증강이다. 장면 변화·회전·원근 문제를 물리적으로 해결했다는 주장은 하지 않는다.

## 평가 전에 고정할 단일 설정

- 기준: 기존 comma2,395 학습 시각 및 공개 영상별 OOF의 나머지40정답. 기존 날짜 분할별 학습 목록·정답·가중치를 각각 그대로 사용. ZOD 혼합은 이번 후보에 추가하지 않는다.
- 특징 추출기: 기존 DIS864 유지. 새 영상 추출 없음. 조향 고정.
- scaler: 각 기준 학습 fold의 기존 comma scaler를 고정. 평가 자료 및 증강 자료로 재적합하지 않는다.
- 분류기: 기존 LogisticRegression(C=.03,class_weight=balanced,max_iter=2000,random_state=42) 동일. 계수만 학습한다.
- 각 학습 표본마다 원래 표준화 벡터1개와 가림 벡터12개를 구성한다. 가림 벡터 하나는 ROI 하나의 모든6시간블록×4채널×3통계=72차원만0으로 만든다. 표준화0은 학습 평균이며 광류0이나 정지 영상이라는 의미가 아니다.
- 원본 표본의 기존 sample_weight를 w라고 할 때 원본에0.5w,12개 가림 표본에 각각w/24를 부여한다. 합계w 보존. 모든 범주를 같은13배로 복제하므로 balanced 범주 계수도 유지되는지 실제 실행 때 확인한다. 총 손실량·범주별 유효 가중치 일치 검사를 포함한다.
- 50% 비중은 근거가 확정된 최적값이 아니라 **한 번만 시험할 설정**이다. 결과를 보고 비중·ROI·C를 탐색하지 않는다. 무작위 ROI 선택 없이12개 전부 동일 가중치이므로 추가 seed 탐색 없음.
- 추론에는 원래864특징만 넣는다. 가림·앙상블·센서 입력·기존 모델 덮어쓰기 없음.

## 비교와 판단

1. 저장 기준 예측과 재현 일치 확인 후 후보 한 설정만 실행.
2. 공개50시각 OOF S3(기준0.808951), 가감속 범주별F1, 기존 comma 날짜/차량별F1, 기존 ZOD 개발 진단 성능을 병기한다. 과거 운영 모델 점수와 같은 실험처럼 비교하지 않는다.
3. 새 A↔D 반전, 기존 반전의 올바른 복구, 반전→등속 오답, 등속→가감속/정지 오답을 각각 집계한다. 이번 등속 오류만 좋아지고 가속·감속이 악화되는지 확인한다.
4. 이득 확인 기준은 공개 S3 상승, 날짜별 가감속 Macro-F1 하락 없음, 각 진단 묶음의 새 반전0을 함께 통과하는 것이다. S3 상승과 엄격한 위험 조건 통과 여부는 별도로 보고한다. 독립/private 성능 개선이라고 부르지 않는다.
5. 실패하면 같은 공개50정답으로 가림 비중이나 영역을 바꿔 반복 탐색하지 않는다. 운영 모델 유지. 통과 시에만 아직 개발에 쓰지 않은 예약 원천18창을 다음 확인 대상으로 검토한다.

## 한계와 중단 근거

- 고정 ROI들은 겹치므로 하나를 가려도 다른 ROI에 같은 물체가 남을 수 있다. 진짜 독립 객체 가림이 아니다.
- 평균값 치환 벡터가 물리적으로 가능한 영상에 대응한다고 보장할 수 없다. 정상 감속 단서도 약해져 가감속 F1·반전이 악화될 수 있다.
- ZOD C03은12개의 단일 영역 중립화 어느 것도 중심11시각의 등속을 복구하지 못했다. 여러 영역의 변화나 표현 자체의 한계는 이 증강으로 해결되지 않을 수 있다.
- 이번 완전6초 비교에는 가속0쌍, 감속1원천만 있다. 반전 감소 효과를 사전 보장할 근거가 없다.
- 과거 고정 차체/공간 마스킹과 긴 차분144차원 영구 제거는 실패했다. 이번 후보는 **모든 위치를 균등하게 학습 중에만 가리고 추론 특징을 유지하는 단일 학습 정책**이라는 차이가 있지만, 이 차이가 성능 향상을 보장하지 않는다.
