# 확대 기준의 긴 시간 차분 제외 대조 실험

실행 exit0. **후보 미채택, 기존 운영 모델 유지.** 전문가 에이전트가 특징 선택·학습 분리·대조군 재현·결론을 읽기 전용 검토했고 결론을 뒤집을 오류는 발견하지 않았다.

## 수행

기존 예측으로23구간의 지원 수·혼동·범주별 recall·등속 오류 연속구간을 저장하고 비교 규칙을 후보 학습 전에 고정했다. 기존864특징의 마지막144열(15점 평균의 ±15 차분)만 제외한720특징을 비교했다. 원시 광류·평균·짧은 차분·공간 ROI·라벨·모델 설정·학습 시각은 유지했다. 캐시 재사용이며 새 영상 특징 추출/다운로드 없다.

주 방향 RAV4437학습/Civic3246평가, 역방향 Civic646학습/RAV42204평가. 양방향 대조군864/후보720 총4개 실험 체크포인트를 학습했다. 두 대조군은 기존 확대 기준의 전체23구간 예측과 일치했다. 공개50정답은 학습하지 않았다. 양방향 공개 결과는 동일50정답에 대한 두 모델의 결과이지 독립100정답이 아니다.

## 해석과 다음 행동

오답의 큰 기여 특징이라고 해서 제거하면 좋아지는 것은 아니었다. 이번 결과는 **현재 확대 학습 조건에서 긴 차분 묶음을 통째로 제거할 근거가 없다**는 결론이다. 다른 시간 특징 가능성 전체를 부정하지 않는다. 같은 개발 자료에서 추가 시간창 후보를 연속 탐색하지 않는다. 차량·촬영환경·범주분포가 함께 다른 일반화 문제와 데이터 공백을 먼저 좁힌다.

대체 정답은13787중5450명확 시각만 남긴 센서 시험 기준이다. 미선택 구간·독립 차량·대회 전체 점수로 일반화하지 않는다. 운영 모델·조향·원본 라벨 해시 보존 검사를 통과했다.
