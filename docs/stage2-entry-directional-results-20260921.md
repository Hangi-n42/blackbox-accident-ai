# Stage2: 00000의 f561 선택 방향에 대한 손실·규제 분해

**현재 가중치의 이 방향에서는 규제가 방해 요인이 아니다.** L2는 f561−f0 점수 차이를 개선하는 방향을 돕고, 시작부터 진입한 00003·00006의 비교 손실이 반대한다. 00000 자신의 손실과 00013의 손실은 사고별 합계로는 이 방향을 돕는다. 이 결과는 현재 목적함수 안의 국소적 상충을 보여주며, 두 시작 전 진입 사례를 틀려야만 00000을 맞힐 수 있다는 뜻은 아니다.

## 실행 범위와 수식

Mac에서 기존 λ=.1 모델, 14개 표준화 특징, 후보·참조, 53개 비교 쌍과 사고별 동일 가중치를 고정했다. 가중치 업데이트·추가 학습·λ 시험·영상 모델 호출·CCD 접근·제출 코드 변경은 모두 0이다.

방향은 `d = (x_00000,f561 − x_00000,f0) / ||x_00000,f561 − x_00000,f0||`로 정의했다. `w + εd`라는 방향의 미분만 계산했으며, 실제 가중치를 이동하거나 그 모델을 평가하지 않았다. 현재 f561−f0 점수 차이는 −1.505019이고, 이 차이의 +d 방향 미분은 +4.663041이므로 양의 작은 이동은 해당 두 후보 사이의 점수 차이를 개선한다.

각 참조 선호쌍에서 `D = x_선호후보 − x_비교후보`, 현재 margin=`D·w`다. 해당 사고의 비교 수를 n이라 하면 pair gradient는 `−D × sigmoid(−D·w) / (4n)`이다. 규제 gradient는 `.1w`다. 각각 d와 내적하여 방향미분을 구했다.

- 음수: +d 방향으로 작게 움직이면 해당 손실이 감소한다. 해당 항은 이 방향을 돕는다.
- 양수: 같은 방향으로 움직이면 해당 손실이 증가한다. 해당 항은 이 방향에 반대한다.
- 결과 JSON의 `winner`/`loser`는 **약한 참조상 선호하는 쪽/비교 대상**이다. 현재 모델의 실제 점수 승자를 뜻하지 않는다.

## 사고·규제별 결과

| 항 | 방향미분 | 이 방향에 대한 작용 |
|---|---:|---|
| 00000의 11개 비교 손실 | −0.104091688 | 도움 |
| 00003의 11개 비교 손실 | +0.057103190 | 반대 |
| 00006의 11개 비교 손실 | +0.117838816 | 반대 |
| 00013의 20개 비교 손실 | −0.038574834 | 도움 |
| 데이터 손실 합계 | +0.032275484 | 반대 |
| L2 규제 | −0.032275475 | 도움 |
| 전체 목적함수 | +0.00000000933 | 수치적으로 거의 0 |

수치는 표준화된 특징 공간의 단위 가중치 이동에 대한 손실 변화율이다. 정확도·초·점수 확률 단위가 아니다.

전체 합이 거의 0인 것은 이미 수렴한 모델에서 예상되는 결과다. 의미 있는 관측은 구성이다. 00003·00006의 반대 압력 합은 +0.174942007이며, 다른 두 사고와 규제가 이를 거의 상쇄한다. 전체 gradient L2는 약 9.19e-8이고 원 학습 목적함수 gradient와 재계산 결과가 일치한다.

L2의 부호는 직접 확인할 수도 있다. `.1w·d = .1 × 현재(f561−f0 margin) / ||x_f561−x_f0||`이며 현재 margin이 음수이므로 이 방향의 규제 미분도 음수다. 따라서 이 결과를 규제 제거·완화가 해당 방향을 더 돕는다는 근거로 사용할 수 없다. λ를 바꿔 재학습한 새 최적점이 어디로 움직이는지까지 결정하는 분석은 아니다.

## 개별 비교가 보여주는 내용

00000의 직접적인 `f561 > f0` 비교는 방향미분 **−0.086724275**로, 해당 순위 개선을 분명히 돕는다. 하지만 00000의 다른 비교가 전부 같은 방향을 원하는 것은 아니다.

| 사고 | 참조가 선호하는 비교 | 방향미분 |
|---|---|---:|
| 00000 | f561 > f748 | +0.006880193 |
| 00000 | f561 > f841 | +0.018322636 |
| 00000 | f561 > f1028 | +0.000521334 |

00000 안에서는 8개 비교가 돕고 3개가 반대한다. 현재 f561은 f841과 f1028에도 점수가 낮다. 따라서 f0와의 차이만 개선하는 방향이 f561을 최종 1위로 만든다고 가정할 수 없다.

00003·00006은 각각 11개 비교 **전부** 이 방향에 반대한다. 개별 최대 반대 항은 00006의 `f0 > f1089` 비교로 +0.035175871이다. 이는 해당 선호 비교의 logistic 손실이 국소적으로 증가한다는 뜻이지, 최종 선택이 즉시 오답으로 바뀐다는 뜻은 아니다. 00013은 12개 비교가 돕고 8개가 반대하지만 사고 합은 도움이다.

## 확인한 결론과 확인하지 못한 것

**확인한 것:** 현재 공유 선형 모델과 53쌍 목적함수에서는, 00000의 f561−f0 차이를 가장 직접적으로 높이는 이 방향이 다른 두 사고의 비교 손실과 충돌한다. 규제는 이 방향의 오히려 반대 압력을 상쇄한다. 추가 λ 완화만을 당연한 다음 해결책으로 선택할 근거는 얻지 못했다.

**확인하지 못한 것:** 이 상충이 피할 수 없는지, 어느 항을 바꾸면 전체 선택이 좋아지는지, 첫 후보 특징 제거 또는 다른 손실이 개선을 만드는지는 확인하지 못했다. 방향은 첫 후보 표시 계수만 바꾸는 방향이 아니라 다른 13개 특징의 계수도 함께 바꾸는 방향이다. 부호 분석을 특정 특징 하나의 인과 효과로 바꾸어 해석하지 않는다.

앞선 표현 가능성 진단에서는 동일 특징의 다른 가중치로 학습 4건의 적절한 후보를 동시에 1위에 둘 수 있었다. 따라서 이번 국소 상충을 모델 계열 전체의 표현 불가능이나 필연적인 두 사고의 희생으로 해석하면 그 결과와도 맞지 않는다.

후속 실험은 이번 진단에 포함하지 않았다. 53개 비교·4개 사고·규제 기여의 원자료를 보존했다.
