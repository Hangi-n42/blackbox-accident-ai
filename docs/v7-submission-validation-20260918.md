## 시간과 한계

Mac CPU 2스레드에서 모델 로딩·전처리를 포함한 실제 Stage1 함수의 공개 10영상 실행은 V6 5.391초, V7 7.377초였다. 추가 시간 1.986초, 관측 비율 1.37배다. Python 시작과 검증용 해시 계산을 포함한 전체 검사 프로세스 시간과는 구분한다.
