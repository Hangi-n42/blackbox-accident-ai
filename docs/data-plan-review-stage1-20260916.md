# Stage1 데이터 정제·활용 계획 전문가 검토

검토일: 2026-09-16. 검토 범위는 계획 타당성이다. 데이터 다운로드, 모델 학습, 성능 검증은 수행하지 않았다. ICL-COMMSP는 제외하며 VDmoire·UHDM의 이용 가능성은 사용자가 확정한 전제로 취급한다.

## 판정

**수정 조건부 통과.** VDmoire를 영상 재촬영 개발, UHDM을 공간 특징 보완에 사용하는 역할은 적절하다. 다만 모아레 제거용 정답을 대회 ORIGINAL로 일괄 대응시키지 않고, 원본 provenance·촬영/정렬 이력·분할 독립성을 먼저 검증해야 한다. 이 구성만으로 도로 영상 일반화 검증이 완료되지는 않는다.

## 확인한 근거

- VDmoire 공식 저장소는 290개 영상, 영상당 60프레임, 720p, 두 장비 조합을 명시한다. data_v1 homography 정렬, data_v2 optical-flow 보정, 별도 원래 모아레 영상을 제공한다. 시간·장비 다양성을 프레임 수로 과장하지 않는다. [공식 저장소](https://github.com/CVMI-Lab/VideoDemoireing)
- UHDM은 정지 이미지 쌍이므로 영상 시간 특징을 직접 제공하지 않는다. 로컬 선행 감사에 보존된 논문 검토는 인터넷 사진·생성 문서와 정렬 처리를 기록한다. [공식 저장소](https://github.com/CVMI-Lab/UHDM), [논문](https://arxiv.org/html/2207.09935v1)
- `research/v7/stage1_preprocessing_audit.md`는 현행 TPO 전체 프레임 224×224가 원저자 계약과 일치하며 forensic 경로는 원본 픽셀 간격 192 패치를 사용함을 확인했다. 따라서 새 고해상도 패치 비교를 TPO 전처리 버그 수정으로 설명해서는 안 된다.
- `HANDOFF.md`와 `docs/mac-improvement-priorities-20260916.md`에는 실제 도로–물리 재촬영 대응 검증의 공백이 기록돼 있다. 이번에는 새 파일 확보 여부를 전수 조사하지 않았다.

## 초안에 필요한 수정

1. **미확인 GT의 보조 사용도 자동 안전하지 않다.** source camera/원본 재생 파일 연결이 확인된 쌍만 hard label 분류용으로 사용한다. clean GT의 출처·보간 이력이 불명확하면 우선 격리한다. 부득이한 paired auxiliary도 분류 학습에서 제외한 별도 연구 후보로 기록한다. 상대적 pairwise 순위 역시 가공 경로를 학습할 수 있어 첫 실험에 도입하지 않는다.
2. **20 clips/100 pairs는 검수 예산이지 성능 판정 표본 수가 아니다.** 이 소규모 pilot에서는 포맷·원본 연결·정렬 흔적·메타데이터·시간 구조만 검사한다. 여기에 60/20/20을 기계적으로 적용해 4개 VDmoire 그룹으로 최종 성능을 판정하지 않는다. 학습 시작 전 충분한 독립 그룹을 확보하고 분할별 원본 수·장비 수·클래스 수를 보고한다. 결과 확인 후 분할을 다시 선택하지 않는다.
3. **분할 단위는 원본 클립보다 넓을 수 있다.** 동일 REDS/MOCA 원본 시퀀스의 다른 조각, 동일 콘텐츠를 다른 장비로 촬영한 영상, 정렬 v1/v2, 이미지/프레임/패치/압축 변형을 연결한 source group을 통째로 분리한다. SHA로 동일 파일을, 시각 유사도와 원본 ID로 파생 중복을 찾아 수동 확인한다. UHDM 공식 test는 학습으로 되돌리지 않고, 중복이 있으면 충돌 그룹을 격리한다.
4. **쌍에 동일 전처리를 해도 원래의 누출은 사라지지 않는다.** 원본별 해상도/코덱/테두리/검정 정렬 블록/흰 전환 프레임/보간 이력을 기록한다. 양쪽 동일 좌표·정책으로 화면 내부를 잘라내는 비교를 만들고, 테두리 포함·제외 결과를 함께 진단한다. 모든 자료를 강제 재인코딩해 맞추면 실제 재촬영 단서도 지워질 수 있으므로 원본 보관 후 통제 비교만 한다.
5. **시간 특징은 실제 촬영 시간과 전달 프레임을 구분한다.** VDmoire 원본 재촬영과 정렬 60프레임의 선택·시간 대응을 확인한다. 선택된 60프레임을 원래 연속 30fps 영상처럼 간주해 주사/플리커 주파수를 계산하지 않는다. PTS가 없으면 프레임 간 변동 통계로 제한하고 시간 단위 특징은 비활성화한다.
6. **기존 고정 특징을 우선 재사용한다.** 현행 TPO/forensic 특징과 영상별 평균·분산 등 단순 집계를 고정하고 가벼운 분류기를 비교한다. 첫 단계에 새 동영상 백본, demoiré 복원 모델, 대형 학습 파이프라인을 추가하지 않는다. UHDM 패치가 수량으로 지배하지 않도록 source group 기준 샘플링·가중치를 적용한다.

## 권장 실행안

### 정제 pilot

- 제안 예산: VDmoire 최대 20개 독립 source clip, UHDM 최대 100개 독립 사진 source pair. 장비·출처가 식별되면 다양하게 표집한다. 수량은 현재 확보 사실이 아니다.
- manifest: dataset/version/source_group/pair_id/device/raw_or_aligned/time_source/content_type/label_evidence/hash/split/rejection_reason.
- 사진/문서 분리, 원본 provenance 확인, 재촬영 실제 여부, decode 성공·프레임 매칭·시간 단조성·시각 중복·정렬 흔적 확인.
- 통과 자료만 확대 대상으로 남긴다. 확인 불가 자료는 임의 ORIGINAL 라벨을 주지 않고 격리한다.

### 학습·개발

- 개발할 후보는 둘뿐: A=검증된 VDmoire 쌍+현행 고정 특징, B=A+검증된 UHDM 사진 쌍의 패치 보조.
- 같은 source_group을 학습/개발/봉인검증에 나누지 않는다. 장비별 진단을 추가하되 두 장비 조합만으로 광범위한 장비 일반화를 증명하지 않는다.
- 모델/임계값/집계는 개발 자료에서만 선택한다. A/B 결과는 영상 단위 VDmoire와 이미지 단위 UHDM을 따로 보고하며 이미지와 프레임을 독립 영상 표본처럼 합산하지 않는다.
- 도로 외부 영상은 ORIGINAL만 대량 섞지 않는다. 도로 원본과 실제 화면 재촬영 대응쌍이 확보되면 둘을 동일 그룹으로 묶어 별도 도메인 검증에 사용한다. ICL 대체 독립 검증이 자동 확보됐다고 부르지 않는다.

## 통과 기준

- 데이터 gate: 포함되는 모든 샘플의 source_group·분할·label_evidence가 존재하고 미해결 분할 간 중복이 0건이다. 파일/시간/쌍 계약 실패 자료는 격리되어야 한다.
- 실험 gate: 기존 기준과 A/B를 같은 봉인 자료에서 비교하고 영상 단위 Macro F1, 양 클래스 recall, 원본 그룹 수, 장비별 결과와 source-group 단위 불확실성을 보고한다. 미리 정한 실용적 개선 폭 및 비열화 허용치를 샘플 수와 함께 확정한다. 표본을 보지 않은 상태에서 유의한 개선 수치를 보장하지 않는다.
- 채택 gate: UHDM 추가가 개발/봉인 자료에서 일관된 이득을 보이고 특정 장비·클래스의 중대한 하락이 없을 때만 유지한다. 작은 표본으로 불확실성을 줄이지 못하면 판정은 보류다.
- 제출/generalization gate: 실제 도로 재촬영 대응 검증이 없으면 외부 데이터 개발 후보까지만 승인한다. 높은 이미지/일반 영상 점수를 도로 대회 성능 향상으로 표현하지 않는다.
