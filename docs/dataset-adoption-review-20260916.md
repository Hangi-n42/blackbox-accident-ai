# 외부 데이터 도입 통합 검토 — 2026-09-16

## 범위와 결론

Stage별 검토 에이전트 3개가 핵심 선정 자료 8개를 나누어 공식 배포처·논문·주석 구조·데이터 라이선스를 조사했다. 총괄은 현 대회 규칙·수상 동의사항과 대조했다. 제안문에 열거된 모든 보류·탈락 대체 후보를 재평가한 보고서는 아니다. 새 데이터 다운로드, 접근 약관 동의, 권리자 연락, 학습, 조합별 성능 측정은 하지 않았다.

제안의 역할 분담은 대체로 타당하지만 세 Stage 모두 곧바로 제출용 조합으로 확정할 근거는 부족하다. Nexar와 comma2k19는 우선 유지/소규모 사용의 근거가 가장 명확하다. PREVENTION은 보조 과제에 조건부 적합하고 필수 자료라고 입증된 것은 아니다. ADAS-TO는 접근·이용 조건을 먼저 확인해야 한다. ZOD는 별도 센서 기반 검증에 적합하다. Stage1 세 자료는 데이터 자체 이용허락 범위와 원본의 의미가 남아 있어 도입 확정을 보류한다.

## 선정 논리의 주요 수정

1. **Stage1의 demoiré 정답은 ORIGINAL 정답과 동일하지 않다.** VDmoire는 REDS/MOCA/자체 영상, UHDM은 인터넷 이미지와 생성 문서를 포함한다. 정렬/보간 흔적을 촬영 여부 대신 학습할 수 있으므로 비정렬 자료와 원천 분리가 중요하다. ICL은 모아레가 약한 재촬영 진단에 유용하지만 도로 동영상 검증을 대신하지 못한다.
2. **Stage2는 여전히 대회 정의 재주석이 핵심이다.** Nexar event에는 near-miss가 포함되고 test는 사건 전에 종료된다. PREVENTION f1은 차량 뒤쪽 중앙과 차선의 관계이며 첫 바퀴 접촉이 아니다. 자동/반자동 주석을 전부 수동 GT로 간주할 수 없다. 두 자료 모두 대회와 같은 회피 공간 GT는 확인되지 않았다.
3. **Stage3 결합 가능성과 정답 일치는 별개다.** 센서로 대체 범주를 만들 수 있으나 대회 임계값은 비공개다. 실제 상태와 목표/명령, 단위·부호·시계·필터 지연을 구분해야 한다. 센서는 추론 입력에 넣지 않는다. ADAS-TO 현재 HF는 179차종/16,446클립으로 GitHub 163차종/15,705클립과 다르다. 배포 revision 고정이 필요하다.

## 대회 규칙과 이용 조건의 교차 검토

[현재 공식 규칙](https://dacon.io/competitions/official/236753/overview/rules)은 누구나 접근 가능한 공개 자원이고 최소 비영리 이용이 허용되면 활용 가능하되 참가자가 개별 조건을 준수하도록 한다. 따라서 NC 자체를 대회 금지라고 해석하지 않는다. ADAS-TO의 수동 승인 접근이 이 공개 자원 기준을 충족하는지는 운영진 확인이 필요하다.

[동의사항 A 및 B10](https://dacon.io/competitions/official/236753/overview/agreement)은 수상 산출물의 저작권·2차적 저작물작성권 독점 귀속과 필요한 권리 부여를 요구한다. 참가자가 갖고 있지 않은 외부 데이터 권리를 새로 양도할 수 있다는 의미는 아니다. 외부 자료/가중치에 남는 제3자 조건을 어떻게 제외·유지하는지 확인해야 한다. 모든 외부 데이터가 금지된다는 결론은 아니다.

[CC 공식 FAQ](https://creativecommons.org/faq/#does-my-use-violate-the-noncommercial-clause-of-the-licenses)는 NC 판단을 주된 이용 목적과 상황에 연결한다. 상금 존재만으로 모든 이용을 자동 금지하거나, 대회 참가라는 이유만으로 자동 허용한다고 단정하지 않는다. [CC의 AI 학습 안내](https://creativecommons.org/using-cc-licensed-works-for-ai-training-2/)도 보수적 준수 권고와 법적 적용 판단을 구분한다. SA가 모든 학습 가중치에 자동 적용된다고도, 항상 면제된다고도 확정할 수 없다. 원본/가공 데이터를 공유하는 경우의 명시적 의무와 가중치 권리 판단은 나누어 기록한다.

대회 규칙에는 학습 데이터 제출 요구가 있다. 로컬 통합 문서는 재배포 제한 자료의 출처·취득경로·라이선스·사용범위·제한사유 기재 대안을 기록하고 있으나, 해당 개별 Q&A의 현재 원문은 이번 조사에서 재확인하지 못했다. 실제 제출 전에 그 예외와 대상 자료 범위를 재확인한다.

## 외부 문의가 필요한 정확한 항목 — 아직 발송하지 않음

### VDmoire/UHDM/ICL 배포자

공식 배포 이미지/영상 자체에 적용되는 라이선스와 제3자 원본 권리를 확인할 수 있는 문서를 요청한다. 이 대회의 상금, 모델 학습, 제출 가중치, 검증용 원본/전처리 자료 제공, 수상작 권리 이전 조건을 함께 설명한다. 코드 LICENSE나 인용 요청만으로 데이터 허락을 대신하지 않는다.

### PREVENTION/ADAS-TO 배포자

상금이 있는 공개 AI 대회 연구 및 학습 가중치의 평가기관 제출이 허용되는지, 수상 후 산출물 이용 범위에 별도 허락이 필요한지 확인한다. ADAS-TO는 추가 접근 약정과 신청 자격 제한도 확인한다. 원본과 전처리 자료를 평가기관에 제공할 수 있는지도 구분한다.

### DACON 운영진

1. 수동 승인 접근이 필요한 ADAS-TO가 누구나 접근 가능한 공개 자원 요건을 충족하는가?
2. NC/SA/custom 자료를 적법하게 사용했을 때, 수상작 독점 권리 귀속에서 제3자 원본 자료와 그 고지/권리 조건은 어떻게 제외 또는 유지되는가?
3. 원본 데이터 재배포에 제한이 있는 경우 출처·라이선스·취득/재현 절차로 대신하는 제출 방식이 해당 자료에도 인정되는가?

이는 사용자 승인 질문이나 신규 허가 획득 결과가 아니라, 공개 문서로 확정하지 못한 사항을 해결할 문의안이다. 이번 작업에서는 계정 정보 공유·약관 수락·외부 전송을 하지 않았다.

## 권장 순서

1. 이미 있는 Nexar/ comma2k19에서 미사용 원천과 주행 단위 분할을 먼저 확정한다. 기존 개발 9건은 새 독립 검증으로 재명명하지 않는다.
2. Nexar의 실제 자차 접촉 사례를 대회 네 항목으로 검수한다. PREVENTION 추가만으로 이 작업을 대체할 수 없다.
3. Stage1 데이터 이용허락을 정리하고 도로 원본–실제 재촬영 대응 검증을 확보한다. 그 후 VDmoire/UHDM 작은 표본의 가공 흔적·출처 누출을 검사한다.
4. ADAS-TO 접근/제출 조건 확인 후 특정 소량 클립의 영상·상태 신호만 검사하고, ZOD는 독립 검증 역할을 유지한다. 전체 센서/전체 데이터 다운로드가 선행 조건은 아니다.
