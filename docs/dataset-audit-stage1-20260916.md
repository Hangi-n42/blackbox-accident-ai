# Stage1 데이터 적합성·이용 조건 검토

검토일: 2026-09-16. 공식 저장소·프로젝트 페이지·원 논문·공식 배포 페이지를 확인했다. 실제 데이터 파일 다운로드·전수검사·학습·외부 연락은 하지 않았다. 아래 기술적 판단은 문서 기반이며 성능 향상이 검증됐다는 뜻이 아니다.

## 결론

| 자료 | 기술적 판정 | 권장 역할 | 제출용 데이터 이용 판정 |
|---|---|---|---|
| VDmoire | 조건부 적합 | 실제 화면 재촬영의 공간·시간 특징 개발 | 보류: 외부 데이터 자체의 라이선스 적용 범위 미확정 |
| UHDM | 조건부 적합 | 고해상도 재촬영 흔적 보조 학습 | 보류: 외부 데이터 라이선스 및 원본 콘텐츠 권리 미확정 |
| ICL-COMMSP | 목적 직접 부합, 영상 과제에는 부분적 | 모아레가 약한 재촬영에 대한 별도 이미지 진단 | 보류: 인용 요청은 있지만 명시적 데이터 이용허락 범위 미확정 |

세 자료를 바로 Stage1의 완성된 주 학습·독립 검증 구성으로 확정하는 것은 근거가 부족하다. 권리가 정리되면 작은 표본을 검사할 기술적 이유는 충분하다. 현재 공개 문서만으로는 세 자료를 사용한 모델의 대회 제출·가중치 배포까지 허용됐다고 확정할 수 없다. 반대로 금지됐다고 확정한 것도 아니다.

## 대회 정의와 적합성

로컬 `대회_통합_정보.md` 34–40행은 별도 촬영기기로 재생 화면을 다시 찍은 영상을 RERECORDED로 정의한다. 단순 화면 녹화는 같은 의미가 아니다. 영상당 이진 분류이며 모아레 외에도 반사·색·압축·원근·기기 움직임 등 여러 단서를 열거한다.

### VDmoire

공식 자료에서 290개, 각 60프레임, 720p를 확인했다. TCL20 pro + Huipu v270, iPhoneXR + MacBook Pro의 두 장비 조합이다. data_v1은 homography 정렬, data_v2는 RAFT optical flow 추가 보정이며 원래 모아레 영상도 별도 제공한다. 원문 짧은 인용: “we also provide the original moire videos.” [공식 저장소](https://github.com/CVMI-Lab/VideoDemoireing), [프로젝트 설명](https://daipengwa.github.io/VDmoire_ProjectPage/).

논문 §4는 원본을 REDS·MOCA·자체 촬영 영상에서 가져왔다고 명시한다. 원본 재생 10fps/카메라 30fps이며 세 프레임 중 가운데를 선택한다. 정렬용 검정 블록과 시작·끝 흰 프레임도 촬영 절차에 사용한다. 원본 60프레임과 재촬영 180프레임을 혼동하면 안 된다. [원 논문 §4](https://arxiv.org/pdf/2204.02957.pdf).

판정: 실제 재촬영이라는 생성 원리는 일치한다. 다만 모아레 제거용 정렬 쌍을 그대로 분류 학습에 넣으면 보정·보간 흔적을 구분할 위험이 있다. 290개는 장비 290종이 아니다. 도로 영상·장비 일반화 근거는 아직 없다. 원본 클립 단위로 모든 파생 프레임/장비 변형을 묶어 분리하고, 가능하면 비정렬 원본 재촬영을 우선 검사해야 한다.

### UHDM

5,000쌍, 공식 4,500/500 분할, 실제 화면 촬영이라는 설명을 확인했다. 논문 §3.1의 GT는 인터넷에서 수집한 4K–8K 이미지와 직접 생성한 문서 이미지다. 세 휴대전화·세 화면을 사용하며 RANSAC homography 정렬과 수동 선별을 수행한다. 이미지 해상도는 4032×3024 또는 4624×3472이고 벤치마크는 3840×2160 중앙 자르기다. 따라서 모든 GT를 가공 없는 블랙박스 원본 또는 일반 카메라 원본으로 간주할 수 없다. [공식 논문 §3.1 및 §5](https://arxiv.org/html/2207.09935v1), [공식 프로젝트](https://xinyu-andy.github.io/uhdm-page/).

판정: 국소 재촬영 흔적 보조 학습에는 타당하다. 정지 이미지이므로 시간적 주사·플리커·카메라 흔들림 학습 자료는 아니다. GT 문서/인터넷 이미지와 촬영본을 곧바로 이진 클래스에 대응시키면 가공 경로와 출처가 정답을 대신하는 문제가 생길 수 있다. 동일 원본 그룹 분리 여부는 실제 파일·메타데이터 검사 전 확인 불가다. 고해상도라는 이유만으로 FHDMi보다 대회 성능이 우수하다고 단정할 수 없다.

### ICL-COMMSP

공식 페이지는 Single-Capture and Recaptured Image Database를 제공하며 100장/66.8MB 표본과 약 8GB 전체 자료를 표시한다. 전체 링크는 원본 3GB, 재촬영 5GB다. 표본의 정답 페이지는 이번 조회에서 타임아웃이므로 실제 접근 성공까지 검증한 것은 아니다. [공식 배포처](https://www.commsp.ee.ic.ac.uk/~pld/research/Rewind/Recapture/).

논문은 눈에 띄는 aliasing을 억제한 고품질 재촬영 자료라고 설명한다. 따라서 모아레가 없으면 ORIGINAL로 오판하는지 검사하기에 적합하다. 논문의 900 원본/1,440 재촬영은 평가 부분이며 전체 규모와 혼동하면 안 된다. 100장 주관평가 표본은 동일 크기 조정·Exif 제거를 했다. [원 논문 §V–VI](https://www.commsp.ee.ic.ac.uk/~pld/publications/IEEETransactionsINFS_THT_HM_PLD15.pdf).

판정: 이진 과제의 의미는 세 자료 중 가장 직접적이다. 다만 이미지 진단이며 도로 동영상에 대한 독립 평가를 대신하지 못한다. 여기서 모델/임계값을 선택하기 시작하면 최종 독립 검증이 아니라 개발 자료로 표기해야 한다.

## 이용 조건 조사

| 자료 | 확인된 내용 | 확인되지 않은 내용 |
|---|---|---|
| VDmoire | GitHub LICENSE는 Apache-2.0; 원본/정렬 데이터는 외부 Dropbox 링크 | 외부 아카이브도 Apache 대상인지, REDS·MOCA 원본의 별도 권리, 데이터 재배포/상업 이용/학습 가중치 배포 조건 |
| UHDM | GitHub LICENSE.md는 Apache-2.0; README는 새 모델 학습·평가 용도로 데이터 제공을 설명 | Drive 데이터의 정확한 라이선스, 인터넷 원본 이미지의 권리 처리, 데이터 재배포/상업 이용/가중치 제출 범위 |
| ICL-COMMSP | 데이터·소프트웨어 사용 시 두 논문 인용 요청 | 명시적 비영리 허용 라이선스, 재배포, 대회 학습, 가중치 공개·상업 이용 조건 |

VDmoire [LICENSE](https://github.com/CVMI-Lab/VideoDemoireing/blob/main/LICENSE), UHDM [LICENSE.md](https://github.com/CVMI-Lab/UHDM/blob/main/LICENSE.md)는 Apache-2.0 표준 본문이다. 외부 데이터 아카이브에 같은 허락이 적용된다는 명시적 연결은 확인하지 못했다. 저장소 코드 라이선스를 외부 이미지·영상에 자동 확장하지 않는다. Apache 대상 코드를 배포한다면 라이선스·고지 보존 및 수정 표시 등 조건을 준수해야 한다.

ICL 공식 페이지의 짧은 인용: “If you use this database or the software we request that you cite the following papers”. 인용 요청만으로 광범위한 이용·재배포 허락을 대신할 수 없다. 아카이브 내부 약관은 다운로드하지 않았으므로 미확인이다.

## 실행 가능한 다음 판단

1. 배포자에게 데이터 자체에 적용되는 라이선스와 원본 콘텐츠 권리 범위를 확인하고, 공개 대회 학습·가중치 제출/공개·대회 후 이용을 각각 구분한다. 이 검토에서는 연락을 보내지 않았다.
2. 권리 확인 후 원본/재촬영/정렬 전후 작은 표본을 열어 출처·해상도·코덱·색공간·보간 흔적이 정답과 결합하는지 검사한다.
3. 동일 원본 클립/이미지와 그 모든 파생본을 같은 분할에 둔다. 출처와 장비를 분리한 평가도 병행한다.
4. 세 자료를 보조 자료로 취급하고, 권리가 정리된 도로 원본과 실제 별도 기기 재촬영의 대응 영상 검증 세트를 별도로 확보한다. 이 검증 없이 '도로 재촬영 성능 향상'을 주장하지 않는다.
