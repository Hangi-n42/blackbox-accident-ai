# Stage2 학습형 진입 후보 선택기 파일럿

상태: Mac 특징 추출·실제 학습 1회·CCD 평가 완료. 사전 개발 기준 실패로 후보 미채택. 독립 수치 검증 PASS, 전문가 사후 검토 완료.

## 목적과 자료

직전 감사에서 CCD 8건의 진입 참조 구간이 기존 12개 후보까지 유지됐지만 최종 선택은 확정 정답 0·오답 7·불확정 1이었다. 자동 첫 프레임 보정도 8건 모두 OUTSIDE여서 개선하지 못했다. 이번에는 **후보 생성은 유지하고 후보 점수를 학습하는 작은 선택기** 하나를 검증한다.

기존 Nexar 사람 초안은 9건이다. 00004는 진입 미상이므로 유지하고, 시점이 적힌 8건을 AI 전문가가 재검수했다. 영상별 전체 구간에서 균등 48프레임, 진입·접촉 주변 시트, 필요한 원본을 확인했다. 전체 원본의 모든 프레임을 전수 관찰한 검수는 아니다. 새 사람 검수가 아니며 기존 사람 초안을 확정 GT로 승격하지 않았다.

최종 약한 학습 자료는 **4개 사고, 시작 전 2·영상 중 2건**이다. 영상당 확실한 후보 순위쌍은 61·66·66·65개, 합계 258개다. 258쌍은 독립 사고 258개가 아니다. 기존 CCD 8건은 학습·PCA·정규화·설정 선택에 넣지 않는 별도 개발 평가로 고정한다. 다만 이미 여러 실험에 노출된 AI 참조이므로 미노출 사람 평가나 공식 점수가 아니다. 공개 5건은 기존 접촉 회귀 용도를 유지하고 공개 사용자 초안을 추가 학습에 넣지 않았다.

## 고정한 변경과 평가

기존 1536×768 Q3 시트의 이미지와 12개 원본 후보 번호를 그대로 사용한다. 기존 Mac MLX Qwen3-VL의 시각 인코더를 동결하고 시트의 각 타일 영역을 평균낸 특징을 추출한다. 첫 32픽셀 행은 평균에서 제외한다. 이는 28픽셀 프레임 번호 헤더와 장면 4픽셀을 함께 제외하는 것이며, 전체 시트 attention을 통해 전달된 번호 정보를 제거했다는 뜻은 아니다. 타일 특징은 사고 상대 차량에만 해당하는 특징도 아니다.

학습 자료에서만 PCA 4차원을 맞춘 뒤 현재 특징·이전 후보와의 차이·다음 후보와의 차이, 상대 PTS와 첫 후보 여부를 사용한다. 총 **14개 특징의 공유 선형 점수**를 학습한다. PCA 투영도 학습 이미지에서 추정한 별도 전처리이며 14개만이 모든 데이터 의존 계수라는 뜻은 아니다. 시각 인코더·언어모델 가중치는 바꾸지 않는다. 초기 구현의 current-first 4개 특징은 선형 순위점수에서 current와 같은 정보를 중복하므로 실제 학습 전에 제거했다.

참조 구간의 **어느 실제 진입 시점을 택해도 A가 B보다 시점 오차가 작을 때만** A의 점수를 높이는 학습쌍을 사용한다. 정답이 후보에 없는 영상에서도 상대 오차 순위는 학습할 수 있으나, 가장 가까운 후보를 정답이라고 부르지 않는다. 구간의 중간점을 정답으로 만들지 않는다. 손실은 영상 안에서 평균한 뒤 4개 영상에 같은 가중치를 주고 L2=1을 적용한다. 0에서 시작하는 L-BFGS 학습 1회, 결과를 본 뒤 재학습하지 않는다.

선택은 기존 12개 후보 중 최고 점수이며 동점이면 먼저 나온 후보를 쓴다. entry_frame만 바꾸고 collision_frame·entry_side·evasion_space는 캐시 값을 보존한다. 이는 세 항목의 정확도나 동일 상대 의미의 일관성을 새로 확인하는 검증은 아니다.

비교 대상은 기존 Q3, 항상 첫 후보를 고르는 규칙, 학습 참조만으로 평균 최대 시점오차가 최소가 되는 고정 후보 위치 규칙이다. 마지막 두 규칙은 영상 특징 없이 얻는 단순 기준이며 평가 결과에 맞춰 선택하지 않는다.

사전 개발 신호 기준은 확정 개선 최소 1건, 가능한 정확도 손실 0, 영상 중 진입의 새 잘못된 f0 선택 0, 같은 참조 시점에서 계산한 평균 절대오차 변화 상한 ≤0, 다른 세 출력 보존이다. 통과해도 제출 채택 조건이 아니다. 별도 사람 참조와 실제 CUDA 경로 확인이 추가로 필요하다.

## 실행 결과

Mac에서 특징 추출 17회(서로 다른 시트 16개와 첫 시트 반복 1회), 실제 데이터 학습 1회, CCD 평가 1회를 완료했다. 언어모델 생성 질의는 0회다. 제외된 Nexar 4건도 고정 입력 추출 묶음에는 남았으나 학습·PCA·정규화에는 쓰지 않았다. 첫 시트의 반복 특징은 정확히 같았다.

학습은 9회 최적화 반복 후 정상 수렴했다. 정규화 포함 목적함수는 **0.693147 → 0.664474**, 최대 절대 gradient는 6.29×10⁻⁸이다. 이는 실제 가중치 학습이 실행됐다는 증거이며 시점 정답이 개선됐다는 증거가 아니다. **학습 4건의 최종 선택 자체도 모두 확정 오답**이었다. 학습 후보쌍 순위의 영상별 평균 정답률은 70.48%였지만, 최상위 후보 선택을 해결하지 못했다. 예를 들어 00003은 66쌍 중 59쌍의 순위를 맞혀도 f0 대신 f49를 선택했다. 선택한 후보의 최대오차는 같은 목록에서 가능한 최소 최대오차보다 각각 9.689·1.633·10.900·7.467초 컸다. 넓은 참조라 정밀 정답을 확정하기 어렵다는 이유만으로 이 차이를 설명할 수 없다. 최종 점수 가중치는 14개, 학습 PCA 투영 계수는 10,240개다. PCA는 학습된 시각 모델 전체를 미세조정한 것이 아니다.

학습 참조만으로 선택한 최선의 고정 후보 위치는 index0이었다. 따라서 두 단순 기준은 모두 항상 f0을 선택해 **정답 4·오답 4건**이다. 학습 선택기는 정확도 상한도 2/8이므로 이 단순 규칙보다 낮다. 단순 규칙도 영상 중 진입 4건을 모두 잘못 f0으로 바꾸므로 제출 개선안으로 채택하지 않는다.

## 원인 분석과 한계

확인된 실패는 올바른 후보가 남아 있는 상태에서도 728/540에서 더 이른 오답을 골랐고, 1237의 넓은 구간에서 정확도 손실 가능성을 만들었다는 것이다. 정상 수렴·입력 일치와 별개로, 이번 14가중치 선택기는 필요한 진입 선택을 해결하지 못했다. 선택값이 전부 f0은 아니므로 항상 첫 후보를 고르는 정책과 같지는 않지만, 그 단순 기준보다 나은 결과도 얻지 못했다.

왜 실패했는지는 다음 제약과 인과 추정을 구분해야 한다. 학습은 약한 참조 4건뿐이며 두 영상 중 진입 구간도 1초 이상으로 넓다. 특징은 상대 차량·바퀴·차로를 직접 추적한 것이 아니라 전체 시트의 시각 특징을 타일별 평균한 것이다. 학습 후보의 평균 시간 간격은 영상별 1.618–3.630초이고 CCD는 0.200–0.436초다. 같은 12개 후보라도 시간 간격과 장면 분포가 다르다.

이 때문에 참조 부족, 필요한 대상·경계 정보의 부족, 선형 점수의 표현 한계, 시간 간격·장면 차이에 따른 학습 전이 실패가 후속으로 검토할 가설이다. **이 실험 하나로 어느 가설이 원인인지 확정하지 않았다.** 더 오래 학습하거나 가중치 수만 늘리면 해결된다는 근거도 없다. 특히 상대 오식별과 차선 관계 오판을 이 전체 장면 특징만으로 구분할 수 없다.

기존 사람 초안 00007의 최초 진입 정의 오류를 발견한 것은 데이터 검수의 실질적 결과다. 이것을 제외했다는 사실이 나머지 4건을 사람 확정 정답으로 만든 것은 아니다. 독립 사람 평가·공식 S2·CUDA NF4 개선은 확인하지 않았으며 제출 코드는 바꾸지 않는다.

## 독립 검증과 후속 결정

독립 검증 **PASS(exit 0)**. 기존 2,056개를 포함한 동결 2,259파일이 유지됐다. 저장한 16개 시각 hidden을 12개 타일 특징으로 다시 평균한 결과가 정확히 일치했고, 실제 processor 해시도 기존 입력과 일치했다. 학습 4건에서만 계산한 PCA·정규화, 258쌍, 14가중치 목적함수와 gradient, 8건의 원본 번호 선택 및 구간 평가를 재계산했다. 검증 과정의 추가 encoder·생성·학습은 0회다. 검증기는 후보 동결 후 별도 파일로 작성했으며 SHA를 따로 기록했다.

특징 추출은 모델 로드를 포함해 15.541초, 최대 MLX 보고 메모리는 6.081GB였다. 실제 선택기 학습은 0.886초였다. 이 값은 캐시를 쓰는 Mac 파일럿 비용이며 제출 서버의 전체 네 출력 실행 시간·CUDA 메모리와 같지 않다.

현재 후보는 미채택하며 제출 코드는 유지한다. 결과 전문가는 **REJECT_CURRENT_RANKER_COMPLETE_PILOT**로 판정했다.

후속 우선순위는 **현재 특징과 공유 선형 점수로 학습 4건의 최상위 선택을 동시에 표현할 수 있는지 검사하는 train-only 진단**이다. 데이터 확대나 CCD에 대한 설정 조정보다 먼저 진행할 일이다. 현재 PCA·14차원 특징·참조·후보를 고정하고, 각 구간의 가능한 참조 시점에서 가장 가까울 수 있는 후보 집합을 만든다. 그 후보 중 하나가 최상위가 되는 공유 선형 부등식에 해가 있는지 확인한다. 여기의 후보 집합은 후보공간의 최선 집합이며 ±0.3초 실제 정답 집합이 아니다.

해가 있으면 현재 특징의 표현 가능성은 남아 있고, 지금의 정규화된 평균 순위 손실과 최상위 선택 사이의 불일치를 우선 검토할 근거가 된다. 그렇다고 L2만 원인이라는 뜻은 아니다. 모든 허용 최상위 조합에 해가 없으면 현 고정 특징·공유 선형 설계의 동시 fitting 제약을 확인한 것이다. 전체 후보쌍을 모두 만족할 수 없다는 사실과 최상위 하나를 맞출 수 없다는 사실도 구분해야 한다.

이 다음 진단은 아직 실행하지 않았다. CCD를 다시 보고 설정을 고르거나 LP 해를 새 성능으로 보고하지 않는다. 독립 사람 참조 확보 필요성도 여전히 남는다.
