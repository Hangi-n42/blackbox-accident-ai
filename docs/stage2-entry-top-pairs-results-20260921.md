# Stage2 53쌍 제한 학습 결과 — Mac, 학습 4건

**부분적인 선택 개선은 확인했지만, 전체 개선 성공으로 판정하지 않는다.** 적절한 후보 집합에 포함된 선택은 0/4에서 2/4로 늘었다. 시작부터 진입한 두 사례는 f0를 선택해 고정 참조 기준 ±0.3초를 충족했다. 그러나 영상 중 진입하는 두 사례의 시간 오차는 모두 악화했다. 네 사고의 실제 참조 시각을 동일하게 두고 비교하면 평균 절대 오차는 가능한 모든 참조 조합에서 **0.6124~1.4082초 증가**한다. 후보를 채택하거나 제출 모델을 교체하지 않았다.

이는 약한 학습 참조 4건에 대한 진단이다. 사람 초안을 AI 검수로 선별·확장한 참조 구간을 사용했으며, 새 사람 확정 정답이나 독립 평가 성능을 얻은 것이 아니다.

## 실행한 단일 변경

기존 확실한 시간오차 우위 쌍 P에서 `P_top = {(i,j) ∈ P : i ∈ M, j ∉ M}`만 남겼다. M은 고정된 참조 구간의 어느 시각에서든 12개 후보 중 최근접이 될 수 있는 후보 집합이다. 참조 구간 전체에서 우위가 확실한 기존 비교만 사용했다.

| 사고 | 적절한 후보 집합 M | 기존 비교 수 | 새 비교 수 |
|---|---|---:|---:|
| 00000 | f561 | 61 | 11 |
| 00003 | f0 | 66 | 11 |
| 00006 | f0 | 66 | 11 |
| 00013 | f545, f599 | 65 | 20 |
| 합계 | | 258 | 53 |

00013의 f545와 f599 사이에는 어느 방향의 순서도 강제하지 않았다. 특징·후보·PTS·참조·PCA·정규화·14개 선형 계수 구조와 L2 계수 1을 고정했다. 손실은 사고별 쌍 logistic 평균의 4사고 동일 가중 평균에 `0.5 × ||w||²`를 더한다.

기존과 같은 0 초기화 및 L-BFGS-B를 사용했다. 설정은 `maxiter=500, ftol=1e-12, gtol=1e-8, maxls=50, jac=True`다. Mac Darwin arm64, Python 3.12.14, NumPy 1.26.4, SciPy 1.17.1에서 1회 학습했고 exit 0으로 완료했다. PCA나 영상 특징은 다시 학습·추출하지 않았다. CCD 평가 0회, 후속 실험 0회다.

실행 전에 protocol과 입력·모델·코드 해시를 저장했다. 기존 모델 가중치나 앞선 선형계획 해를 초기값으로 사용하지 않았다.

## 사고별 선택과 오차

점수 차이는 `집합 안의 최고 점수 − 집합 밖의 최고 점수`다. 양수면 집합 안 후보가 1위이고, 음수면 집합 밖 후보가 1위다. 확률이나 시간 오차 단위가 아니다.

| 사고 | 기존 → 새 선택 | 집합 포함: 기존 → 새 | 점수 차이: 기존 → 새 | 절대 시간 오차 범위: 기존 → 새 |
|---|---|---|---|---|
| 00000 | f841 → f0 | 밖 → 밖 | −0.241505 → −0.998861 | 9.1003~10.6920초 → 18.4083~20.0000초 |
| 00003 | f49 → f0 | 밖 → 안 | −0.171097 → +1.027375 | 1.6333초 → 0초 |
| 00006 | f327 → f0 | 밖 → 안 | −0.095094 → +0.690117 | 10.9000초 → 0초 |
| 00013 | f327 → f109 | 밖 → 밖 | −0.548908 → −0.175378 | 7.6667~8.8667초 → 14.9333~16.1333초 |

00013은 집합 안팎의 점수 차이가 0에 가까워졌지만 선택 시각의 오차는 커졌다. 따라서 점수 차이 개선만으로 시간 선택 개선을 판정해서도 안 된다.

| 현재 고정 참조에 대한 ±0.3초 판정 | 기존 | 새 모델 |
|---|---:|---:|
| 구간 전체에서 충족 | 0 | 2 |
| 구간 전체에서 불충족 | 4 | 2 |
| 구간 내 실제 시각에 따라 달라짐 | 0 | 0 |

새로 충족한 두 건은 정확히 00003·00006이다. **집합 포함과 ±0.3초는 별개 지표다.** 이번 선택에서는 둘 다 2/4지만 일반적으로 같지 않다. 특히 00013의 M에 있는 f545는 참조 구간 어디에서도 ±0.3초를 충족하지 않는다. f599와 00000의 f561도 구간 일부에서만 충족할 수 있다.

각 사고에 같은 실제 진입 시각을 적용한 `새 절대 오차 − 기존 절대 오차`는 다음과 같다.

| 사고 | 가능한 오차 변화 |
|---|---|
| 00000 | +7.7163~+10.8997초 |
| 00003 | −1.6333초 |
| 00006 | −10.9000초 |
| 00013 | +7.2667초 |
| 사고 동일 가중 평균 | **+0.6124~+1.4082초** |

이는 서로 독립적으로 구한 old/new 오차 구간의 끝점을 빼서 만든 범위가 아니다. 사고마다 동일한 미상 참조 시각 T를 유지한 `|t_new−T|−|t_old−T|`의 최소·최대를 계산했다. 진입 시각의 확률 분포나 기대값을 가정하지 않았다.

## 수렴과 성공 판정을 구분

새 53쌍 목적함수는 0 초기화에서 0.69314718, 기존 가중치에서 0.71373408, 새 가중치에서 0.49457638이다. 새 모델의 53쌍 data loss는 0.40964189, L2 벌점은 0.08493449다. 비교 쌍 수가 다른 기존 258쌍 목적함수 값과 직접 비교해 개선이라고 주장하지 않는다.

9번 반복, 11번 함수 계산 후 상대 손실 감소 조건으로 종료했다. 최종 gradient L2는 약 3.40e-7이다. λ=1인 고정 특징 목적함수는 강볼록이며, 계산된 gradient를 사용한 최솟값 차이의 수치 상계는 약 5.78e-14다. 엄밀한 구간산술 인증은 아니지만 단순 미수렴이라는 설명을 지지하지 않는다. 손실 감소 자체를 성공 판정에 쓰지 않았다.

새 모델은 top 비교 쌍에서 사고별 7/11, 11/11, 11/11, 16/20의 양의 차이를 얻었다. 00013처럼 다수 비교가 맞아도 집합 밖 한 후보의 점수가 높으면 최종 선택은 실패한다. 이번 53쌍 목적도 모든 사고의 최종 1위 성공을 직접 강제하는 제약은 아니다.

## 원인: 확인된 사실

1. **비교 쌍 제한만으로 학습 해와 선택이 바뀌었다.** 나머지 조건을 고정한 대조에서 시작 전 진입 2건은 회복되고 영상 중 진입 2건은 악화했다. 따라서 이 자료에서 감독에 쓰는 비교 대상이 결과에 영향을 준다는 점은 확인됐다. 전체 시간 오차 개선은 달성하지 못했다.
2. **사고 간 가중치를 유지해도 특징별 학습 신호는 바뀌었다.** 00003·00006에서 f0를 다른 후보보다 높이는 쌍의 비중은 각각 11/66에서 11/11로 늘었다. 반대로 00000에서 f0보다 다른 후보를 높이는 쌍은 11/61에서 1/11, 00013에서는 11/65에서 2/20이 됐다. 0 초기값에서의 실제 gradient도 이 변화를 확인한다.
3. **00000의 새 오선택에는 첫 후보 표시 항의 수치적 기여가 명확하다.** 이 특징의 계수는 −0.018647에서 +0.285055로 바뀌었다. 새 모델에서 `f0 점수 − f561 점수`는 +0.998861이다. 그중 첫 후보 표시 항이 +1.031368, 나머지 항의 합은 −0.032507이다. 현재 두 후보의 점수 순서는 첫 후보 항이 뒤집는다. 이는 저장된 선형 점수의 산술 분해이며, 해당 특징을 제거하여 다시 학습한 인과 실험은 아니다.
4. **00013의 오선택은 첫 후보 표시만으로 설명되지 않는다.** 새 선택 f109와 집합 내 최고인 f545는 모두 첫 후보가 아니므로 그 항의 차이는 0이다. 전후 특징 차분 항은 각각 +0.180264, +0.149400을 기여하고, 영상 PCA 항 −0.122696 및 상대 시각 항 −0.031590을 합쳐 f109가 +0.175378 높아졌다. 이 계산은 어떤 항이 점수를 높였는지를 보여줄 뿐, 차량·차선의 의미를 학습했다는 증거는 아니다.
5. **원하는 4건 top-1을 표현할 수 있다는 앞선 결과와 이번 실패는 모순되지 않는다.** 앞선 진단은 적절한 후보 하나를 1위로 만드는 선형 가중치의 존재를 확인했다. 이번에는 53개 비교 손실과 L2를 함께 최소화했다. 원하는 해의 존재가 이 목적함수에서 그 해를 선택함을 보장하지 않는다.

## 미확인 가설과 한계

- λ=1 규제가 원하는 선택을 방해하는 주원인인지는 확인하지 못했다. 감독 범위만 바꿨으므로 규제의 효과는 분리되지 않았다.
- 첫 후보 표시를 이용하는 학습 경향이 다른 사고에서도 성능을 떨어뜨리는지는 확인하지 못했다. 모든 영상에서 f0만 고르는 모델도 아니다. 이번 00013 선택은 f109다.
- 영상 특징이 상대 차량·바퀴·차선 관계를 충분히 담고 있는지, 새로운 사고에서 일반화되는지는 확인하지 못했다. 학습 4건의 결과를 공식 S2 점수로 환산할 수 없다.
- 앞선 두 top-1 가중치의 존재만으로 이번 53개 비교를 모두 동시에 만족시킬 수 있다고 주장할 수 없다. 전체 비교 순서를 맞추는 요구와 최종 하나를 고르는 요구는 다르다.

## 다음 단일 변경 제안 — 실행하지 않음

**이번 53쌍과 나머지 모든 조건을 그대로 두고, L2 계수만 1에서 0.1로 낮추는 학습 4건 진단 1회**를 제안한다. 목적은 규제를 10배 완화했을 때 현재 남은 최종 선택 오류가 달라지는지 확인하는 것이다. 0.1이 최적이라는 근거는 없으며, 여러 계수를 탐색하는 제안이 아니다.

같은 0 초기화·최적화 조건에서 이번 모델을 기준으로 선택 프레임, 집합 안팎 최고 점수 차이, 같은 참조 시각의 오차 변화, ±0.3초 판정을 모두 비교해야 한다. 시작 전 진입 2건의 회귀와 영상 중 진입 2건의 개선을 같이 판단한다. 규제값 변경 후 총손실을 서로 직접 비교해서는 안 된다. 성공해도 이 네 학습 자료에서의 규제 효과만 확인하며, 실패해도 특징의 표현 불가능을 결론 내리지 않는다.

규제 완화가 첫 후보 표시나 전후 차분 항의 현재 점수 기여를 바로잡는다는 보장은 없으며 악화시킬 수도 있다. 제안의 목적은 규제 강도의 영향을 다른 조건과 분리하는 데 있다.

사용자가 결과를 검토한 뒤 결정할 후속 실험이다. 이번 작업에서는 실행하지 않았다.

## 검수·독립 검증 완료

추가 산술 검증 `score_verification.py`도 exit 0, **PASS**다. 저장된 수치를 정확한 유리수로 바꾸어 점수 기여와 초기 첫 후보 항 gradient를 확인했다. 기존 258쌍 목적에서 0 초기값의 첫 후보 항 gradient는 +0.00733817, 새 53쌍 목적에서는 −0.81819215로 바뀐다. 이것은 손실 구성 변경에 따른 계산 사실이며 추가 학습·특징 제거 실험이 아니다.

13개 동결 파일이 보존됐고, 새 모델의 가중치 이외 배열은 원 모델과 완전히 같다. 추적 중인 제출 코드 변경도 없다. 두 검수는 AI 에이전트 검수이며 사람 정답 검수나 독립 데이터 평가를 대체하지 않는다.
