# 직접 촬영 없이 Stage1 평가 자료 구성

2026-09-18. 상태: 공개 자료 조사 및 원천 대응 3개 장면 확인. 독립 평가 세트 완성이나 후보 성능 비교 완료가 아니다.

## 확인한 대안

VDmoire는 실제 화면 재촬영 자료이고 REDS에서 가져온 콘텐츠를 포함한다. 보유 표본 20개 원천을 육안 확인한 후 차량이 있는 거리 002, 버스 도로 016, 보행 상가 거리 045를 원천 연결 후보로 선택했다. 모델 점수로 선택하지 않았다. REDS 공식 배포 train_sharp ZIP에서 각 원천의 첫 프레임을 직접 확보했고, VDmoire의 해당 video_2/16/45와 동일 장면임을 이미지로 확인했다. 검수는 AI 이미지 확인이며 사람의 정답 검수가 아니다. 시점까지 정확히 일치하는 대응은 아직 검증하지 않았다.

확보: REDS 원본 3프레임, 기존 실제 재촬영 18프레임(원천당 6프레임). ZIP 전체 34,261,573,976바이트를 받지 않고 HTTP range로 인덱스와 필요한 원본만 확보했다. helper 기록 다운로드 7,210,130바이트에 초기 probe 128바이트가 별도로 있다. 원본과 재촬영 파일 해시를 재검증했다.

- `artifacts/stage1_road_data_search_20260918/candidate_pairs.json`: 원천·경로·해시·기기·기존 노출 이력.
- `reds_vd_comparison.jpg`: 좌 REDS, 우 VDmoire 동일 장면 비교.
- 이 3개 원천은 이미 이전 개발에 노출되었다. 최종 확인용에 넣지 않는다.
- 045는 보행 거리이므로 차량 도로와 별도 층으로 관리한다. 어느 표본도 블랙박스 장착 촬영으로 확인된 것은 아니다.

공식 자료: [VDmoire 저장소](https://github.com/CVMI-Lab/VideoDemoireing), [VDmoire 논문 §4](https://arxiv.org/pdf/2204.02957.pdf), [REDS 배포·라이선스](https://seungjunnah.github.io/Datasets/reds.html).

## 구성 방식

1. VDmoire의 미사용 REDS 원천을 모델 점수를 보지 않고 내용 기준으로 검사한다. 도로·차량 거리, 보행 거리, 비도로를 구분한다. 제공자의 train/val 명칭만 믿지 말고 실제 REDS 원천 및 촬영 연속성·유사 장면을 묶는다. 다른 번호라도 같은 연속 촬영이면 같은 분할에 둔다.
2. REDS sharp 카메라 원천과 raw 물리 재촬영을 연결한다. 정렬 clean을 출처 확인 없이 ORIGINAL로 쓰지 않는다. 전체 프레임의 시점 대응을 검사하고, 화면 내부의 안전한 사각 영역을 잘라 테두리 없는 조건을 만든다. 가능한 한 원근 워핑을 피하고 두 클래스의 크기·인코딩 차이가 정답 단서가 되는지 검사한다.
3. 원천별 조정용/최종 확인용을 추론 전에 고정한다. 두 기기의 재촬영이 동일 원천이면 둘 다 같은 분할이다. 장비 분리가 가능한 표본이 확보될 때 별도 장비 평가를 추가한다. 이미 본 20원천과 comma2k19 기존 Stage1 개발 원천은 새 독립 holdout으로 재사용하지 않는다.
4. 실제 재촬영과 카메라 원본 양쪽에 동일한 약한 블러·JPEG 압축 조건을 적용한다. 모든 파생본은 부모 원천을 상속한다. 디지털 변형은 강건성 조건이며 물리 재촬영 자체를 대체하지 않는다. 원본의 자연 반복무늬 사례도 확보하되 실제 이미지 검수로 포함 여부를 기록한다.
5. 충분한 독립 원천과 양 클래스가 확보된 뒤 frozen V6의 현행 0.5:0.5/임계값0.5, TPO 단독/0.5, 고정 비율·임계값 후보를 동일 입력에서 비교한다. 개발용에서만 후보를 선택하고 최종 확인용에서는 변경하지 않는다. 원천별 오류와 원본 오탐/재촬영 누락을 함께 보고한다. 프레임·파생본 개수를 독립 표본 수로 계산하지 않는다. 대회형 12프레임 영상 평가와 프레임 진단을 구분한다.

## 제한과 다른 후보

- 검색한 공개 출처에서 바로 사용할 수 있는 **블랙박스 도로 원본–물리 재촬영 대응 영상 세트**는 확인하지 못했다. 전 세계에 없다고 단정하지 않는다.
- VDmoire+REDS는 원천을 확인할 수 있는 실제 재촬영의 도로/거리 보조 평가 대안이다. 블랙박스 주행·야간·다양한 화면/카메라 조합까지 대표한다고 주장할 수 없다. 모아레 제거용 수집 편향 때문에 모아레가 약한 재촬영의 충분한 확보도 미확인이다.
- [Scoop](https://github.com/trusslab/scoop)은 물리 재촬영 관련 공개 후보지만 도로 대응 자료 여부·파일 확보를 확인하지 못했다. 현 단계 주 후보로 채택하지 않는다.
- comma2k19는 도로 ORIGINAL 확인에 유용하지만 대응 물리 재촬영을 제공하는 근거가 없다. 단독으로 양 클래스 평가 세트를 만들 수 없다.
- UHDM 참조는 검증된 카메라 원본을 대신하지 않는다. 화면 녹화·모아레 합성·생성 모델 결과는 실제 물리 재촬영 정답으로 넣지 않는다. 합성이 필요해도 학습 증강의 별도 실험에 한정한다.
- REDS 공식 페이지는 데이터 CC BY 4.0을 명시한다. VDmoire 사용은 기존 사용자 승인 범위의 연구를 이어가는 것이며 외부 아카이브의 권리 범위를 새로 확정한 것은 아니다. 배포 원천과 변경 기록을 보존한다.

## 현재 미완료 항목

미사용 원천 확대, 시간 대응, 테두리 없는 입력 구성, 원천/장비 독립 분할, 충분한 원본의 흐림·반복무늬 조건, 현행/TPO/고정결합 비교는 미완료다. 현재 3개 장면만으로 임계값을 선택하거나 도로 성능 향상을 선언하지 않는다. 기존 모델·결합 설정은 변경하지 않았다.
