## UHDM

위치: `external_data/uhdm/train/`. 9,000장 전체 디코딩·SHA256 계산 완료. 깨짐·짝 누락 없음. 공급자 체크섬과 대조한 것은 아니며 로컬 무결성 기준을 생성했다.

`pair_mi_14/0165`와 `0166`은 GT와 moire가 각각 바이트 단위로 같다. 중복 쌍 하나를 제외하면 4,499쌍이다. 원본은 삭제하지 않았고 제외 후보만 기록했다. 이것은 의미상 중복까지 제거했다는 뜻이 아니다.

GT 64장 축소판 육안 표본에서 문서·텍스트·그림 페이지 9장, 콜라주·도해 2장, 사진 형태 53장을 분류했다. 전체 분포 추정이나 원본 진위 판정으로 사용하지 않는다. 도로 재촬영 성능의 독립 검증 자료로 간주할 근거도 부족하다.

필요 정제:

1. 중복 쌍 제외와 유사 원천 이미지 그룹화 후 그룹 단위 분할.
2. 문서·콜라주를 별도 층으로 관리하고 도로 영상 성능과 구분 평가.
3. GT를 그대로 '카메라 원본' 정답으로 붙이기 전에 생성·보정 과정을 확인.
4. 모아레 흔적을 없애는 과도한 축소·노이즈 제거를 피하고 두 클래스에 같은 전처리 적용.

## VDmoire

기존 프레임 manifest의 해시가 모두 일치한다. 현재 표본은 재촬영 120프레임과 clean 40프레임이며, 20개의 전체 영상이 아니다. 원천 ID를 유지하고 동일 영상의 프레임·패치를 학습과 평가에 나누지 않는다. 시간 분석에 쓰려면 raw/clean의 대응 프레임과 정렬·보정 여부를 먼저 확인해야 한다.

## Nexar

40개 MP4의 배포 해시·크기 일치, 보관 PTS 단조 증가, 헤더 프레임 수와 PTS 길이 일치, 첫 프레임 디코딩을 확인했다. 이번 검사에서 모든 영상을 다시 전체 디코딩한 것은 아니다.

기존 대회형 참조값은 AI 검수값이며 공식 대회 정답이 아니다. 기존 검증 참조 5사례에서도 접촉 값 5개에 비해 진입 2개·방향 1개만 존재한다. 이미 자차선에 있던 사례의 진입 0초를 정확한 진입 시점 검증으로 사용하면 안 된다.

필요 정제: 실제 접촉/근접사고 구분, 첫 바퀴 경계 접촉의 시점 또는 구간 기록, 진입 방향과 회피 공간의 정의 통일, 판독 불가 필드는 결측 마스크 유지. 원본 PTS를 유지하고 개발에 노출된 사례를 새 독립 평가로 보고하지 않는다.

## Sama

위치: `external_data/sama/access_pilot_20260917/`. 공개 Hugging Face 행 API에서 20개 위치별 연속 10장과 대응 주석을 받았다. 이미지 합계 8,612,644바이트이며 전체 약 1GB 자료는 받지 않았다. 200장 모두 848×480, 디코딩 오류·완전 중복·범위 밖 좌표·역전 상자·부족한 도형 꼭짓점 없음. 이것은 주석 내용이 모두 정확하다는 판정이 아니다.

21개의 배포 video ID는 독립 주행 21회를 보장하지 않는다. 표본은 맑음 150·눈 30·흐림 10·기타 10장, 낮 180·해질녘 10·밤 10장으로 균형 표본이 아니다. 20장 오버레이를 육안 검사했고 `164-047.jpg`는 좁은 목재 통로 형태이며 차선 경계를 식별하기 어려워 별도 검토 대상으로 표시했다.

사용 범위: 차량 위치·차선 관계·주행 가능 영역의 공간 분석 보조. 1FPS 자료를 접촉·진입의 ±0.3초 시점 정답으로 쓰지 않는다. Drivable Space를 사고 시점의 회피 가능 공간으로 복사하지 않는다.

필요 정제: 연속 촬영 묶음별 분할, 중첩 category 이름 매핑, 열린 차선 polyline과 영역 polygon 구분, 가림·누락 객체와 특이 장면 검사. 공간 정답을 대회 사고 정답으로 전환하는 추가 주석은 별도로 필요하다.

## comma2k19

정렬 자료 23개에서 시간 역전 없음, 유효값의 비유한 값 없음. 속도와 조향 각각 유효하지 않은 지점 20개가 있어 기존 마스크를 유지한다. 영상 프레임과 가장 가까운 시간의 최대 차이는 0.049755초였다. 이것만으로 센서 자체 지연까지 검증된 것은 아니다.

필요 정제: 속도 단위·조향 부호 확인, 시간창에 기반한 가속/감속/정지/정속 범주 변환, 경계 구간 제외, 차량·연속 주행별 분할. 센서 기반 대체 정답과 대회 정답을 구분한다. 현재 신호가 있다고 모든 대회 범주의 정답이 확보된 것은 아니다.

## ANAID

위치: `external_data/anaid/access_sample_20260917/`와 `qa_pilot_20260917/`. 공개 Kaggle 개별 파일 다운로드가 작동했다. 이전 표본을 포함한 다운로드 합계 6,727,898바이트로 승인된 10MB 이내다. run2의 예상 회피 파일 경로는 404였으며, run2 전체 자료가 없다는 뜻은 아니다.

| 표본 | 영상 프레임 | CSV 행 | 첫 영상 PTS | 필수 신호 결측 행 |
|---|---:|---:|---:|---:|
| run1 회피 | 121 | 132 | 0.555초 | 0 |
| run3 회피 | 92 | 100 | 0.443초 | 0 |
| run1 일반 | 1,200 | 1,200 | 0초 | 58 |
| run2 일반 | 1,200 | 1,200 | 0초 | 55 |
| run3 일반 | 1,200 | 1,200 | 0초 | 17 |

5개 영상 전체 디코딩 완료. CSV에 원본 타임스탬프가 없고 frame_id만 있어, 회피 영상의 길이 불일치를 행 자르기로 교정할 근거가 없다. 원본 JPEG 2장과 MP4 동일 프레임을 대조했지만 이는 영상 프레임 대응만 지지하며 센서 동기화를 증명하지 않는다. 모든 표본의 yawRate가 0이라 회전 정답으로 신뢰할 근거가 없다.

공개 생성 코드에는 영상 무재인코딩 절단(`-ss`, `-t`, `-c copy`)과 센서 CSV의 명목 구간 길이×FPS 행 생성, 최근접 매칭 허용 오차 0.5초, 이후 timestamp 삭제 구조가 있다. 배포본이 정확히 이 코드 버전으로 생성됐는지는 확인되지 않았다. 관측된 차이를 특정 원인으로 확정하지 않는다.

일반 주행 표본에도 주차장·회전·초반 어두운 프레임이 확인된다. normal이라는 이름을 직진/정속 정답으로 쓰지 않는다. 현재 5쌍은 모두 동기화 확인 전 지도학습 사용을 보류한다. 원본 시간 정보로 재정렬할 수 없으면 정량 학습 자료에서 제외하고 장면 진단 용도로만 남긴다. 결측값을 0으로 채우지 않는다.

## 이용 조건 기록

이 문서는 새 법적 사용 승인을 선언하지 않는다. 기존 검토와 사용자 허용 범위 안에서 표본을 확보했다. 원천 URL·ID·해시·배포 조건을 파생 자료에도 유지해야 한다.

- [Sama 공식 배포](https://huggingface.co/datasets/SamaAI/sama-drives-california): CC BY 4.0 표기를 확인한 자료. 출처·변경 표시 유지.
- [ANAID Kaggle 배포](https://www.kaggle.com/datasets/mgarciafernandez/anaid-autonomous-naturalistic-driving): 배포 버전의 CC BY-SA 4.0을 기준으로 관리. 논문 CC BY 표기를 대신 적용하지 않는다. 코드 라이선스와 데이터 조건은 별개다.
- [ANAID 공식 코드](https://github.com/mgarciafernandez-uem/ANAID): 이번에 동기화·절단 코드를 읽었으며 실행하거나 프로젝트에 통합하지 않았다.
