# Stage1 UHDM 50쌍 분기 반응 진단

실행일: 2026-09-18. 기존 AI 패치 검수 통과 50쌍 전부를 사용했다. V6 TPO·forensic·결합 가중치와 임계값은 동결했고 학습·튜닝·다운로드·제출은 하지 않았다. 제공 clean-reference는 대회 ORIGINAL 정답으로 취급하지 않는다.

## 결과와 판단

**이 UHDM 표본에서 forensic은 재촬영의 미세 공간 주파수 변화에 강하게 반응했으며, TPO는 중앙 패치에서 참조 이미지에도 높은 점수를 주었다. 전체 화면 TPO와 원해상도 forensic을 유지하는 방향이 타당하다. forensic 제거 또는 TPO 중앙 패치 교체를 지지하지 않는다.**

다만 이는 이미지 쌍에 대한 탐색 진단이다. 도로 동영상 일반화, 실제 카메라 ORIGINAL 오탐률, 대회 Macro-F1 개선을 증명하지 않는다. 블러·흑백 반응은 개입의 효과이며 모아레만의 인과적 효과가 아니다.

## 고정 조건과 검증

- 선택: `artifacts/data_curation_20260917/uhdm/patch_qa_review.json`에서 기존 `pass_auxiliary_pair_content_QA` 50쌍. 결과를 보고 제외한 쌍은 없다.
- 공급자 train 자료이며 사진형으로 선별된 개발 표본이다. 50개의 잠정 source_group ID는 50개 독립 촬영을 보장하지 않는다.
- 입력: 100장. 동일 쌍에 전체 RGB, 기존 동일 좌표 native384 패치, 패치 흑백, 패치 Gaussian blur sigma=1.0의 네 조건. 총 400개 단일 이미지 점수.
- 흑백: OpenCV RGB2GRAY → GRAY2RGB, uint8. 블러: kernel=(0,0), sigma=1.0, BORDER_REFLECT_101. 양쪽 라벨에 동일 적용.
- 실행: `artifacts/submissions/verify_v6/model/stage2/code/solution`의 실제 V6 모듈, CPU 2스레드. TPO 내부 원래 224×224 변환 유지. forensic은 각 입력 내 원해상도 최대192 패치 5개를 추출한다. 384 패치를 입력했다고 forensic 패치 크기를 384로 바꾼 것은 아니다.
- 영상 12프레임 집계가 아니라 이미지 한 장을 각 분기에 넣었다. 동영상 실행 성능으로 해석하지 않는다.
- config: forensic/TPO 0.5/0.5, 임계값0.5. 모든 분기에 같은 임계값을 쓴 수량은 진단용이다.
- protocol과 모델·코드 SHA256은 추론 전에 저장했다. 기존 9/17 provenance와 중첩 파일 해시 일치. 실행 후 동결 파일 변경 없음.
- 원본100장과 패치100장 저장 SHA256을 실행 전후 검증했다. 패치와 원본 같은 좌표의 RGB 차이는 최대0. forensic 선형항으로 확률을 재구성한 최대 오차2.22e-16.
- 400행 중복/누락 없음. 저장된 예측에서 임계값 수량과 결합식을 재계산한 검사 PASS. 모델 로드 이후 진단 루프 및 정리 시간23.60초이며 전체 영상 추론 시간이나 L40S 시간은 아니다.

## 분기별 결과

`참조/재촬영 ≥0.5`는 각각 50개 중 임계값 이상인 수다. 참조의 수량을 공식 ORIGINAL 오탐이라고 부르지 않는다. `쌍 차이`는 각 쌍의 재촬영 점수에서 참조 점수를 뺀 뒤 평균한 값이다. 아래 점수는 모델 출력이며 목표 도메인에 보정된 확률이라는 증거가 없다.

## 어떤 흔적에 반응했는가

### 1. forensic: 미세 공간 주파수에 강한 민감성

native384 재촬영 평균 .7656 → 약한 블러 .1740, 변화 -.5916. 50/50에서 점수가 하락했다. 참조 평균 하락은 -.1189다. 재촬영/참조 평균 차이는 .5056 → .0329로 줄었다. 이 결과는 고주파 정보를 약화했을 때 현재 forensic의 쌍 구분 신호가 크게 소실된다는 관측이다.

현행 분류기는 주파수 특징 22개에 대한 선형 로짓이다. 정확한 계수 분해 결과, native 쌍 로짓 차이의 큰 양의 평균 기여는 다음과 같다. 이 수치는 확률 변화량이나 인과적 중요도가 아니라 현재 선형식의 산술적 분해다.

| 특징 | 의미 | 평균 재촬영−참조 로짓 기여 |
|---|---|---:|
| patch_q90_12 | 잔차 FFT 반경 .4–.71 cycles/pixel 에너지 비율의 패치90분위 | +.6648 |
| patch_q90_8 | .0–.1 대역 비율의 패치90분위 | +.6234 |
| patch_median_12 | .4–.71 대역 비율의 패치중앙값 | +.5266 |
| patch_q90_9 | .1–.2 대역 비율의 패치90분위 | +.4544 |
| patch_median_8 | .0–.1 대역 비율의 패치중앙값 | +.4226 |

저주파 비율 특징은 계수가 음수이므로 그 비율이 줄어도 양의 판정 기여를 만든다. 따라서 '고주파 하나만 본다'보다 **여러 대역 사이의 상대 에너지 변화에 반응한다**가 정확하다. 블러는 모아레뿐 아니라 장면 질감·선명도·잡음도 바꾸므로 모아레만 원인이라고 결론 내리지 않는다.

흑백에서도 평균 쌍 차이 .4633과 49/50 순위가 유지됐다. 이 표본에서 forensic의 구분 신호가 색 정보에만 의존하지 않는다는 근거다. 오히려 흑백은 양쪽 모든50장의 forensic 점수를 올렸다. 주된 로짓 증가항은 음의 계수를 가진 R−B 고주파 잔차 비율(patch_median_16, patch_q90_16)을 제거한 효과였다. 이를 흑백 변환의 성능 개선 근거로 해석하지 않는다.

### 2. TPO: 중앙 패치에서 참조에도 높은 점수, 색 제거에는 민감

전체 → native384에서 참조 평균 .4639 → .6710, 참조 임계값 이상24 → 40개. 재촬영 평균은 .8572 → .8485로 비슷하지만 쌍 차이는 .3933 → .1775로 감소했다. 따라서 기존 TPO를 중앙 패치 입력으로 바꾸는 것은 이 표본의 분리에 불리하다.

블러는 재촬영 평균을 .0273 올렸고 개별30개 상승/20개 하락으로 반응이 섞였다. forensic과 같은 방향의 큰 평균 붕괴는 없었다. 흑백은 재촬영 평균을 .1030 내렸고42/50에서 하락했다. 이 결과는 색 정보 제거에 대한 민감성을 보여주지만 반사·화면 경계·색 모아레·자연색 중 무엇을 이용했는지 구별하지 못한다. TPO 내부 설명가능성 분석을 수행한 것은 아니다.

### 3. 결합: 전역 입력에서는 도움이 있고 블러 조건에서는 검출 억제

전체 입력에서 TPO가 높게 판정한 참조24개 중15개를 결합이 낮췄다. TPO가 검출한 재촬영을 결합이 놓친 사례는0개였다. 반면 블러 패치에서는 TPO가 높게 판정한 재촬영 중17개가 결합에서 낮아졌다. 이전 VDmoire에서 관찰한 forensic의 낮은 점수를 모든 외부 데이터에 일반화할 수 없다. 고정50:50 결합의 손익은 데이터와 입력 조건에 의존한다.

## 대표 이미지 확인

결과 기반으로 네 사례를 선택하고 native384 시트를 직접 확인했다. 선택 규칙은 `visual_selection.json`에 남겼으며 이4개를 전체 성능 추정에 사용하지 않았다. AI 시각 검토이고 사람 검수는 아니다.

- `pair_mi_06/0167`: forensic 블러 하락 최대. 참조보다 재촬영에 조밀한 격자형 패턴이 관찰된다. 재촬영 forensic .998 → 블러 .019, TPO .799 → .939. 주파수 민감성의 설명 사례이며 패턴의 물리 발생 원인 전체를 확정하지 않는다.
- `pair_15/0087`: 유일하게 native forensic 재촬영 점수가 참조보다 낮다(.113 vs .162). 가는 선과 거친 갈색 질감이 보이며, 이 표시에서 첫 사례 같은 조밀한 격자는 명확하지 않다. TPO는 두 이미지 모두 약.998로 분리하지 못한다.
- `pair_00/0165`: TPO 참조 점수 최대. 꽃잎 패치이며 참조 약1.000, 재촬영 .998. 원본형 자연 질감에도 매우 높은 점수를 줄 수 있다는 관측이고, 이 패치에서 실제 촬영 원본 여부를 시각만으로 판정하지 않는다.
- `pair_03/0005`: TPO 전체 대비 패치 쌍 차이 감소 최대. 보라색 꽃잎 패치에서 참조 .991, 재촬영 .850. 주변 장면 제거와 입력 스케일이 동시에 달라지므로 테두리 의존으로 단정하지 않는다.

## 다음 실험 판단

1. **현행 전역 TPO 유지.** 중앙 패치로 대체하거나 forensic을 제거하지 않는다.
2. 현재 forensic은 이 UHDM 표본의 공간 신호를 상당 부분 구분한다. 새 backbone이 당장 필요하다는 근거는 얻지 못했다.
3. 다음 학습을 계획한다면 실제 재촬영의 크기·압축·약한 흐림 조건과 원본 대조군을 함께 구성하는 것이 우선이다. 블러에 견디도록 양쪽을 단순 증강하면 구분 증거 자체를 없앨 수 있으므로 그대로 처방하지 않는다.
4. 다른 분기 가중치·임계값·블러 강도 탐색은 이번에 하지 않았다. 이50쌍은 이미 개발에 노출됐으므로 새 독립 검증으로 사용할 수 없다.
5. 실제 도로 원본과 물리 재촬영에서 새 원천/장비로 확인하기 전에는 모델 변경·공식 성능 개선으로 보고하지 않는다. UHDM GT가 camera ORIGINAL로 확인되지 않았으므로 이번 결과로 공식 F1을 계산하지 않는다.
