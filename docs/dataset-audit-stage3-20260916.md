# Stage3 외부 데이터 적합성 및 이용 조건 검토

검토일: 2026-09-16. 범위: 공식 배포 문서·라이선스·공식 SDK 구조. 전체 데이터 다운로드, 실제 신호 품질 측정, 학습, 외부 연락은 수행하지 않았다. 아래 기술적 판정은 문서로 확인한 입력·신호 구성에 대한 판단이며 성능 향상 실증이 아니다.

## 대회 목표와의 일치

프로젝트 `대회_통합_정보.md` 62–78행에 따르면 Stage3는 10Hz 영상만 입력받아 모든 프레임의 가감속 4종·조향 3종을 출력한다. 정답은 CAN 차속·종가속도·조향각으로 생성하지만 임계값과 전환 규칙은 비공개다. 따라서 아래 자료는 **대회와 같은 센서 계열을 가진 대체 정답 자료**이지 이미 대회 정답을 가진 자료가 아니다. 센서는 학습·검증 정답 구성에만 사용하며 추론 입력으로 사용하지 않는다.

## comma2k19

공식 문서는 33시간 이상, 1분 단위 2,019구간, 캘리포니아 280번 고속도로 약20km, RAV4와 Civic 두 차량을 명시한다. CAN `car_speed`와 `wheel_speeds`는 m/s, `steering_angle`은 degree다. 로그와 프레임 시간 모두 장치 부팅 후 초 단위로 제공한다. 공식 저장소에 1분 표본도 있다. [공식 구조](https://github.com/commaai/comma2k19)

**기술적 판정:** 시간 정렬과 차속·조향 대체 정답 구현에 적합하다. 도심 정지/출발·다양한 차량을 대표하지 못한다. 같은 주행 경로의 인접 구간을 프레임 단위로 무작위 분할하면 과대평가할 수 있으므로 route 단위로 묶는다. 속도 차분을 종가속도로 사용할 경우 필터와 지연을 별도로 검증한다. README의 IMU 가속도 단위에는 `m^2/s` 표기가 있으므로 그대로 구현 근거로 복사하지 않는다.

**이용 조건:** GitHub LICENSE만 보고 코드 라이선스를 데이터에 확대 적용한 판단이 아니다. 공식 README가 연결한 Academic Torrents 배포 항목에서 `Type: Dataset`, `license= {MIT License}`, `terms= {}`를 확인했다. 라이선스 전문은 사용·수정·배포·판매를 허용하며 복제물/상당 부분에 저작권 및 허가 고지 보존을 요구한다. [데이터 배포 항목](https://academictorrents.com/details/65a2fbc964078aff62076ff4e103f18b951c5ddb), [MIT 전문](https://raw.githubusercontent.com/commaai/comma2k19/master/LICENSE)

## ADAS-TO

**중요한 버전 불일치:** GitHub는 15,705클립·327운전자·163차종·약33GB라고 기재하지만, 현재 HF 전체 배포카드는 **16,446클립·364운전자·179차종·2,585경로·약41GB**라고 기재한다. HF 파일 크기 표시는43.6GB다. 현재 전체판은 클립당13종 CSV,20초,20fps이고 rlog가 있으면 최대100Hz, 아니면 qlog 주기를 사용한다. 따라서 사용자 제안의163차종은 현 전체판의 확정 수치로 쓸 수 없다. [GitHub](https://github.com/OpenLKA/ADAS-TO), [현재 HF 배포카드](https://huggingface.co/datasets/HenryYHW/ADAS-TO)

공식 필드표상 실제 상태 후보는 `carState.csv`의 `vEgo`(m/s), `aEgo`(m/s²), `steeringAngleDeg`(degree)다. `carControl.actuators.accel`, `longitudinalPlan.aTarget`, 모델 예측 곡률 등은 목표/명령값이므로 실제 가감속 정답에 대입하면 안 된다. 메타에는 이벤트 monotonic ns, route 내 영상 시간·클립 시작 시간 등이 있다. 다만 실제 파일의 결측률·차종별 부호·필터 지연·프레임 정렬 정확도는 아직 검사하지 않았다. [공식 필드표](https://github.com/OpenLKA/ADAS-TO#-data-fields-reference)

**기술적 판정:** 다양한 차종의 보완 자료라는 논거는 성립한다. 그러나 ADAS 해제 전후20초만 선별한 자료이므로 일반 주행의 확률 분포가 아니다. `aEgo`를 독립 정밀 가속도계의 원시 측정이라고 단정할 근거도 없다. 센서 생성 경로와 차속 차분의 일관성을 표본에서 확인해야 한다. 차종/운전자/route 분할과 자료별 가중치를 사전에 고정한다. 클립 시나리오 `stop`·`turn` 라벨은 프레임별 대회 정답으로 직접 복사하지 않는다.

**이용 조건:** HF와 GitHub 모두 CC BY-NC4.0을 명시한다. HF는 연락정보 공유 동의 및 수동 접근 승인 대상이다. 전체판 및 Sample 모두 게이트가 있어 공개 페이지에서 확인할 수 없는 접근 약정은 미확인이다. Sample은 약1,570클립·3.3GB라고 기재하고 현재 총 파일 크기는3.44GB다. 작지만 무승인 공개 표본은 아니다. [Sample](https://huggingface.co/datasets/HenryYHW/ADAS-TO-Sample)

BY-NC4.0은 비상업적 복제·개작·공유를 허용하고 공개 시 저작자·라이선스·출처·변경 표시 등을 요구한다. NC는 주된 목적이 상업적 이익이나 금전 보상을 향하는지에 관한 조건이다. 이번 참가 및 수상물 후속 활용이 그 조건에 들어가는지 배포자의 별도 명시를 확인하지 못했다. 접근 승인 시 대회명·상금·모델 학습·가중치 제출/공개·주최자의 후속 이용 범위를 명시하여 확인하는 것이 적절하다. **이번 검토에서 연락/신청을 대신 수행하지 않았다.** [BY-NC4.0 전문](https://creativecommons.org/licenses/by-nc/4.0/legalcode.en)

## ZOD Sequences/Drives

공식 설명상1,473 Sequences(각20초),29 Drives(수분),카메라10.1Hz,GNSS/IMU100Hz다. 차량 제어 신호100Hz·일반IMU50Hz·위성신호1Hz를 제공한다. Sequences/Drives는 영상 개인정보 블러 처리본이다. [공식 센서·구성 설명](https://zod.zenseact.com/)

SDK는 `ego_vehicle_data.lon_vel`(m/s), `lon_acc`(m/s²), `ego_vehicle_controls.steering_angle`(radian,반시계양수), 각 epoch timestamp(ns)를 실제 HDF5 경로에서 읽는다. 그러므로 조향/종가속도 신호 존재는 단순 홈페이지 홍보 이상의 코드 근거가 있다. `acc_pedal`을 가속도 정답으로 대신 사용할 이유가 없다. [공식 SDK](https://raw.githubusercontent.com/zenseact/zod/main/zod/data_classes/vehicle_data.py)

**기술적 판정:** 외부 검증에 적합하되10.1Hz를10Hz로 가정하지 않는다. 실제 타임스탬프로 센서를 보간하고 영상 프레임 시간에 맞춘다. 학습 튜닝에 계속 사용하면 독립 검증 역할을 잃는다. 대회 범주 임계값이 비공개이므로 ZOD 센서 점수도 공식 대회 점수를 대체하지 못한다.

**이용 조건:** 데이터는 CC BY-SA4.0, SDK는 MIT다. 공식 데이터 페이지는 상업·비상업 활용을 허용한다고 명시한다. 공개 사용/배포/전시에는 Zenseact가 요청한 개인정보 제거·삭제 요청 안내 고지 전체를 포함해야 한다. 재배포·개작 공개에는 저작자/출처/변경/라이선스 표시 및 해당 개작물의 동일조건 공유 요건을 검토해야 한다. [데이터 라이선스](https://zod.zenseact.com/license/), [CC BY-SA4.0](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en)

SA가 학습 가중치 전체에 무조건 전염되거나 무조건 적용되지 않는다고 단정할 수 없다. 데이터가 포함된 재배포물인지, 저작권상 개작물인지가 중요하며 공식 문서에 이번 가중치 제출의 개별 판정은 없다. 검증 전용 사용은 데이터를 가중치에 학습시키지 않는 구성으로 유지할 수 있다. CC는 기술 이름이 AI라는 이유로 추가 허가가 필수라고 하지 않으며 기존 조건을 준수하는 이용을 허용한다고 설명한다. [CC AI FAQ](https://creativecommons.org/faq/#artificial-intelligence-and-cc-licenses)

접근은 공식 페이지에서 이름·소속·Dropbox 이메일·사용 목적을 포함한 요청 절차를 안내하고, 동시에 공식 Academic Torrents 링크도 제공한다. 전체 센서 자료가 필수인 것은 아니므로 향후 확보 시 카메라·시간·vehicle data/OxTS만 선택하고 LiDAR/radar는 제외할 수 있다. [다운로드 안내](https://zod.zenseact.com/download/)

## 실제 확보 전 최소 검증

1. 선택한 배포 revision, 라이선스/게이트 조건, 파일 목록 및 해시를 고정한다. ADAS-TO 버전 차이를 우선 해소한다.
2. 소량 영상·상태 신호에서 시간 단조성, 프레임 수, 센서 주기·결측, 단위·부호·지연을 확인한다.
3. CAN 대체 정답 기준을 사전 정의하고, 차속·가속도·조향 범주 경계의 불확실 구간을 기록한다.
4. 주행/운전자 단위 분리 후 대회 공개 라벨과 별도로 검증한다. 소량 공개 라벨에 반복 임계값 최적화한 수치를 일반화 성능으로 보고하지 않는다.
5. comma2k19를 기본, ADAS-TO는 접근·이용 조건 완료 후 보완, ZOD는 고정 외부 검증으로 운영한다. 조합 자체의 성능 우월성은 아직 확인 불가다.
