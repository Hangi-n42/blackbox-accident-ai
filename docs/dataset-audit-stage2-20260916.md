# Stage2 외부 데이터 적합성·이용 조건 검토

확인일: 2026-09-16. 공식 배포 문서, 원 논문, 데이터 라이선스와 로컬 인수인계를 비교했다. 전체 파일 검사·다운로드·학습·외부 문의는 수행하지 않았다. 아래 사용 판단은 문서 기반이며 점수 개선을 입증한 결과가 아니다.

## 판정

| 자료 | 기술적 역할 | 현재 판단 |
| --- | --- | --- |
| Nexar collision prediction | 자차 사고 장면 확보, 접촉 후보 탐색 및 대회 기준 재주석 | 우선 유지. 원본 train에서 실제 접촉 여부를 확인하고 네 항목을 다시 표시해야 한다. 제공 event/alert 시점을 대회 정답으로 직접 복사하지 않는다. |
| PREVENTION | 동일 차량 추적, 차량과 차선의 관계, 차선 변경 구간 탐색의 보조 학습·진단 | 조건부 채택 후보. Stage2 네 항목을 직접 학습하는 정답 자료가 아니다. NC/SA 준수와 실제 제출·공개 조건을 확인한 뒤 제한된 표본부터 검증한다. |

## 과제 정의와 차이

프로젝트 `대회_통합_정보.md:44–60`은 자차와 상대 차량의 실제 접촉, 상대 차량 첫 바퀴의 자차 차선 접촉, 화면상 진입 방향, 충돌 당시 회피 공간을 요구한다. 무충돌과 제3자끼리만 충돌한 영상은 평가 대상이 아니라고 기록한다. `HANDOFF.md:118` 역시 Nexar positive/time_of_event를 최초 접촉 정답과 동일시하지 말라고 명시한다.

Nexar 공식 카드의 train은 1,500개이며 절반은 충돌 또는 근접사고, 절반은 일반 주행이다. positive의 이벤트 시점은 둘을 함께 취급한다. 약 10초 test 영상은 사건 0.5/1/1.5초 전에 끝나므로 접촉 자체를 관찰하는 검증 자료로 부적합하다. train의 실제 접촉 영상만 선별하는 것이 맞다. 제공 필드에 첫 바퀴 진입, 사고 상대 트랙, 대회 방향 및 회피 공간의 정답은 없다. [공식 데이터 카드](https://huggingface.co/datasets/nexar-ai/nexar_collision_prediction)

원 논문은 IMU 급제동·급가속으로 수집이 시작되는 구조를 설명한다. 따라서 무작위 전체 주행 표본이라고 볼 수 없다. 사고 정의는 자차와 제3자 사이의 사건이지만 공개 positive에는 근접사고도 함께 들어 있으므로 개별 사례 선별은 여전히 필요하다. [Nexar 원 논문](https://openaccess.thecvf.com/content/CVPR2025W/WAD/papers/Moura_Nexar_Dashcam_Collision_Prediction_Dataset_and_Challenge_CVPRW_2025_paper.pdf)

PREVENTION은 `lane_changes.txt`의 f0/f1/f2를 제공하며 f1은 차량 뒤쪽 중앙이 차선 사이에 놓이는 시점이다. f0도 단순히 변경 시작으로 명시돼 있어 첫 바퀴 접촉과 같다고 확정할 수 없다. LC_type의 좌우는 차량의 변경 방향이며 대회의 진입 출처 방향과 직접 대응하지 않는다. 차량 ID·궤적·차선 정보는 동일 상대를 계속 찾는 보조 과제에 유용하다. [공식 주석 구조](https://prevention-dataset.uah.es/)

PREVENTION 원 논문은 도시 장면도 있으나 주로 고속도로 의도·궤적 예측을 목표로 한다. 중앙 낮 시간대, 일부 반복 주행 구간이라는 제한이 있다. 검출은 CNN 자동 생성, 추적은 사람 감독을 포함하는 반자동 과정, 차선은 검출 시스템 산출물이므로 전 항목을 사람이 만든 정답으로 취급하면 안 된다. 차선 변경 라벨은 차량 중심의 경계 통과와 관련된다. 사고·회피 공간 정답은 확인하지 못했다. [배포자 원 논문](https://invett.aut.uah.es/sotelo/ITSC2019-PREVENTION.pdf)

## 이용 조건

### Nexar

정확한 이름은 `nexar-open-data-license`이며 MIT나 CC BY-NC가 아니다. 공개 LICENSE에서 숫자 버전은 명시되지 않았다(2025 copyright; 페이지에 표시된 변경 commit `ed1ffff`). 사용·복사·수정·배포를 허용하되 Nexar 표시, 출판·연구의 출처 인용, 재배포 시 copyright/조건/면책 유지가 필요하다. 데이터 판매·재라이선스·수익 목적 재배포에는 사전 서면 동의가 필요하다. 해악 시스템, 기만 미디어, 재식별·무단 감시, 무기화, 약탈적 금융 목적 등 윤리 제한도 있다. [데이터 LICENSE 원문](https://huggingface.co/datasets/nexar-ai/nexar_collision_prediction/blob/main/LICENSE)

**해석:** 이 문서는 비영리만 허용하는 라이선스가 아니다. 상금 수령 자체를 금지하는 문구도 확인되지 않았다. 안전한 사고 분석 개발은 허용된 사용 범위와 부합하지만, 학습 가중치의 별도 권리나 모든 형태의 상업 활용을 명시적으로 보장하는 조항은 없다. 데이터 재배포와 가중치 제출을 구분해야 한다. 가중치가 자동으로 데이터와 같은 라이선스라고 단정하지 않는다. 주최측에 원본/가공 데이터도 전달한다면 재배포 조건과 수익 목적 여부를 별도로 점검한다.

현재 저장소에는 `research/v7/fresh_sources/LICENSE`, `research/v7/new_validation_sources/LICENSE`, `research/v6_review_tool/dist/NEXAR_LICENSE.txt`에 Nexar 라이선스가 보존돼 있다. 검수 UI README도 출처 표시를 기록한다. 다만 이것만으로 모든 과거 사용과 배포가 준수됐다고 전수 인증한 것은 아니다.

### PREVENTION

사이트 하단뿐 아니라 Dataset 구조화 metadata도 **CC BY-NC-SA 4.0**을 데이터 라이선스로 명시한다. 코드 저장소의 별도 라이선스로 데이터 권한을 대신 판단하지 않았다. [공식 배포처](https://prevention-dataset.uah.es/)

CC 본문은 비영리 목적의 복제·공유·변형을 허용한다. 공유 시 저작자·출처·라이선스·기존 고지를 유지하고 변경을 표시한다. 변형 자료를 공유할 때 같은 라이선스 요소/호환 조건을 지켜야 한다. NC는 주된 목적이 상업적 이익 또는 금전 보상인지에 관한 조건이다. 원본이나 변형 자료의 공유와 학습 가중치가 법적으로 변형 자료인지 여부는 별개이며 후자는 이 문서만으로 확정할 수 없다. [CC BY-NC-SA 4.0 법률문](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en)

**대회 관련 판단:** DACON 공식 규칙은 외부 자료에 최소 비영리 이용 허용을 요구하므로 NC 표기만으로 대회에서 금지됐다고 말할 수 없다. 그렇다고 데이터 권리자가 모든 상금 대회·수상작 활용을 허용한 것으로 해석할 수도 없다. 실제 참가 목적, 수상 시 원본/가공 데이터 제공, 모델·코드 공개와 상업적 활용 범위를 함께 확인해야 한다. 상업 이용이 필요하면 별도 허락을 받아야 한다. [대회 규칙](https://dacon.io/competitions/official/236753/overview/rules)

## 실행 권장안

1. 이미 확보한 Nexar 영상 중 미사용·원천 비중복 자차 접촉 사례를 우선 선정한다. 사용 이력이 있는 사람 검수 9건은 독립 평가로 재사용하지 않는다(`research/v6_review_tool/README.md`, `research/v7/validation_and_resource_plan.md`).
2. 모델 출력을 보지 않은 상태에서 같은 상대 차량에 대한 접촉·첫 바퀴 진입·방향·회피 공간을 표시하고 불확실 항목은 별도로 둔다. 프레임 번호와 원본 PTS를 보존한다.
3. PREVENTION은 이용 범위를 해결한 뒤 전방 영상, 대응 주석, 시간·보정 정보의 작은 묶음으로 차량 ID/차선 관계의 정확성을 검사한다. 원본 센서 전체를 받을 필요는 없다. RGB 추론에 없는 LiDAR·레이더를 실행 입력으로 요구하는 모델은 대회에 그대로 사용할 수 없다.
4. PREVENTION 보조 과제 성능과 Nexar의 대회 기준 Stage2 성능을 별도로 기록한다. 두 자료를 동일 event 라벨로 합치지 않는다. 같은 drive/사고의 인접 프레임을 학습·검증에 나누지 않는다.
5. 허용 범위가 불명확하면 배포자에게 대회명·상금·가중치 공개·주최측 데이터 제공·수상작 활용을 명시해 확인한다. 이번 검토에서는 외부 연락을 보내지 않았다.

가장 먼저 해결할 것은 데이터 총량이 아니라 대회 정의에 맞고 아직 개발에 사용하지 않은 정답의 확보다. PREVENTION 추가만으로 현재 진입 시점 정답 부족이 해결되지는 않는다.
