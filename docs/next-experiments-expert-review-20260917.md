## 권고 작업 순서

### 0. 확대 기준의 비교 규칙 고정

기존 예측만 사용해 차량/route별 범주 지원 수, 혼동, 등속 오류 지속 구간, 제외 사유를 정리한다. 공식 공개 지표와 센서 대체 지표를 분리한다. 주 방향437학습/3,246비교와 역방향646학습/2,204비교를 고정한다. 13,787 중5,450명확 시각만 사용했다는 선택 한계를 명시한다.

전환 거리·검출률은 보조 진단이다. 센서 동기화·범주 임계값 불확실성이 있어 .0132초 같은 작은 평균 거리 차이를 공식 성능의 확정 악화로 해석하지 않는다. 기존 후보 결과는 보존하고 다음 후보 판정 원칙을 결과 전에 정한다. 대회 첫 프레임 제출 관례와 실제 진입시각의 left-censored 결측도 구분한다.

### 1. Stage3 긴 시간 차분 묶음만 제외하는 실험 1회

현재864특징 중 ±15프레임 차분 묶음만 제외한다. 원시 특징·공간 ROI·평균·짧은 차분·라벨·학습시각·파라미터·seed를 유지한다. 기존 캐시로 기준과 후보를 같은 조건에서 학습하고 양 방향 및 공개50시각을 비교한다. 운영 모델·조향·평활은 변경하지 않는다.

근거: 상세 오류3건 중2건에서 긴 차분의 큰 기여가 관측됐다. 제거 효과가 입증된 것은 아니다. 주 방향 F1·등속오류뿐 아니라 역방향, 범주별 recall, 반전, 공개 회귀를 함께 보고한다. 한 방향만 좋아지면 보편적 개선으로 채택하지 않는다. 전환은 불확실성을 표시한 보조 지표로 보고한다. 하단 제거·차체 마스크 후보 반복 탐색은 우선하지 않는다.

### 2. Stage2 접촉 선택 질문 한 가지 대조

공개5개 전체에서 후보 생성·움직임 보정·나머지 필드를 고정하고, 동일 사고 상대의 실제 접촉과 접촉 전 큰 움직임을 구분하는 질문만 바꾼다. 기존 기록을 재사용한다. 최소4/5와 MAE 비악화, 기존 정답 사례 유지, 프레임 반환/반복성 조건을 확인한다. 통과해도 개발 후보다. S2_002 하나에 반복 맞춤하거나 움직임 보정을 통째로 제거하지 않는다.

진입 탐색 재개 전에는 정밀 정답을 보강한다. 가려진 Nexar를 반복 검수하지 않는다. 기존 확보분에서 가시성이 있는 사례를 먼저 선별하되, 개발 미노출 여부를 확인하지 못하면 독립 평가라 부르지 않는다. 추가 확보가 필요하면 명확 접촉·비충돌 큰 움직임·다중차량을 포함한5건 파일럿을 계획할 수 있다. 이는 통계적 충분량이 아니라 검수 절차 시험용 제안이다. 실제 접촉/첫 바퀴 경계가 보이지 않는 필드는 결측으로 유지한다.

### 3. Stage1 입력 민감성 진단 및 필요시50쌍만 보조 실험

VDmoire 기존 예측의 모델 분기별 확률과 원천별 미탐을 확인한다. 제공 clean과 공식 ORIGINAL을 분리한다. 구체적인 미탐 패턴이 확인될 때 UHDM 검수50쌍의 동일 좌표 native 패치만 보조 실험에 쓴다. 4,500쌍 일괄 학습/콘텐츠 검수를 선행하지 않는다.

도로 원본과 물리 재촬영 대응 평가 자료는 별도 필요하다. 원천 ID·촬영기기/화면·압축·테두리 노출 여부를 보존하고 개선용/확인용 원천을 분리해야 한다. 현재 확보분만으로 일반화 개선을 확정할 수 없다.

### 4. 남는 데이터 공백에만 대응

Stage3 양방향 결과가 갈리면 시간창을 연속 탐색하기보다 새 차량/촬영조건과 독립 주행의 정지→출발·감속→정지·등속 구간이 필요하다. RAV4 정지 학습30시각은 한 route뿐이다. 기존23구간의 프레임 밀도 증가를 다양성 확대로 표현하지 않는다. ANAID는 작은 구간에서 시계·신호·지연을 검증한 뒤에만 채택 여부를 판단한다. Sama는 차량/차선 모듈 후보가 실제 필요할 때 검수19장부터 사용한다.

### 5. 제출 실행 검증을 병행 과제로 확보

Mac MLX4bit와 Linux CUDA/NF4는 수치동일하지 않다. 정책 확정 전부터 보존된 Linux 실행 경로에서 오프라인 로드·출력 형식·공개 표본·메모리·시간을 확인할 환경을 준비해야 한다. 성능 실험이 모두 끝날 때까지 이 위험을 미루지 않는다. 현재 L40S 실측은 미검증이며 작은 표본으로 전체60분 통과를 주장하지 않는다. 이번 검토는 환경 구매·제출 실행을 포함하지 않는다.
