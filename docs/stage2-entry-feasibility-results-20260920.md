# Stage2 학습 4건의 선형 top-1 표현 가능성 진단

**결론: 가능하다.** 고정된 14개 특징과 기존 공유 선형 점수식으로 학습 4건에서 가능한 최근접 후보를 동시에 단독 1위로 만드는 가중치가 존재한다. 가능한 후보 조합 2개를 전부 검사했고, 두 조합 모두 양의 점수 차이로 통과했다. 따라서 이 4건의 기존 실패만으로 특징이나 선형 모델의 표현력이 부족하다고 결론 내릴 수 없다.

이는 학습 자료에 대한 표현 가능성 증명이다. 실제 진입을 이해했다는 증거, 독립 자료의 성능, 공식 점수 개선은 아니다. 참조는 기존 사람 초안을 AI 전문가가 선별·확장한 약한 구간이며, 사람이 확정한 정답이 아니다.

## 고정한 것과 실제 실행

- Mac arm64에서 저장된 학습 4건의 영상 특징만 사용했다: `00000`, `00003`, `00006`, `00013`.
- 기존 PCA 4성분, 정규화 통계, 14차원 특징 생성식, 12개 후보와 PTS, 참조 구간을 고정했다. 영상 특징에는 PCA 좌표, 전후 차분, 상대 시각, 첫 후보 표시가 들어 있다.
- 진입 참조 구간의 어느 시각에서든 12개 중 시간 오차가 최소가 될 수 있는 후보를 구했다. 후보 간 중간 시각과 구간의 교집합은 저장된 PTS의 십진수 표현을 유리수로 바꾸어 계산했다.
- 각 후보 조합마다 하나의 공유 가중치 `w`로 선택 후보 점수가 나머지 11개보다 1 이상 높도록 하는 선형계획을 풀었다. 총 44개 비교 제약이며, 두 조합을 모두 검사했다. 가중치의 L1 크기를 최소화했다.
- 모델 가중치가 자유롭게 확대될 수 있으므로 마진 1은 점수의 크기를 정하는 규약이다. 실제 argmax와 모든 제약 잔차로 양의 차이를 확인했다. 동률 처리 검사는 필요하지 않았다. 원 실행 코드의 `longdouble` 계산은 이 Mac에서 float64와 같은 정밀도이므로, 결과 키 `min_extended_precision_margin`을 추가 정밀도 검증으로 해석하면 안 된다.
- 진단용 가중치 계산 2회, 기존 학습 목적함수 재학습 0회, 영상 모델 호출 0회, CCD 평가 0회다. 진단 가중치는 결과 파일에만 저장했다. 기존 모델과 제출 코드는 교체하지 않았다.

기존 모델은 4건 모두 이 후보 집합 밖을 선택했다. 가중치 A와 B는 각각 4건 모두 집합 안의 후보를 단독 1위로 선택했다. 최소 점수 차이는 두 경우 모두 약 1이며, 단위 L2 길이로 가중치를 정규화한 최소 차이는 각각 0.204825와 0.162344다. 수치 오차에 의존한 동점 결과는 아니다. 이 수치는 입력이 달라졌을 때의 강건성 보증은 아니다.

**최근접 후보를 고르는 것과 ±0.3초 정답은 다르다.**

| 사례·후보 | 고정 참조 구간 기준 가능한 절대 오차 | ±0.3초 판정 |
|---|---|---|
| 00000 f561 | 0~1.00346초 | 참조 구간 일부에서만 가능 |
| 00003 f0 | 0초 | 전체 참조에서 충족 |
| 00006 f0 | 0초 | 전체 참조에서 충족 |

00013은 실제 진입이 참조 구간의 앞부분이면 f545가 가장 가깝지만, 그 경우에도 최소 오차는 0.4초다. 따라서 “4건 정답률 100%”라는 해석은 틀리다. 가중치 B조차 00000과 00013의 정확한 진입 시점을 확정하지 못하므로 네 건의 시간 정답을 보장하지 않는다.

## 기존 학습이 실패한 원인에 대해 확인한 범위

기존 목적함수는 사고마다 모든 확실한 후보 쌍의 logistic 손실을 평균한 값에 `||w||² / 2`를 더한다. 최종 1개 후보를 맞히는 것과 서로 다른 목표다. 정답 후보와 무관한 두 오답 후보의 순서도 손실에 포함된다. 실제 기존 평균 쌍 순서 정확도는 70.48%였지만, 최종 선택은 4건 모두 가능한 최근접 후보 밖이었다.

기존 가중치에서 목적함수는 0.6644740581, 기울기의 L2 크기는 약 1.40e-7이다. 고정 특징에 대한 이 목적함수는 L2 계수 1의 강볼록 함수다. 따라서 정확한 산술에서 `기울기 크기² / 2`로 계산하는 최솟값과의 차이 상계는 약 9.82e-15다. 이 수치는 부동소수점 계산을 이용한 수치 진단이며 엄밀한 구간산술 증명은 아니다. 기존 최적화가 덜 수렴해서 실패했다는 설명을 지지하지 않는다.

이번 양의 마진 해는 “기존 모델 계열에는 원하는 학습 top-1을 표현하는 해가 없다”는 주장을 반박한다. 반면 기존 목적함수를 충분히 최소화한 가중치는 그 해를 선택하지 않았다. **따라서 다음 우선순위는 특징 교체보다 학습 목표와 규제의 영향을 분리하는 것이다.**

규제가 단독 원인이라고 확정할 수는 없다. LP 해는 top-1 제약만 만족시키므로 전체 쌍의 순서가 나쁠 수 있고, 마진 1을 강제한 가중치 크기를 그대로 기존 L2 벌점과 비교하면 점수 크기 선택의 영향을 섞게 된다. 두 LP 해의 기존 목적함수 값이 12.83과 19.85라는 사실만으로 “규제를 없애면 해결된다”고 결론 내리면 안 된다.

또한 학습 4건에 맞는 14개 계수의 존재는 상대 차량·바퀴·차선 관계의 학습을 증명하지 않는다. 시각과 첫 후보 표시, 장면 특성에 의존해 이 네 사례를 구분했을 가능성을 이번 검사로 배제하지 못했다.

## 다음 단일 변경 제안 — 아직 실행하지 않음

**특징·후보·참조·L2 계수 1은 유지하고, 학습에 쓰는 비교 쌍만 최종 선택에 집중시키는 진단 1회를 권고한다.** 가능한 최근접 후보 집합을 M, 기존의 확실한 우위 쌍 집합을 P라 할 때 `P_top = {(i,j) ∈ P : i ∈ M, j ∉ M}`만 사용한다. 참조 구간 전체에서 우위가 확실한 비교만 유지한다.

기존 258쌍 대신 53쌍(사고별 11/11/11/20)을 쓴다. 영상 안에서 평균한 뒤 4개 영상에 동일 가중치를 주는 방식, logistic 함수, 규제, 최적화 조건은 유지한다. 00013의 f545와 f599 사이 순서를 강제하지 않으며, 정확한 진입 시점을 새로 가정하지 않는다. 고정 특징에서의 볼록한 목적함수도 유지된다.

판정은 이 학습 4건의 가능한 최근접 후보 top-1 선택 수와 각 사고의 점수 차이, 선택 시각의 절대 오차 범위로 한다. 기존 0/4에서 개선되는지 검사하고, 전부 가능한 후보를 선택하면 이 자료에서 목적함수의 비교 대상이 문제였다는 근거를 얻는다. 후보 집합 안을 선택해도 실제 시간 오차가 나빠질 수 있으므로 선택 수만으로 성공을 판정하지 않는다. 실패하면 같은 조건에서 규제 효과를 별도로 검사할 이유가 생기며, 곧바로 영상 특징이 부족하다고 결론 내리지 않는다. 이번 LP는 다음 학습의 성공을 보장하지 않는다. 이 후속 진단도 CCD를 사용하지 않아야 한다.

## 전문가 검수와 독립 검증

전문가 A는 후보 정의·LP 제약·해석·후속 단일 실험을 검수했고 `PASS_METHOD_AND_RESULT_WITH_LIMITED_INTERPRETATION`으로 판정했다. 별도 검증 에이전트는 원 특징 변환을 독립 식으로 재구성하여 저장 특징과 일치함을 확인하고, 가중치와 특징의 저장 부동소수점 값을 정확한 유리수로 옮겨 각 해의 44개 점수 차이를 다시 계산했다. 모든 차이가 양수이며 검증 스크립트는 exit 0, `PASS`다. 실행 전 동결한 11개 파일도 그대로다.

이는 저장된 수치에서 양의 점수 차이가 존재함을 검증한다. 원 영상 특징의 측정 오차나 다른 입력에 대한 보증은 아니며, L1 최소해라는 solver의 최적성까지 별도 인증하지는 않았다. 표현 가능한 가중치의 존재라는 결론에는 L1 최적성 인증이 필요하지 않다. 두 검수는 AI 에이전트에 의한 것이며 추가 사람 정답 검수로 간주하지 않는다.
