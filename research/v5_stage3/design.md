## 3. 단일 후보: 원광류 보존 + 전역 운동장/국소 잔차 보조 특징

**검증할 가설:** 기존 통계로 압축하기 전에 광류의 전역적인 공간 관계를 4계수로 요약하고 ROI별 잔차를 보조 입력으로 제공하면, 원시 광류를 지우지 않으면서 가감속·조향 분류에 필요한 구분이 추가될 수 있다. 성능 향상은 아직 미검증이다. 전역 보정 영상·새 광류 모델·신경망·새 시간 모델·새 proxy는 추가하지 않는다.

### 고정 계산 정의

1. 기존과 같은 해독·회색조·크기·DIS·10Hz 시점을 사용한다. 기존 864차원은 독립적으로 계산하여 **출력의 앞 864열을 비트 단위로 보존**한다. 추가 특징은 같은 DIS 결과를 재사용한다. 두 번째 광류 계산은 없다.
2. 기존 함수의 flow는 이미 pixel/second다. 폭을 w, 높이를 h라 할 때 `X=(x-w/2)/w`, `Y=(y-h/2)/w`, `U=flow_x/w`, `V=flow_y/w`로 둔다. 양 좌표를 모두 w로 나눠 종횡비로 회전 표현을 왜곡하지 않는다. 프레임 간 변위와 초당 속도를 혼동하여 추가 ×10을 하지 않는다.
3. 고정 표본점은 `rint(linspace(.03*(w-1), .97*(w-1),16))`의 x와 `rint(linspace(.15*(h-1), .72*(h-1),12))`의 y를 조합한 192점이다. 표본 선택에 정답·다른 영상·검증 점수를 사용하지 않는다.
4. 이 점에서 `U=tx+a*X-b*Y`, `V=ty+b*X+a*Y`라는 4계수 운동장을 맞춘다. float64 최소제곱 1회 후 **고정 3회 IRLS**를 수행한다. 각 회차 잔차 크기 e에 대해 `s=max(median(e),1e-6)`, `weight=min(1,1.345*s/max(e,1e-12))`; 두 방정식에 같은 점 가중의 제곱근을 적용해 재계산한다. 무작위 표본·학습되는 문턱·수렴에 따른 반복 증가는 없다. 최종 계수로 잔차와 가중을 다시 산출한다.
5. 최종 모델을 전체 flow 격자에 적용하고 `Ru=U-Uhat`, `Rv=V-Vhat`를 구한다. 기존 12 ROI 각각에서 median(Ru), median(Rv), p80(hypot(Ru,Rv))를 산출한다. ROI 경계는 기존 코드와 같고 NumPy 분위수 보간은 현재 기본 linear로 명시한다. 이는 **36차원**이다.
6. 전역 보조값은 tx, ty, a, b, 표본 최종 잔차 median/p80, 최종 robust weight 평균, fit_valid의 **8차원**이다. 합계 44차원이다. a/b는 2D 운동장의 팽창/회전 성분이며 실제 차량 종가속도·yaw·CAN 조향각이 아니다. 가중 평균도 배경 확률이 아니다.
7. 44차원에 기존과 동일한 raw, 평균창 5/15/31, smooth15의 lag5/15 변화량을 적용한다. 총 264차원 보조 특징, 최종 **1,128차원 = 864+264**다. 시점 보간·끝점 처리도 기존과 같다. 새로운 창·평활화 후보를 비교하지 않는다.
8. 유효 표본 16점 미만, 설계행렬 rank<4, 예외·비유한 계수이면 전역 계수/신뢰 보조값은 0, fit_valid=0으로 둔다. 잔차는 유한 값으로 정리한 원광류를 사용한다. 정상은 fit_valid=1. 단일 해독 프레임 영상은 기존과 같은 정책으로 1,128열 0을 반환한다. 실패율과 원인을 기록하되 이를 보고 ROI/문턱을 조절하지 않는다.
9. 격자·행렬·ROI 캐시는 함수의 해당 영상 호출 안에서만 유지한다. 고정 IRLS는 각 프레임 쌍에 적용하는 수치 특징 연산이다. 평가 영상의 클래스·모델·정규화 파라미터를 갱신하지 않는다. 파일 간 적응·전역 통계는 없다.

국소 물체가 화면을 지배하거나 깊이별 시차·도로 경사·카메라 흔들림이 크면 이 전역 근사가 틀릴 수 있다. 실제 도로는 단일 평면이 아니므로 잔차를 곧바로 이동 객체라고 부르지 않는다. **원광류를 보존하는 이유는 이 분해가 틀렸을 때도 원래 단서를 남기기 위해서다.** 그래도 잘못된 보조 특징을 분류기가 이용할 위험은 남는다. Stage2의 충돌 흔들림 단서를 제거하는 공용 전처리로 확장하지 않는다.

## 4. 학습 대조·분할 고정

baseline=기존864, candidate=기존864+보조264의 두 군만 비교한다. 둘의 해독 픽셀·라벨·학습행·표본 순서·class_weight·sample_weight=1·seed42는 같다. 증강·미러링·source1:1·클래스 임계값 탐색은 없다. 가감속 StandardScaler는 각 fold의 학습 자료만으로 맞춘다.

- 가감속: 현행 StandardScaler+LogisticRegression(C=.03, balanced, max_iter=2000, random_state=42).
- 조향: 현행 RandomForest(n_estimators=160, max_depth=10, min_samples_leaf=2, max_features=.4, balanced, n_jobs=2, random_state=42).
- 주의: RF max_features 비율을 유지하면 분할 때 고려하는 차원 수가 345→451로 바뀐다. 추가 특징 효과와 이 분할 후보 집합 변화가 묶인 **구조 확장 전체**의 비교이며 순수한 정보량의 인과 실험이라고 주장하지 않는다. 이를 보고 추가 max_features 후보를 탐색하지 않는다.

분할은 [V4 동결 계획](C:/Users/dsl/Desktop/Dacon/블랙박스/research/v4_stage3/experiment_plan_frozen.json)의 목록을 **그대로 복사**한다. 파일 SHA256은 `a01a9f4d555c13a0481dc1ae75c257d890b12afb9b7dc2e3de818b1644277102`다. 목록 변경·새 유리한 split 선택은 허용하지 않는다.

조향 학습·평가는 각 출처의 **정답** STOPPED를 제외한다. 예측 STOPPED로 평가 행을 제외하지 않는다. 모든 Macro-F1은 고정 전체 클래스 목록과 zero_division=0을 사용하고, route 평균을 pooled 점수로 대체하지 않는다.

알려진 OPEN_001 동일 원천 `Chunk_1/b0c9d2329ad1606b|2018-07-27--06-03-57/10` 및 해당 route를 외부 학습에서 제외한 현재 목록을 유지한다. [중복 감사](C:/Users/dsl/Desktop/Dacon/블랙박스/research/v4_stage3/overlap_audit.json). 공개 나머지4영상의 원출처 중복을 모두 배제한 것은 아니다. 따라서 공개 OOF를 완전한 원천 독립 검증이라 부르지 않는다.

이 17/6 및 V4 차량 split과 공개50은 이미 연구에 사용한 개발 자료다. 차량 stress에서는 학습할 모델에 Civic이 들어가지 않지만, 연구 전체에서 처음 보는 봉인 시험은 아니다. 공식 점수는 가설·문턱·특징 선택에 사용하지 않는다. 새로운 테스트 데이터가 생겼다는 주장도 하지 않는다.

아래는 작은 자료와 기존 실패 이력을 고려한 **보수적 제안 기준**이다. 경험적으로 최적인 문턱이라는 뜻이 아니다. root 합의 시 그대로 동결하고 결과에 따라 완화하지 않는다.

1. 계산 계약: 기존864 prefix 비트 동일, train20/stride2와 동일 픽셀10/stride1의 보조 특징/시점 동일, 모든 해독 프레임의 유한값·출력행/라벨 계약, 파일명 변경 및 다른 파일 추가 시 해당 파일 예측 동일을 확인한다. 위반하면 학습 전 중단한다.
2. 실행 예산: CPU/BLAS/OpenCV 각각 최대2스레드, GPU·추가 다운로드 없음. 공개 실제10Hz 2,998행 및 기존 반복5분 runtime 영상에서 baseline fast와 비교한다. 동일 환경 3회 중앙값의 **전체 특징 추출시간 비율 ≤1.25**를 제안 예산으로 둔다. 이 수치는 아직 달성 여부를 모른다. 실패하면 더 많은 정확도 후보를 돌리지 않고 설계 검토로 돌린다. 반복5분은 자연 연속영상이 아닌 runtime 시험이다.
3. 같은 조건 baseline 재현: 공개 기존 A=.7760091436/S=.8503042851 및 차량 stress A≈.487026/S≈.748080을 저장된 행별 예측과 대조한다. baseline의 결과/행·라벨·설정 해시가 일치하면 기존 baseline 결과를 재사용할 수 있다. 불일치는 먼저 원인을 확인하며 후보 이득으로 계산하지 않는다.
4. 차량 gate: candidate의 **두 head pooled Macro-F1 모두 baseline 이상**, S3 엄격 증가(수치 허용오차1e-12), 12 route 중 S3 증가가 7개 이상이어야 공개 OOF로 진행한다. 어느 한 head 하락을 다른 head 상승으로 상쇄하지 않는다. 실패 시 공개 추가 탐색·전체 refit 없이 미채택 종료한다.
5. 공개 gate: 두 head Macro-F1 모두 baseline 이상이고 S3 엄격 증가해야 root 채택 검토로 전달한다. 클래스별 F1·혼동행렬·영상별 변화·코덱 민감도는 모두 보고한다. 공식 정답을 사용한 코덱 진단은 임계값/후보 선택의 추가 창으로 사용하지 않는다. 공개만 상승하거나 차량만 상승하면 미채택이다.
6. 두 gate 통과는 독립 성능 증명이나 자동 제출 승인이 아니다. root가 표본 규모·출처 한계·실행시간을 검토한 뒤에만 별도 최종 학습을 결정한다. 그 전에는 전체23+공개50 refit, 최종 체크포인트, 기존 모델/ZIP 교체를 하지 않는다.

새 특징 캐시는 기존 28개 영상만 별도 연구 폴더에 저장하고 입력 manifest/픽셀 처리/코드 SHA를 기록한다. 특징 캐시 생성 약 5~15분, 통제 학습·검증 약 10~20분을 초기 작업 예상으로 잡되 **새 계산의 실제 시간은 미측정**이다. 이는 기존 V4 감사147초·학습531초를 참고한 일정 추정이지 실행 보장값이 아니다. 평가 서버의 전체 Stage1/2/3 60분 제한은 다른 stage까지 합쳐 별도 확인해야 한다.

## 6. 현재 결정 요청

학습 승인 전 합의할 범위는 **전역 운동장+잔차 264차원 한 후보, 현행864 보존, 고정 V4 split, 양쪽 head 무하락 gate**다. 이 설계는 표현 손실을 직접 겨냥하지만 두 차량 proxy의 범주·환경 편향을 해결하지 않는다. 실험이 실패하면 근거를 남기고 종료하며, 시간배율·출처1:1·배율 증강·기시도 회귀 파이프라인으로 되돌아가 추가 탐색하지 않는다.
