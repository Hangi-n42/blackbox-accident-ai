# V5 전역·잔차 후보: 동등 계산 최적화 후 차량 검증에서 기각

**최종 상태: `rejected_source_gate_no_public_oof`.** Root가 채택 중단을 확정했다. 원1,128차원 구현의 시간 탈락 기록은 보존했고, 수학적으로 동일한 구현 최적화만 별도 검증했다. 최적화는 시간 기준을 통과했지만 차량 검증 기준은 통과하지 못했다. 공개 OOF·전체 재학습·후보 체크포인트 생성은 하지 않았다.

## 1. 동등 구현 최적화

ROI 크기별 분위수 인덱스·보간계수를 사전계산하고 median/percentile의 partition 결과를 함께 사용했다. 기본 float32 median, float32 차분 후 float64 보간을 보존하고 부호가 있는0 분위수는 원래 계산 경로를 사용했다. IRLS3·고정192점·ROI·44보조값·시간 창·최종1,128차원은 바꾸지 않았다.

프로파일의 고정24개 실제 광류×10회에서 기본144 계산은1.217→0.707초, 보조44는1.391→0.948초였다. 프로파일 자체의 함수 호출 계측 비용이 있으므로 실제 전체 영상 시간과 구분한다.

| 입력 | 기존864 처리 중앙값 | 동등최적화1128 중앙값 | 비율 | 로컬 기준 |
|---|---:|---:|---:|---|
| 실제10Hz 공개5영상 2,998행 | 25.649초 | 31.514초 | 1.228672 | ≤1.25 통과 |
| 5분 반복 외부영상 3,000행 | 24.958초 | 30.608초 | 1.226390 | ≤1.25 통과 |

각3회 교차순서 중앙값이다. 기존 원후보의 시간비율1.478277/1.477398 실패를 성공으로 고쳐쓰지 않았다. 환경의 동시 CPU 작업이 다를 수 있으므로 과거·현재 절대시간 차이를 동일조건 인과효과로 단정하지 않는다. 새 비교의 동일조건 비율이 로컬 기준을 통과했다는 의미이며 서버60분 보장이 아니다.

합성32+고정실제24 광류, 공개5 원본/동일픽셀20·10Hz, 실제 Civic1분1200행, 실제10Hz 공개2998/반복외부3000행에서 전체1128 float32가 원후보와 비트 단위 일치했다. 이후23외부 학습 캐시의 기존864 prefix도 모두 일치했다. 공개·외부 fit 실패0. 파일명 변경/다른 파일 추가/단일 프레임 계약을 검사했다. 해당 IO검사는 기존864 head의 메모리상 prefix 어댑터를 사용했으며 새모델 정확도 시험이 아니다.

- 공개50 희소 GT의 반복선택 편향과 proxy/공식 범주 정의의 불일치 가능성은 그대로다. 이번 공개 OOF는 실행하지 않았다.

- 새 학습은 source용 두 분류기만 메모리에서 수행했다. 모델 파일/최종 전체자료 refit/ZIP 생성은 없다. 기존 원후보·모델·제출ZIP과 최초 시간탈락 기록의 보호검사를 통과했다.
