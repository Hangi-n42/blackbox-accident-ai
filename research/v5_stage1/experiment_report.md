## 원천 유래와 중복 점검

- 모든 DLC/comma pT는 같은 merged TPO이고 pF는 같은 `forensic_frequency_augmented.json`이다. 두 기존 동결 진단 manifest의 원모델·코드 SHA 목록이 같으며 실제 파일 해시와도 일치했다. 실행 후 다시 검증했다.
- pT의 TPO 학습 원천은 기존 물체 원본/인쇄/화면 공격 자료다. pF는 공개 5원천의 clean/JPEG75/JPEG95/half-resolution 파생 자료로 학습됐다. 이 실험에서 둘의 학습 원천을 바꾸지 않았다.
- 결합기의 fold별 학습·검증 video/document/camera/label 목록, 두 점수의 유래, 표준화·계수는 JSON에 전부 보존했다. 학습과 검증의 문서 교집합은 없다. 동시 제외에서는 카메라 교집합도 없다.
- DLC 24개 video ID가 유일하며, 취득 manifest의 JPEG SHA가 서로 다른 문서에 중복되는 사례는 없었다. 원본과 재촬영에서 같은 문서 콘텐츠가 존재하는 것은 의도한 그룹 구조다. 문자열 ID·해시 비중복이 모든 시각적 콘텐츠 중복 부재를 증명하지는 않는다.
- comma 23개는 서로 다른 segment/route이며 두 차량 계열이다. 이미 확인한 공개 중복 `Chunk_1/b0c9d2329ad1606b|2018-07-27--06-03-57/10`은 제외 상태를 재확인했다. 각 데이터의 기록된 원본 파일 SHA 간 교집합은 없었다. **서로 다른 인코딩의 파일 hash 비교만으로 추가 원천·주행 경로 중복을 배제할 수 없다.**
- CLIP 사전학습 전체와 외부 원천의 중복은 확인 불가다. DLC/comma/public은 이미 살펴본 개발 자료이며 이번 split을 만들었다고 미사용 최종 평가셋으로 바뀌지 않는다.

## 결정 및 보존

사전 gate 5개 모두 실패했다: DLC 미검출 개선과 FP 보존, comma 모든 fold FP=0, 공개 training-fit 회귀 보존, 두 카메라별 FP/FN 보존, 문서별 FP/FN 보존. **STOP**하며 threshold·C·입력 특징을 결과에 맞춰 바꾸지 않는다.

`experiment_report.json`에 전체 18fold의 OOF 점수·클래스 혼동표, 모든 comma guard 확률, 공개 회귀 혼동표, source 유래, 환경·해시·gate를 저장했다. BLAS/OpenMP는 실행 중 각각 2스레드 제한을 확인했다. 재현 도구는 `run_fusion_experiment.py`이며 frozen plan의 SHA를 명시해야 실행된다. 최종 전체 DLC 재학습이나 배포 모델 파일은 만들지 않았다.
