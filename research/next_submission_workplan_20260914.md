# 다음 제출 준비 작업과 판단 기준

2026-09-14. 사용자 요청에 따른 작업 정리다. 새 목표 설정·모델 수정·학습·추가 제출을 실행한 기록이 아니다. 공식 평가 URL의 본문과 브라우저에 표시된 수식 표를 다시 확인했다.

공식 출처: https://dacon.io/competitions/official/236753/overview/evaluation

## 평가 산식

- S1 = 원본/재녹화 Macro-F1.
- S2 = 0.35 × 충돌 Accuracy@0.3초 + 0.35 × 진입 Accuracy@0.3초 + 0.15 × 진입방향 Macro-F1 + 0.15 × 회피공간 Macro-F1.
- S3 = 0.70 × 가감속 Macro-F1 + 0.30 × 조향 Macro-F1.
- 종합 = 0.20 × S1 + 0.40 × S2 + 0.40 × S3.

산식 전개의 전체 비중은 재녹화20%, 충돌14%, 진입14%, 방향6%, 회피6%, 가감속28%, 조향12%다. 비중은 개선 가능성의 예측이 아니다.

시점은 제출한 원본 프레임 번호를 영상별 시간으로 변환하여 평가한다. 고정 프레임 오차로 대체하지 않는다. Stage3 조향 평가에서 정지 프레임은 제외되지만 모든 프레임의 조향 출력은 필요하다. 로컬 평가는 정답의 정지 마스크를 쓰며 예측 STOPPED로 평가 대상을 바꾸지 않는다.

## 다음 후보의 범위

기준은 실제 제출·평가가 완료된 V5(88887)다. S1 0.5078837545, S2 0.2281306982, S3 0.5266169416이며 V3와 같다. 종합 계산값0.40347580682는 공식 Private가 아니다. 실제 패키지를 기준으로 모델·활성 소스·입력 처리·환경·예측을 고정한다. workspace의 기본 inference.py와 버전별 실제 진입점을 혼동하지 않는다.

첫 정확도 후보는 Stage2의 진단에서 확인된 오류 하나만 수정한다. Stage1/3도 같은 제출에 반드시 새 모델로 바꿔야 하는 것은 아니다. 두 Stage의 라벨 점검과 자료 확보는 병행하며 개선 근거가 생긴 변경은 별도 비교를 거쳐 통합한다.

### Stage2 오류 분해의 의미

1. 원본 프레임/시간 대응 자체로 허용 오차를 표현할 수 없다면 자료·평가 적합성 문제다.
2. 원본에는 있지만 내부 충돌 상한 때문에 제외됐다면 탐색 범위의 문제다.
3. 범위 안에는 있지만 샘플링한 후보 사이로 빠졌다면 시간 샘플링의 문제다.
4. 후보 안에 있는데 고르지 못했다면 차량 식별·공간 해상도·의미 선택 등을 후속 단일 실험으로 나눈다.

충돌 출력은 현재 motion 최댓값이다. 큰 흔들림과 접촉 시점의 불일치를 실제 주석으로 확인한 뒤에만 별도 접촉 판정 후보를 설계한다. 단순히 창을 넓히면 정답 포함률은 올라가도 선택 실패가 늘 수 있다.

## 병행 작업

### Stage3: 기존 정답과 대리 라벨 점검

정확히 대응하는 공개 정답·CAN 구간에서 기존 대리 라벨과의 불일치를 모델 없이 측정한다. 속도·종가속도 생성 신호, 필터, 경계 전환, 시간 정합을 구분한다. 공개 희소 정답에서 공식 비공개 임계값을 확정했다고 주장하지 않는다. 기존 공개 중복 원천을 이 감사에 쓴다고 학습에 다시 넣지 않는다. 직접 비교할 수 없는 외부 라벨은 자체 기준의 proxy로 표시하고 공식 정답과 같은 신뢰도로 다루지 않는다. 현재 공개 자료는 정의 감사/개발용이고 미사용 최종 검증 자료가 아니다.

### Stage1: 실제 도로 재촬영 대응 자료

도로 원본을 실제 화면에 재생하고 카메라로 촬영한 대응 자료를 준비한다. 원천 장면·화면·촬영 카메라를 기록하고 개발/검증에서 장면과 기기가 분리되도록 설계한다. 모델을 동결해 TPO 자체 오류, forensic 자체 오류, 결합으로 생기는 검출 손실·오탐 감소를 분해한다. 합성 압축·문서 재촬영을 목표 양성으로 대체하지 않는다.

## 제출 판단 기준

이 항목은 대회가 요구하는 공식 제출 자격이 아니라 이번 프로젝트의 제안된 내부 채택 기준이다.

- 수정 대상 오류 감소와 가중 지표 개선이 미사용 원천에서 확인되어야 한다. 목표 항목만 좋아지고 다른 항목의 손실로 S2/종합 이득이 사라진 경우 채택하지 않는다.
- 결과 전에 정한 개선폭·악화 허용 범위·원천별 불확실성 기준을 충족해야 한다. 수치는 정답 품질·표본 구성·달성 가능한 검정력을 확인한 뒤, 후보 평가 전에 정한다. 임의의 영상 수를 충분한 표본이라고 선언하지 않는다.
- Stage2 일부 정답만 있다면 전체 S2 향상을 계산하지 않는다. 특히 direction/space 출력이 변하는 후보에서 해당 GT가 없으면 그 손실은 미측정이다. 완전한 GT를 확보하거나 변경 범위를 줄여야 한다.
- AI의 조건부 관찰 구간과 이미 살펴본 공개5개만으로 독립 정확도 개선을 인증하지 않는다.
- 증거가 부족하면 성능 개선 제출을 보류한다. 동등 출력/속도 수정은 운영 목적의 변경으로만 기록한다.

## 패키지 제한과 실행 가능성

공식 평가 페이지 기준 ZIP10GB/압축해제32GB, 설치10분/전체 추론60분이다. 전체 시간에는 모든 Stage의 로딩·전처리·추론·후처리·저장이 포함되고 추론 중 외부 다운로드는 불가능하다. 로컬 일부 구간 시간만으로 서버 전체 시간을 보장하지 않는다.

사람의 실제 주석과 물리적 재촬영은 AI 에이전트의 검토로 대신 완료했다고 기록할 수 없다. 현재 조건에 맞는 충분한 독립 정답 자료와 촬영 장비·작업자가 확보됐는지는 확인되지 않았다. 즉시 자동화할 수 있는 작업은 자료 목록/중복 감사, 주석 도구·양식, 평가기·오류 기록기, 기준 모델 재현 준비다. 실제 정답이 필요한 정확도 비교는 그 뒤에 진행한다.

이번 계획은 점수 상승의 보장이 아니다. 다음 제출이 무엇을 개선했는지 판단할 수 있는 근거를 먼저 만드는 절차다.
