# Stage 3 고정 시간 평활화 실험 — 채택하지 않음

## 결론

외부 검증만으로 선정한 3프레임 평균확률 평활화는 공개 영상별 OOF에서 예측을 한 건도 바꾸지 못했다. 동일한 외부 17개 학습 route 조건에서 원래 분류와 평활 분류의 Stage 3 점수는 모두 **0.759552**였다. 현재 제출 모델의 공개 OOF **0.798298**보다도 낮으므로 신규 제출 후보로 채택하지 않는다. 결과 확인 후 공개 라벨로 다른 창을 탐색하지 않았다.

현재 `model/stage3/motion_model.joblib`, `solution/stage3.py` 및 기존 제출 ZIP을 변경하지 않았다. 별도 배포 체크포인트도 생성하지 않았다.

## 사전 고정한 실험 방법

- 단일 가설: 프레임별 class probability를 고정 시간창으로 평균하면 짧은 출력 흔들림을 줄여 Macro-F1을 개선할 수 있다.
- HMM은 사용하지 않았다. 공개 정답이 6초 간격으로 희소하여 10Hz 전이확률을 공개 정답에서 추정하지 않았으며, 외부의 연속 CAN proxy 라벨을 검증에 활용했다.
- 기존 comma2k19 23개 route에서 차량별 route 해시 순서로 3개씩, 총 6개를 외부 검증으로 고정했다. 나머지 17개만 모델 학습에 사용했다. 외부 검증 route는 후속 공개 OOF 및 전체 학습에서도 사용하지 않았다.
- 외부 설정 선택용 모델에는 공개 라벨을 넣지 않았다. 정지 0.3m/s, 가감속 ±0.25m/s², 조향 ±2도라는 기존 외부 proxy 기준을 그대로 유지했다. 공식 대회 임계값이라는 주장은 하지 않는다.
- 사전 후보 창은 평활 없음, 3/5/11/21프레임이었다. 10Hz에서 각각 0.3/0.5/1.1/2.1초로 표기했다. 양 끝은 nearest padding으로 처리한다.
- 외부 검증의 가중 Stage 3 점수로 창을 하나만 선정하여 `frozen_smoothing.json`에 먼저 기록했다. 그 뒤 공개 라벨을 읽고 동일한 공개 5영상 leave-one-video-out 비교를 수행했다.
- 가감속은 기존 설정 Logistic Regression, 조향은 기존 설정 RandomForest 160개 tree를 사용했다. 조향 학습 및 채점은 정답 STOPPED 행을 제외했다. 평활 자체는 파일마다 독립적으로 적용하며 학습·갱신·파일 간 보정이 없다.

## 외부 검증 결과

6개 route의 10Hz 연속 CAN proxy 라벨 3,594개로 평가했다. 조향은 이 중 정지 513개를 제외했다.

| 고정 창 | 가감속 Macro-F1 | 조향 Macro-F1 | 가중 Stage 3 |
|---|---:|---:|---:|
| 없음 | 0.562593 | 0.700623 | 0.604002 |
| 3프레임 — 선정 | 0.562231 | 0.703790 | 0.604699 |
| 5프레임 | 0.561175 | 0.700993 | 0.603120 |
| 11프레임 | 0.563633 | 0.696876 | 0.603606 |
| 21프레임 | 0.565818 | 0.672709 | 0.597885 |

선정 창의 외부 점수 이득은 **+0.000697**이다. 가감속은 오히려 조금 낮아졌으며 조향의 작은 개선으로 가중 점수가 올랐다. 외부 validation에서 창을 선택했으므로 그 작은 이득도 독립 최종 평가의 확정 개선으로 해석할 수 없다.

외부 영상 전체의 가감속 출력 전환 횟수는 207→122, 조향은 161→113으로 줄었다. 그러나 전환 횟수가 적다는 사실은 정답률 향상을 뜻하지 않는다. 실제로 평활화는 진짜 짧은 상태 전환도 제거할 수 있다. 상세 값은 `external_jitter_diagnostics.json`에 있다.

## 공개 OOF 결과

공개 영상 하나를 통째로 제외한 5개 fold를 사용했다. 각 fold는 나머지 공개 4영상과 외부 학습 17개 route로만 학습했다. 선정된 3프레임 창 외의 공개 성능은 탐색하지 않았다.

| 비교 | 가감속 Macro-F1 | 조향 Macro-F1 | 가중 Stage 3 |
|---|---:|---:|---:|
| 외부 17개 조건, 평활 없음 | 0.742857 | 0.798507 | 0.759552 |
| 같은 조건, 고정 3프레임 평활 | 0.742857 | 0.798507 | 0.759552 |
| 현재 제출 모델 참고: 외부 23개 | 0.776009 | 0.850304 | 0.798298 |

공개 50개 가감속 라벨과 50개 조향 출력에서 raw/평활의 바뀐 예측은 모두 0건이었다. 조향 채점 대상은 정지 3개를 제외한 47개다. 현재 제출 모델 대비 -0.038745 차이는 외부 학습 route 수가 다른 비교이므로 **평활화만의 악영향으로 해석하면 안 된다**. 격리된 평활 효과는 같은 17개 조건에서의 0.000000이다.

## 시간·제약·산출물

- 전체 실험: **196.18초**, CPU만 사용. thread pool 및 RandomForest는 최대 2개 thread로 제한했다.
- 공개 5영상 양쪽 head의 평활 연산 합계: **0.000611초**. 이는 캐시된 확률에 대한 후처리 시간이며 영상 디코딩·flow 추출을 포함하지 않는다.
- 공개 라벨이 희소하므로 라벨 사이 실제 전환 경계의 정확도 개선 여부는 확인할 수 없다. 외부 CAN 범주화도 공식 정답 생성 조건과 동일하다고 볼 수 없다.
- 이번 부정적 결과는 이 고정 평균확률 가설에 대한 결과이며 HMM 등 모든 시간 모델의 효과를 부정하지 않는다.
- `report.json`: 결과, 클래스별 지표, 시간, 보호 대상 파일의 전후 확인.
- `external_split.json`: 외부 17/6 route 분리 및 검증 분포.
- `frozen_smoothing.json`: 공개 OOF 전에 고정한 단일 창과 외부 성능.
- `public_oof_comparison.csv`, `public_oof_probabilities_*.npz`: 전체 공개 OOF 재검토 근거.
- `experiment_source.py`: 실행한 실험 코드 사본. 출력 경로가 이미 있으면 중단하여 이번 결과를 덮어쓰지 않는다.

외부 데이터 출처·MIT 라이선스·원본 inventory는 기존 `external_data/comma2k19` 기록을 그대로 사용했다. 새 데이터 다운로드나 Private 점수 사용은 없었다.
