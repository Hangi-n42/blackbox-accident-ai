# 2026-09-15 검수 후속 결과와 현재 판단

**전체 원본 프레임에서 고정 C의 접촉 성공이 V5 0/6에서 3/6으로 증가했다. 현재 허용되는 다음 단계는 새 사람 검수 자료 평가이며, 후보 채택·제출은 아직 허용되지 않는다.** 아래 결과는 이미 노출된 Nexar 6개와 단일 사람 검수 초안에 대한 진단이다. 공식 점수나 완전한 S2가 아니다.

## 받은 검수 자료와 유지한 불확실성

추가 파일 4개는 신규 00004·00005·00006과 갱신 00003이다. 원본 JSON 바이트를 보존했고, 원본 영상 SHA·검수 화면의 전체 프레임 배열 SHA·원본 프레임의 native PTS 대응이 일치했다. 선택된 서로 다른 PNG 6장도 파일 SHA와 원본 디코드 RGB가 일치했다. 모든 PNG를 픽셀 비교했다는 의미는 아니다.

00003 갱신은 작성 시각과 메모만 바뀌었으며 기존 접촉·진입·공간 값은 유지됐다. 계속 같은 차로에 있었다는 설명과 **방향 빈값**도 그대로 보존했다. 00006 방향과 00004 진입 역시 미상이며 임의 정답을 채우지 않았다. 파일 무결성 통과는 사람 판정의 독립성이나 정확성을 인증하지 않는다.

## 발견한 로컬 입력 문제

기존 Nexar 입력은 원본을 10Hz로 추린 뒤 양 끝점을 강제 포함했다. 00007 마지막 구간은 직전 0.1초에서 0.033333초로 짧아졌다. 시간으로 나누지 않은 변위 차이를 jerk로 사용해, 변위 크기 2.395110→0.820796이 raw jerk 1.576394를 만들었다. C는 상한을 제거하므로 마지막 프레임의 점수 20.181040을 선택했다. MAD 분모 하한이나 PNG 손상이 원인이라는 근거는 없다.

이는 **로컬 샘플링과 특징 정의의 불일치**다. 대회 문서는 Stage2 전체·연속 프레임과 원본 번호를 요구하고, baseline의 공개 예제 준비도 전체 프레임을 추출한다. Stage3의 10Hz 규정을 Stage2로 옮길 근거는 없다. 다만 hidden FPS·JPEG 품질·디코더는 확인되지 않았으므로 이번 전체 PNG 실험을 공식 입력의 완전한 재현으로 부르지 않는다. 이 문제만으로 공식 V5 점수를 설명할 수도 없다.

## 동일 원천의 두 입력 밀도 × 두 점수 정책

접촉 성공은 원본 native PTS 기준 ±0.3초다.

| 입력·정책 | 접촉 성공 | 접촉 평균 절대오차(초) |
|---|---:|---:|
| 기존 10Hz V5 | 1/6 | 3.693009099064463 |
| 기존 10Hz 고정 C | 3/6 | 3.488760733051391 |
| 전체 프레임 V5 | 0/6 | 9.3720235806741 |
| 전체 프레임 동일 C | 3/6 | 1.7929193899782134 |

전체 프레임 V5의 다른 항목은 진입 0/5, 방향 2/4, 공간 1/6이다. 방향 Macro-F1은 0.5, 공간 Macro-F1은 0.14285714285714285다. 미상 항목은 분모에서 제외했다. C는 기존 네 질문을 다시 실행하지 않고 최종 접촉 선택만 바꿨으며, **각 영상의 진입·방향·공간과 그 진단 문맥은 그대로**다. 기존 V5 점수와 원본 번호가 정확히 재현됐고 C 점수도 특징에서 독립 재계산해 일치했다.

C에서 접촉이 허용 범위에 들어온 영상은 00000·00003·00006이다. 남은 실패는 00004(+0.400000초), 00005(-0.457516초), 00007(-9.833333초)다. 단순히 마지막 프레임 선택이 없어졌다고 00007의 접촉을 해결한 것은 아니다.

## 전체 V5 오류를 분리한 결과

- **접촉:** fine 후보에 허용 시간대가 들어 있는 영상은 4/6이지만 내부 VLM 접촉 선택은 0/6이다. 따라서 4개는 후보 누락만으로 설명할 수 없는 선택 실패다. 모든 관련 파서는 제시된 번호를 그대로 수락했다. 나머지 2개에는 fine 후보 누락도 있다.
- **진입:** 알려진 5개 중 첫 실패 단계는 내부 접촉까지의 범위 제한 1개(00007), 균등 후보 누락 1개(00000), 후보가 있는데 잘못 선택 3개(00003·00005·00006)다. 00004는 미상이라 이 분해에서 제외했다.
- 최종 motion 접촉 교체는 내부 접촉을 기준으로 만든 진입·공간 문맥을 다시 계산하지 않는다. C의 접촉 개선으로 이 세 항목도 개선됐다고 해석할 수 없다.

이 분해는 어느 단계에서 실패했는지 보여준다. 상대 차량 오인, 축소 이미지 가독성 등 각각의 시각적 원인을 확정하는 결과는 아니다.

## 실패 기록과 다음 단계

기존 10Hz C의 예약 검증 실패는 그대로 유효하다. 위 6개 합산 수치로 당시 예약 gate를 소급 통과시키지 않는다. 전체 프레임 재계산은 입력 밀도 문제가 발견된 뒤 **기존 C 코드·상한 제거·가중치를 바꾸지 않고** 사전 선언한 별도 진단이다. 전체 입력에서 성공 +3, 기존 성공 손실 0, 평균 오차 비증가와 다른 필드 보존을 확인해 `gate_advance_to_new_validation_only=true`가 됐다. `adoption_allowed=false`, `submission_allowed=false`는 유지된다.

6개는 이제 모두 노출된 개발·진단 원천이다. 다음 후보 원천 00008·00010·00013에는 실제 사람의 접촉 검수가 필요하다. 새 자료의 입력·코드·판정 기준을 먼저 고정하고 그 이후의 결과로 진행 여부를 판단해야 한다. 이번 보고서에서는 새 자료의 정답이나 예측을 생성하지 않았다.
