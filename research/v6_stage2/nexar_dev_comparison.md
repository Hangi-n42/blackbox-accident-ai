# Nexar 두 개발 초안과 동결 V5 대조

2026-09-15. `compare_nexar_dev.py`를 완료된 baseline run에 CPU로 실행했다. 원본/사람 초안/UI case/무결성 보고서/전체 native PTS/샘플 PNG/runner/선택 manifest/실행 freeze/report의 결합 검사가 통과했다. 새 추론·모델 변경·GT 승격은 없고 예약 00007의 예측은 읽지 않았다. 정확한 재현 binding과 모든 단계별 수치는 `nexar_dev_comparison.json`에 있다.

아래 오차는 **단일 사람 개발 초안에 대한 시간 차이**다. 공식 정확도, 확정 독립 검증 또는 모델 채택 지표가 아니다. source grouping 미확정, split 미배정, 독립 판정 합의 미완이며 전체 S2는 null이다.

| 항목 | 00000 | 00003 |
|---|---|---|
| 전체 원본→10Hz→정상 디코드 | 1158→402→402 | 1203→402→402 |
| 접촉 사람 프레임/초 | 584 / 20.207612457 | 582 / 19.4 |
| 접촉 fine 후보의 최근접 오차 | 0초, 정확 프레임 포함 | 0.6초, 정확 프레임 미포함 |
| 내부 VLM 접촉 선택 | 858, +9.480968858초 | 600, +0.6초 |
| 최종 motion 접촉 선택 | 587, +0.103806228초 | 345, −7.9초 |
| 진입 사람 프레임/초 | 555 / 19.204152249 | 0 / 0 |
| 진입 12후보의 최근접 오차 | 546, 0.311418685초 | 0, 0초 |
| 최종 진입 선택 | 702, +5.086505190초 | 492, +16.4초 |
| 기원측 초안/예측 | LEFT / RIGHT, 불일치 | 미입력 / RIGHT, 비교하지 않음 |
| 회피 공간 초안/예측 | 0 / 0, 일치 | 1 / 0, 불일치 |

네 사건 프레임은 모두 원본·10Hz 샘플·정상 디코드에 들어 있다. 따라서 이 네 사건의 정확 프레임 손실을 초기 10Hz 취득이나 읽기 실패로 설명할 수 없다. 원본 SHA와 모든 native PTS가 앞선 검수 무결성 기록에 대응한다.

00000 접촉은 fine 후보에 정확한 584가 있어도 VLM이 858을 골랐다. 최종 motion 대체는 이 초안 기준 ±0.3초 안으로 들어왔다. 진입은 내부 접촉 858까지의 prefix에 555가 남지만 12개 균등 후보 생성에서 빠졌고, 가장 가까운 546도 0.311418685초 차이라 ±0.3초를 넘는다. 선택된 702는 최근접 후보보다 더 늦다. prefix 종료 시점이 사람 진입보다 이른 잘림은 없었으며, 늦은 내부 접촉으로 늘어난 구간과 고정 12후보의 관계는 추가 통제 없이 인과 개선 효과로 확정하지 않는다.

00003 접촉은 fine 후보 어느 것도 ±0.3초 안에 없고, 내부 VLM은 최근접 600을 선택했다. 최종 motion 대체 345는 7.9초 이르게 만들어 이 초안 기준 오차를 키웠다. 진입은 초안의 0이 처음부터 후보에 있지만 492를 선택했다. 후보 확장만으로 고칠 수 있다고 단정할 수 없는 선택 실패다. 초안은 already_entered_at_start=true이며 side는 빈값이므로 RIGHT/LEFT 어느 쪽으로도 강제 정답을 만들지 않았다.

확인 가능한 반증은 “모든 오류가 디코드/샘플 누락이다”, “후보 안에 답이 있으면 VLM이 선택한다”, “motion 대체가 항상 VLM보다 접촉을 개선한다”가 이 두 초안 대조에서 성립하지 않는다는 것이다. 두 사례만으로 실패 유형의 모집단 비율, 최선 수정 또는 대회 점수 개선을 확정할 수 없다. 특히 00000 진입의 0.311초는 정확 시점의 사람 간 불확실성에 민감하다. ±0.3 문턱 통과 여부만 보고 검수 정확성이 증명됐다고 해석하지 않는다.

스크립트는 순수 coverage 계약 4개와 구문 검사를 통과했고 실제 대조도 exit 0으로 완료했다. 모델 출력과 정책을 그대로 보존했으며 selected 값과 parser/default 유래는 별개임을 JSON에 명시했다. parsed diagnostics를 보존했지만 독립 parser fallback 재구현은 하지 않았다.
