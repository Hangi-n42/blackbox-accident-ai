# Nexar 개발/예약 검증 원천 중복 점검

상태: **지정된 표본에서 동일 영상·같은 사고의 중복 증거를 발견하지 못함. 독립성 인증은 아님.**

대상은 Nexar 개발 00000/00003/00004, 예약 00005/00006/00007의 원본 MP4 6개와 PUBLIC_DEV 원본 `Baseline/data/stage2/videos/000001.mp4`~`000005.mp4` 5개로 한정했다. 정답·주석·모델 출력 파일을 읽지 않았으며, 외부 검색·다운로드·얼굴 또는 번호판 식별을 하지 않았다. GPU를 사용하지 않았고 CPU 스레드는 2개로 제한했다.

## 결과 전에 고정한 방법

`plan_frozen.json`에 원본 11개 및 감사 코드 SHA를 저장했다. 각 영상 처음부터 끝까지 균등한 decoded index 12개를 정하고 순차 디코드했다. 실제 프레임 수가 메타데이터와 같은지 확인했다. 저장된 전체 PNG를 전수 해시하지 않고 선택된 132개 프레임의 원본 BGR SHA만 계산했다.

모든 영상 쌍의 모든 선택 프레임 쌍을 비교했다. 전체 화면 및 중앙 80% 영역 각각에 대해 DC를 제외한 DCT pHash 63비트와 64×64 grayscale 평균 절대차를 계산했다. 사전 고정한 근접 프레임 조건은 **Hamming 거리 ≤8 AND grayscale MAE ≤0.08**이다. 동일 프레임 SHA가 하나라도 있거나, 같은 영역에서 양쪽 각각 3개 이상의 다른 프레임이 근접 대응하면 중복 후보로 표시하도록 했다. 이 기준은 검토 대상을 찾기 위한 경험적 기준이며 오류율이 보정된 검정이 아니다. 기준 밖의 모든 쌍의 최소 거리도 원본 보고서에 보존했다.

## 수치 결과

| 비교 범위 | 영상 쌍 | 동일 파일 SHA | 동일 표본 프레임 | 근접 표본 프레임 | 최소 pHash 거리: 전체 / 중앙 |
|---|---:|---:|---:|---:|---:|
| Nexar 개발 ↔ 예약 | 9 | 0 | 0 | 0 | 14 / 18 |
| Nexar 6개 ↔ PUBLIC_DEV 5개 | 30 | 0 | 0 | 0 | 16 / 16 |
| 지정 11개 전체 | 55 | 0 | 0 | 0 | 상세는 report.json |

총 55×12×12 = 7,920개 교차 프레임 쌍을 두 영역에서 비교했다. 중복 후보는 0개다. 처리 완료 실행 시간은 20.02초이며, 실행 전후 원본과 코드 SHA가 같았다.

## 표본 이미지 육안 확인

고정된 12개 표본 중 0/3/6/8/11번째를 시간순으로 배치한 두 contact sheet를 직접 확인했다. 예약 영상의 사고 시점·정답·모델 성능을 판정하지 않았으며 원천 장면 중복만 검토했다.

| 원천 | 육안으로 관측한 장면 구별 단서 |
|---|---|
| Nexar 00000 | 야간 도시 교차로, 밝은 유리 외벽 건물, 다차로 도로 |
| Nexar 00003 | 야간 젖은 노면, 나무가 많은 도로, 가까운 선행 차량 |
| Nexar 00004 | 주간 다차로 도로, 길게 이어진 붉은색 벽돌 건물 |
| Nexar 00005 | 주간 교차로, 붉은색 모서리 건물과 가림 구조물 |
| Nexar 00006 | 흐린 주간 주택가, 가공 전선과 도로 위 주황색 콘 |
| Nexar 00007 | 밝은 주간 고층 건물이 밀집한 도심 도로 |

개발/예약 표본 사이에서 같은 배경과 차량 배치가 이어지는 장면을 발견하지 못했다. PUBLIC_DEV 5개의 표본에도 이 Nexar 장면들과 대응하는 도로·건물·차량 배치가 보이지 않았다. PUBLIC_DEV 일부는 영상 외곽 프레임 또는 화면 촬영 형태가 포함되어 있어 이런 변환이 해시 비교의 민감도를 낮출 수 있다. 육안 확인은 이 자동 비교의 제한을 보완하는 제한적 검토다.

## 해석과 한계

- **근거가 있는 결론:** 지정한 파일들은 바이트가 같지 않고, 균등 표본에서 동일·근접 프레임 및 육안 장면 중복 증거가 없었다. 현재 3개 개발/3개 예약 분할에서 발견된 중복으로 합쳐야 하는 원천은 없다.
- **확인할 수 없는 결론:** 각각이 반드시 다른 사고라는 보증은 불가능하다. 한 영상당 12프레임이므로 짧은 공통 구간, 크게 자르거나 변형한 재업로드, 다른 카메라가 찍은 같은 사고는 놓칠 수 있다. 사고 식별자·촬영 시각·공식 원천 계보를 교차 검증하지 않았다.
- 파일번호가 다르다는 사실 자체를 독립성 근거로 사용하지 않았다. 동일 채널 또는 동일 제공 데이터셋은 공유하며, 차량·지역·기기·운전자 수준의 독립성까지 주장하지 않는다.
- 이 결과는 사전학습 데이터와의 비중복, 숨은 평가 데이터와의 비중복, 통계적 일반화 또는 정답 품질을 인증하지 않는다. 새 정답을 만들거나 예약 검증의 예측 결과를 열어보지 않았다.

## 재현 기록

`audit.py`, `plan_frozen.json`, `report.json`, `nexar_contactsheet.jpg`, `public_contactsheet.jpg`를 이 폴더에 보존했다. 최초 실행은 한글 경로에 대한 OpenCV 이미지 저장 실패로 종료되었다. 비교 기준을 바꾸지 않고 JPEG 메모리 인코딩 후 파일 쓰기로 수정하여 재실행했다. 최초 계획은 `plan_initial_before_path_fix.json`에 보존했다. 최종 `report.json`의 자동 상태는 이미지 육안 확인 전 상태이며, 이 문서가 육안 확인 완료 기록이다.
