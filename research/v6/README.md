## 준비 작업

- 실제 V5 제출 아티팩트의 전체 해시를 재확인하고 기준을 동결한다. 기본 workspace 진입점 대신 실제V5 추출본을 기준으로 쓴다.
- Stage2 담당: 주석/프레임 시각/실험 이력 구조, 시점 후보 오류 기록기와 공식 산식 평가기. 사람 정답 없는 실제 정확도는 미측정으로 처리한다.
- Stage1 담당: 실제 물리적 도로 재촬영 가용성 감사와 촬영·출처·기기 분할 기록 양식/검사기.
- Stage3 담당: 공개 공식 정답에 정확하게 대응하는 구간의 CAN 대리 라벨 비교. 학습·비공개 임계값 추정 없이 수행한다.
- Root: 기준 동결·자료 출처 감사·사람 검수 준비·채택 판단과 통합.

## 채택 기준의 상태

정답 품질·독립 원천·표본 구성이 아직 확정되지 않아 수치 문턱은 미설정이다. 다음 후보 예측을 보기 전에 최소 유의미 개선폭·부작용 허용 범위·원천별 불확실성 기준을 확정한다. 공식 규정과 별개의 내부 판단 기준이며 이 수치가 성능을 보장하지 않는다.

Stage2 GT 일부만 존재하면 전체 S2를 산출하지 않는다. 해당 항목 하나만 바꾸고 나머지 필드가 동일하게 유지되는 후보는 제한된 범위의 대조 실험으로 검토할 수 있지만, 먼저 정답 정의·원천 독립성·실제 시각 대응이 확인되어야 한다. 사람 주석이 이미 공개된 자료도 이 조건을 만족하는지 검토할 수 있다.
