## 다음 진행에 필요한 입력

최초 작성 이후 사용자가 PUBLIC_DEV_001 사람 검수 초안을 제공했다. 원본 50프레임의 해시·시각·픽셀 대응을 확인했고, V5와 비교한 개발 진단을 ../v6_stage2/user_review_001_summary.md에 보존했다. 접촉/진입 후보 누락은 없고 진입 시점도 일치한다. 방향은 사용자 RIGHT와 모델 LEFT가 불일치한다. 회피 공간은 후속 사용자 답변 있음(1)과 모델 0이 불일치한다. 공식 접촉 3.2초와 사용자 3.3초는 구분해 보존한다.

새 검수 후보로 공식 Nexar 공개 원본 6개(88,160,574 bytes, 7,194프레임)도 확보했다. 원본 LFS 해시와 실제 PTS 검증을 마쳤다. 이 자료는 실제 충돌과 near-miss의 구분 및 원천 중복을 검수하기 전이므로 확정 정답이나 독립 검증 집합이 아니다. 상세는 external_source_audit.md에 있다. AI의 영상 관찰을 사람 확정 정답으로 기록하지 않는다.

현재 검수 화면은 http://127.0.0.1:8766/ 에 로컬 서버를 시작했고 HTTP 200을 확인했다. Codex 패널 열기는 queued를 반환했으며 실제 표시 완료는 확인하지 않았다. 서버가 종료되면 research/v6_review_tool/dist/index.html 또는 해당 폴더의 로컬 정적 서버로 사용할 수 있다.

새 원천의 검수와 분할을 확정한 뒤 후보 예측을 보기 전에 채택 기준을 고정한다. V5 오류를 후보 장면 누락·후보 내 선택 실패로 나누고, 확인된 원인 하나만 수정한다. 수정에 쓰지 않은 원천에서 목표 오류와 부작용을 비교하고 채택 조건을 통과한 경우에만 실제 ZIP 오프라인 검사와 제출로 진행한다.

Stage1/Stage3의 자료 공백만으로 Stage2 개선 후보 제출을 막는 것은 아니다. 현재 제출을 진행할 수 없는 직접 이유는 Stage2의 새 독립 정답과 개선 증거가 없다는 점이다. 예상 점수 상승폭은 확인 불가다.
