# comma2k19 원본 주행영상: 동결 오탐 진단

실행일: 2026-09-11. 기존에 취득한 comma2k19 24개 구간 중 공개 예제와 정렬 중복이 확인된 1개를 제외하고 **23개 구간**을 평가했다. 새 데이터 다운로드, 학습, 모델·가중치·임계값·결합 비율 변경은 하지 않았다.

## 결과

|---|---:|---:|
| TPO | 4 / 23 | 17.39% |

판정 임계값은 세 방식 모두 0.5다. TPO는 영상당 12개 프레임 확률의 평균, forensic은 같은 프레임의 기존 특징 집계, 결합은 두 확률의 고정 평균이다. **원본만 있는 검사이므로 Macro-F1이나 재촬영 검출률을 계산하지 않았다.** DLC와 합친 지표도 만들지 않았다.

## 원본 라벨의 근거와 출처

공식 자료는 comma EON의 **도로 방향 카메라로 수집한 주행영상**과 CAN·GNSS 기록이라고 설명하고, 각 raw 세그먼트의 `video.hevc`를 영상 파일로 명시한다. 이번 음성 라벨 ORIGINAL은 이 수집 출처에 근거한다. 취득한 원래 HEVC를 직접 읽었으며 화면 재촬영·합성 변환을 수행하지 않았다. [공식 데이터 설명](https://github.com/commaai/comma2k19)

공식 Hugging Face 데이터 카드의 MIT 표기를 재확인했고 기존 라이선스 원문을 이 폴더의 `comma2k19_LICENSE`로 복사했다. 출처 URL, 원천 ZIP 내부 멤버, route/segment, 로컬 경로, 원본 파일 SHA-256은 `sources.json`에 보존했다. 23개 HEVC 모두 기존 `external_data/comma2k19/inventory.json`의 해시와 일치했다. [공식 데이터 카드](https://huggingface.co/datasets/commaai/comma2k19)

제외한 구간은 `Chunk_1/b0c9d2329ad1606b|2018-07-27--06-03-57/10`이다. 기존 `research/stage3_external_overlap.json`은 공개 예제와 정렬된 4개 축소 프레임의 RMSE가 0임을 기록한다. 이 한 중복을 제외했다고 모든 경로·원천 중복이 없음을 보장하지 않는다. 이 자료는 앞선 Stage 3 연구에도 사용한 외부 자료이며 모든 연구 단계에 걸친 미사용 최종 평가셋으로 주장하지 않는다.

## 프레임 선택과 실행 검증

HEVC 사전 확인에서 OpenCV의 전체 프레임 수는 음수였고, 109번 프레임으로 seek한 뒤 위치가 0으로 반환됐다. 따라서 파일 형식의 위치 이동 결과를 사용하지 않았다.

1. 원본 `frame_times` 개수로 목표 프레임을 먼저 계산했다.
2. HEVC를 처음부터 끝까지 순차 디코딩하면서 `np.linspace(0, N-1, 12).round()`의 목표 위치만 RGB로 얻었다. 이 위치 계산은 Stage 1의 균등 선택 규칙과 같다.
3. 실제 순차 디코딩 총수와 `frame_times` 개수를 대조했다. 23개 모두 일치하여 각 영상은 한 번만 순차 디코딩했다. 총수는 1,187~1,202프레임이었다.
4. 23개 × 12장 = 276장을 사용했다. 모두 1164×874 해상도다. JPEG 저장·재압축·추가 resize는 하지 않았다. 기존 모델 내부 전처리만 적용했다.

각 영상의 실제 총 프레임 수, 선택한 0-based 위치, 디코딩 RGB SHA-256, 해상도, 프레임별 TPO 확률 및 영상별 고정 확률은 `predictions.json`에 있다. 직접 기존 `sample_video`의 잘못된 HEVC 메타데이터 경로를 실행한 것과 동일하다고 주장하지 않는다. 불안정한 seek를 순차 읽기로 대체한 진단이다.

디코딩·특징·모델 추론 루프는 74.16초였으며 초기 모델 로딩은 제외된다. 가중치·설정·추론 코드의 실행 전후 SHA-256이 모두 일치한다. `frozen_manifest.json`과 `metrics.json`에 기록했다.

## 남는 제한

이 결과는 원본 23개에 대한 **관측 오탐률**이다. 0/23을 모집단 오탐률 0의 보장으로 해석할 수 없다. 특정 캘리포니아 고속도로 통근과 두 차량에 제한된 데이터이므로 한국 사고 영상·다른 카메라·다양한 촬영 조건으로 일반화되지 않는다. 실제 재촬영 양성이 없으므로 도로 영역에서 결합의 미검출 손실을 측정하지 못했다. [공식 수집 범위](https://github.com/commaai/comma2k19)

이번 검사는 모델 변경의 자동 근거가 아니다. 도로 원본 오탐과 도로 화면 재촬영 검출을 같은 원천·기기 분리 기준으로 비교할 자료가 여전히 필요하다. 학습이나 설정 변경은 수행하지 않았다.
