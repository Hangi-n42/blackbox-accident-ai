## 결론

**현재 TPO 사전학습 모델의 독립 검증용으로 TPO 데이터를 사용하면 안 된다.** 공식 자료가 전체 TPO를 학습에 사용했고 별도 검증 분할이 없다고 명시한다. 나중에 TPO를 분할하거나 같은 원천 영상의 다른 프레임을 추출해도 이미 발생한 원천 노출은 제거되지 않는다. [공식 데이터 설명](https://github.com/gurayozgur/TPO/tree/main/data)

별도 후보로 **DLC-2021의 물리적 원본 문서 영상과 화면 재촬영 영상**을 선정할 근거가 있다. 데이터 배포물의 이용조건을 직접 확인했고 실제 LCD 화면 재촬영을 포함한다. 다만 이는 문서 도메인의 외부 진단이다. **DLC 점수를 블랙박스 대회 일반화 성능으로 해석할 수 없다.** 아직 다운로드하거나 평가하지 않았다.

공식 첫 제출의 Stage 1 점수는 `artifacts/submissions/submission_status.json`에 기록된 **0.5078837545**다. 공개 합성 예제의 높은 점수가 실제 평가 점수를 예측하지 못했다는 사실은 확인되지만, 이 단일 점수만으로 실패 원인을 임계값·특징·촬영기기 중 하나로 확정할 수 없다.

## TPO: 실제 촬영 여부, 접근, 권리

| 항목 | 확인된 내용 | 사용 판단 |
|---|---|---|
| 공개 자산 | 코드와 사전학습 어댑터는 공개. 프로젝트 라이선스는 CC BY-NC-SA 4.0. | 저장소 자산의 고지와 변경내역 보존이 필요하다. |
| 데이터 접근 | 영상에서 추출한 57,408개 PNG 프레임을 연구 목적으로 신청 배포한다. 원시 영상 약 194GB는 표준 배포에 포함되지 않으며 별도 문의 대상이다. | 공개 코드 다운로드 성공이 데이터 취득 성공을 뜻하지 않는다. 이번에 신청하지 않았다. |
| 데이터 이용조건 | 저장소의 프로젝트 라이선스와 연구 목적 신청 안내는 확인했다. 신청서의 전체 약정 및 실제 데이터 아카이브 내부 라이선스는 확인하지 못했다. | 코드 라이선스가 별도 전달 데이터에도 동일하게 적용된다고 확정할 수 없다. 데이터의 대회 학습·재배포 권리는 추가 확인 전까지 미확정이다. |

근거: [TPO 공식 저장소](https://github.com/gurayozgur/TPO), [프로젝트 라이선스](https://github.com/gurayozgur/TPO/blob/main/LICENSE). 신청 양식 링크의 존재와 신청 조건 안내만 확인했으며 개인정보 제출은 하지 않았다.

TPO의 화면 재촬영은 실제 촬영이다. 원본 물체 영상을 Microsoft Surface 또는 Samsung Galaxy 화면에 표시하고 해당 기기들로 재촬영했다. 실내 동일 공간의 채소 촬영이며, 재촬영 때 반사를 줄이도록 주변 조명을 껐다. 블랙박스의 도로 장면·주행 움직임·날씨·다양한 디스플레이 조건을 포괄하는 자료로 볼 수 없다. 논문의 얼굴 벤치마크 AUC와 대상별 EER 임계값에서 산출한 HTER는 대회의 고정 판정 Macro-F1과 다르다. 저자도 영역 간 임계값 보정 문제를 기술한다. 이는 지표 해석의 제한이며 현재 제출 실패 원인의 증명은 아니다. [TPO 원논문](https://arxiv.org/html/2608.21455v2)

독립성에 관한 구체적 판단은 다음과 같다.

- TPO 프레임 전체 또는 부분집합: 현재 모델에 대한 **학습 자료 재평가**다.
- TPO 원시 영상의 미추출 인접 프레임: 동일 콘텐츠·촬영 세션이므로 독립 검증으로 인정할 수 없다.
- TPO에서 원천·기기를 나누는 검증: 처음부터 해당 원천을 배제한 별도 재학습을 할 때만 의미가 있다. 현재 사전학습 체크포인트의 노출을 되돌리지는 못한다.
- 논문에 등장하는 얼굴 PAD 벤치마크: 현재 TPO 체크포인트의 하위 학습 자료와 저자의 평가 자료를 구분해야 한다. 저자 평가에 이미 사용된 자료라는 점과 각 데이터 이용조건도 별도로 기록해야 한다.
- CLIP 기반 모델의 전체 사전학습 이미지 목록과 후보 데이터 간 중복 부재는 확인하지 못했다. 아래의 ‘외부’는 확인된 TPO 후속 학습 원천과 별개라는 의미이며, 모든 사전학습 단계에서 완전히 미노출임을 보장하지 않는다.

**접근·이용조건:** Zenodo Part 2의 화면 재촬영 파일은 공개 다운로드 항목으로 제공되며 총 **38.5GB**의 분할 압축 파일이다. 이번 조사에서 미디어를 다운로드하지 않았다. 이 버전 배포물의 `license.txt`는 **CC BY-SA 2.5 Generic**을 명시하며, 얼굴 이미지 출처 Generated Photos의 기여 표시를 권장한다. 이것은 저장소 코드나 논문의 라이선스를 대신 적용한 판단이 아니라 데이터 배포물의 라이선스 확인이다. 출처 표시와 공유조건을 보존해야 하며 독점 권리 양도 가능성까지 의미하지 않는다. [확인한 배포 버전](https://zenodo.org/records/6466770), [데이터 라이선스 파일](https://zenodo.org/records/6466770/files/license.txt?download=1)

### 작은 메타데이터 및 원격 부분 읽기 실측

2026-09-11에 위 버전의 `README.md` 5,340바이트와 `dlc-2021.csv` 70,444바이트를 취득했다. 두 파일의 MD5가 Zenodo 표시값과 일치한다. CSV는 헤더 없는 세미콜론 구분 1,424행이다. 이 파일들과 HTTP 응답 요약은 `research/stage1/dlc_metadata/`에 보존했다. [공식 README](https://zenodo.org/records/6466770/files/README.md?download=1), [공식 CSV](https://zenodo.org/records/6466770/files/dlc-2021.csv?download=1)

CSV를 직접 집계한 결과, 문서 종류/두 자리 식별자 조합은 `or` 80개, `re` 73개이며 교집합은 73개다. 이는 **같은 문서 콘텐츠 그룹으로 연결할 수 있음**을 뜻한다. `00.or0001`과 `00.re0001`의 일련번호가 같다는 이유로 같은 원천 영상의 재생 짝이라고 단정할 수는 없다. CSV에 그런 일대일 대응표는 없다. 이후 분할은 `alb_id/00`처럼 문서 종류와 식별자를 함께 사용하고 모든 촬영·파생 프레임을 묶어야 한다.

CSV의 `re` 화면 표기는 `philips` 160개, `macbook pro` 160개, `lenovo` 40개, `hp` 40개이며 각 표기 내에서 `iphone`/`android`가 반씩이다. 제조사·제품군 수준 표기는 확보했지만 정확한 LCD 모델·세대·패널 사양은 여전히 확인 불가다. 특정 화면별 데이터량이 다르므로 기기별 결과도 함께 봐야 한다. 이 수치는 논문 수치를 추정한 것이 아니라 보존된 CSV를 집계한 값이다.

**원격 파일 목록 확보는 성공했다.** `re.zip`에 마지막 65,557바이트를 요청했고 HTTP `206 Partial Content`를 받았다. ZIP 종료 레코드에서 중앙 디렉터리 위치를 읽은 뒤, `bytes=4167714927-4170685686`의 **2,970,760바이트**만 추가로 읽었다. 응답 범위·길이를 검증했고 미디어 payload는 읽지 않았다. 결과를 `re_archive_index.csv`와 `index_summary.json`에 저장했다.

- 파일·디렉터리 항목 23,131개 중 영상 400개, JPEG 21,896개, 주석 JSON 400개를 확인했다.
- 목록에는 경로, 압축/원본 크기, 시작 분할 번호, 로컬 헤더 위치, 압축 방식, CRC32가 있다. 영상 payload 합계는 31,370,471,599바이트, JPEG payload 합계는 7,136,908,660바이트다. 이는 전체 압축 묶음 크기와 다른 목록 집계값이다.
- 원격 부분 읽기가 지원되고 위치 정보를 확보했으므로 **선택한 파일만 가져오는 구현의 근거는 확보했다.** 단, 실제 선택 추출은 아직 하지 않았다. 개별 자산 추출에는 로컬 헤더 검증, 분할 경계 처리, CRC 확인이 추가로 필요하다.
- 예를 들어 JPEG 한 항목의 압축 크기는 533,623바이트다. 일부 프레임 진단은 전체 38.5GB 취득보다 훨씬 작은 전송으로 구현 가능하지만, 프레임만 평가한 결과는 최종 영상 추론 평가와 구분해야 한다.
- Part 1의 압축 파일 목록·원본 영상 payload는 이번에 읽지 않았다. 원본까지 포함한 선택 취득 총량은 아직 산정하지 않았다.

기술 확인에 사용한 공식 자산: [Part 2 분할 ZIP 마지막 파일](https://zenodo.org/records/6466770/files/re.zip?download=1). 이 URL은 대용량 파일이므로 전체 다운로드 대신 위 HTTP Range로 메타데이터만 읽었다. 이번 실제 전송은 작은 설명 파일과 ZIP 목록에 한정되었다.

**도메인 한계:** DLC는 정지 문서 이미지를 화면에 표시한 뒤 촬영한 영상이다. 움직이는 주행영상의 재생을 촬영한 블랙박스 자료와 시간적 패턴이 다르다. 화면 질감·반사·촬영 변환에 대한 외부 진단에는 사용할 수 있지만, 도로영상의 원본 오탐률이나 실제 대회 재촬영 검출률을 직접 추정하지 못한다.

## 후속 실행안 — 미실행 제안

1. 현재 모델과 임계값을 고정한 상태에서 DLC의 `or`/`re`만 평가하는 비용을 먼저 산정한다. TPO 취득은 독립 검증 확보 목적으로 추진하지 않는다.
2. 동일 문서 원천·물리적 표본·재촬영 파생본·추출 프레임을 하나의 콘텐츠 그룹으로 관리한다. 영상 단위 Macro-F1, 혼동행렬, 기기별 결과를 기록하고 프레임을 독립 표본으로 계산하지 않는다.
3. DLC 결과를 보고 모델 선택이나 임계값을 변경하면 이후 DLC 성능은 개발 결과다. 추가 학습에 사용하려면 원천 그룹과 가능하면 촬영기기를 개발/최종 검증으로 먼저 분리한다. 충분한 메타데이터를 확보하지 못한 축의 독립성은 주장하지 않는다.
4. 대회 영역의 개선을 판단하려면 별도로 적법한 원본 주행영상과 실제 화면 재촬영 짝을 확보하고, 원천 영상·카메라·디스플레이·세션을 분리한 검증이 필요하다. DLC 평가만으로 이 단계를 대체하지 않는다.

현재 선택: **DLC를 별도 영역의 실제 화면 재촬영 진단 후보로 유지한다. 다운로드 및 다음 학습 자료 확정은 아직 하지 않았다.**
