## 데이터와 도구 보완

사용자의 실제 검수 JSON·원본·case·PNG10,811개 해시 보존을 확인했다. 추가3개 entry 선택 이미지의 원본 RGB/nativePTS 대응도 일치했다. 검수 UI의 프레임 로드·표시·기록을 묶고 export 시작 시 자료를 복제하여 빠른 이동/느린 로드 중 대응이 어긋날 수 있는 경로를 수정했다. 해당 오류가 과거 검수에서 실제 발생했다는 증거는 없다. 관련 합성/기존 회귀 검사와 실제 브라우저의 기본 이동·이미지/번호 대응·선택지 배치 확인을 통과했다. 느린 로드 경합은 통제 시험으로 검증했으며 실제 브라우저에 인위적인 네트워크 지연을 주지는 않았다. 브라우저에 남은 이전 초안은 최신 제출 JSON과 별개로 보존했다.

모델 결과 전에 번호순으로 고정한 신규3원천을 두 전문가가 서로의 답과 후보 출력을 보지 않고 AI 시각 검토했다. 최초 접촉을 직접 확정한 정답은0개다. 00015에 한 검토자는 파편을 포함한 강한 접촉 추론 구간을 기록했고 다른 검토자는 화면 밖 접촉을 확정하지 않았다. 불일치를 지우거나 AI 합의를 사람 정답으로 승격하지 않았다. 00014/00016의 흔들림·근접 구간도 정답으로 채우지 않았다.

## 이어서 확인할 문제

복잡한 출력 schema·잘못된 참조·현재 모델의 사건 판별 능력을 분리해야 한다. 문구를 바꾸어 동일 소표본을 반복 맞추는 방식은 채택 근거가 약하다. 기존 과업 분해와 거의 같은 재설계의 위험을 전문가가 검토했고, 공식8B 모델의 자산·설치·메모리·시간 조건을 확인했다. 고정 revision의17,545,914,364bytes 취득을1,774.172초에 마치고 각 파일 SHA/원본 Git blob을 확인했다. 기존 정책의8B9개 실행은 완료·네트워크0이나 위 개발 기준에서 실패했다. 실제9개 ask 누적시간은 archived4B82.903초 대비8B132.328초(1.596배)였다. 동시 무작위 비교나 전체 서버60분 예측은 아니다.

원저자 TPO 전처리 감사에서도 전체224×224 Resize, RGB와 정규화 계약의 명백한 불일치는 발견되지 않았다. 표준 CLIP 중앙 자르기로 바꿀 버그 근거는 없다. 자세한 원문 출처·검사 범위는 `stage1_preprocessing_audit.md`에 기록했다.

8B 비교는 실패한 통합 사건 계획을 채택하는 시험이 아니다. V6의 기존4회 질문 정책·최종 motion 접촉 선택은 유지하고 체크포인트만 바꾼다. 따라서 이 시험에서 접촉 정확도는 구조상 바뀌지 않고 진입·방향·공간을 비교한다. 공식8B의 vision encoder도4B와 달라 순수 언어 파라미터 수 효과로 해석하지 않는다. CPU FP16 입력 embedding 조회의 사전4B 검증에서 같은 실제4질문의 원문 답변은 모두 일치했지만, 이는8B 메모리·전체 정확도·내보내기 검증이 아니다. 4B는 입출력 가중치가 묶여 있어 해당 시험에 메모리 절감 성과를 주장하지 않는다.

8B 전체GPU 실행은 기존1.2MP 예산에서 성공하여 CPU embedding 정책은 적용하지 않았다. 이어서4B에서 실패했던 동일한 통합 사건 계획 SHA를8B에 적용하는 네 번째 조합을 별도 고정했다. 이는 기존8B×V6 결과와 구분한다. 같은 source/render 규칙을 써도 응답에 따른 후속 이미지가 달라질 수 있으며, 네 조합은 노출된 개발자료의 기술적 비교일 뿐 독립 검증이 아니다.

## 이번 후보 비교의 종료 판단

실행한 정확도 후보는 모두 사전 기준 실패로 보존한다. 큰 모델·복합 질문 구조·시간 모델·최종접촉 공간문맥 어느 것도 이번 자료에서 채택 조건을 통과하지 않았다. 전문가가 실제8B 시트3개를 검토했으며 서로 다른 차량을 같은 사건의 상대처럼 처리한 사례와 fallback 우연 일치를 확인했다. 실패한 구조의 일부를 사후 섞는 추가 후보는 이번 사이클에서 실행하지 않는다. 현재9개로 문구·window·gate를 다시 맞추지 않는다.

모든 이번 GPU 실행은 종료했다. 새8B NF4 export·ZIP·V7 제출은 하지 않았고 기존 제출자산은 유지했다. V7 제출 목표는 미완료다. 상세 수치·수정·한계·후속 데이터 조건은 `research_decision_20260915.md`에 정리했다. 이를 목표 달성으로 표시하지 않는다.
