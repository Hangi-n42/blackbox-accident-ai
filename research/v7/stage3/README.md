# V7 Stage3: 추가 가능성 시험

이 실험은 최초 제안의 RAV4→Civic 및 공개 그룹 OOF 채택 시험을 대체하지 않는다. CPU 2스레드·단일 학습 15분 상한에서 작은 시간 head의 실행 가능성과 경로 제외 성능을 확인하는 추가 시험이다. 기존 17/6 분할은 이전 실험에서 사용됐다. 6개 경로는 이번 학습에서 제외되지만 새 독립 검증이라고 부르지 않는다. 결과가 좋아도 이 시험만으로 V7 Stage3를 채택하지 않는다.

## 변경한 구조와 유지한 조건

기존 864개 특징과 가감속 Logistic/조향 RF를 같은 외부17 학습행·설정·seed42로 재학습한다. 이전 외부6개 경로의 저장된 확률과 비교하여 기준을 재현한다. 배포 모델은 23개 외부 경로와 공개 GT를 학습했으므로 그대로 외부 검증에 사용하지 않는다.

새 head는 144→32 projection, kernel3/dilation1·2·4·8 convolution, 7개 logit 보정이다. 중심±15의 31개 광류 시점만 사용한다. 출력 층은 0으로 시작하고, 기존 log 확률에 보정을 더한다. 클래스 균형 가중치와 조향의 GT STOPPED 제외를 유지한다. 학습행은 외부17의 기존 2Hz 행, 정규화 통계도 외부17에서만 계산한다. 40epoch의 마지막 상태 한 번만 평가한다. 공개 정답으로 학습하거나 epoch를 선택하지 않는다.

기존 캐시의 첫144를 모든 행에서 raw로 오인하지 않는다. 20Hz/stride2의 광류 중심은 decoded index1,3,…이므로 정확한 중심 행의 첫144를 선택한다. 이를 이용한 864 재구성 28개 캐시 전부와 실제 영상 2개 광류 재계산이 비트 단위로 일치해야 학습한다.

## 기록과 한계

- 최초 `frozen_plan.json`, `raw_recovery_audit.json`, `baseline_reproduction.json`은 보존한다. 최초 실행은 Windows int32 라벨 오류로 첫 optimizer step 전에 중단됐다. `dtype_failure_record.json`과 원래 소스가 남아 있다.
- 자료형만 int64로 수정한 실행은 `dtype_fix_run/`에 별도로 기록한다. 구조·분할·최적화 설정·기준은 변경하지 않았다.
- OPEN_001의 공식 공개10 GT는 가감속이 전부 CONSTANT다. 정확 대응 외부 원천 전체를 학습에서 제외해도 이10개로 가감속 다른3클래스 성능은 알 수 없다. 이미 검토한 공개 GT이므로 새 검증도 아니다.
- 외부 평가 정답은 속도 미분/조향 임계값 proxy다. 공식 범주 정의의 동일성을 입증하지 못한다. 두 차량을 훈련에 포함하므로 새로운 차량 일반화를 검증하지 않는다.
- 고정 기준 모델의 학습행 예측 위에 보정 head를 학습한다. 이 예측은 out-of-fold가 아니어서 보정 과적합 위험이 있다. 시간 순서, 새 모델 용량, 비선형성의 효과를 이 한 실험에서 인과적으로 분리하지 않는다.
- CPU 시간은 캐시 이후 두 head를 각3회 교차 순서로 측정하고 별도로 측정한 광류 시간을 더해 추정한다. 전체 파일의 반복 end-to-end 벤치마크나 서버60분 보장이 아니다.
- 기존 코드·모델·ZIP은 변경하지 않는다. 새 배포 가중치를 저장하지 않는다. 실제 채택은 원래 검증 기준을 갖춘 추가 근거와 root 판단이 필요하다.

실행 소스: `run_temporal.py`. 원본 연구 근거: `../validation_and_resource_plan.md`.
