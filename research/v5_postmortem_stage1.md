## 2. 실제 구조와 로컬에서 확인한 실패

**검증 대상과 학습 현상이 다르다.** 공개 학습은 원본 5개와 같은 원천의 simulated 재촬영 5개다. 변형을 포함한 40행은 독립 원천 40개가 아니라 5그룹이다. TPO는 물체 원본/인쇄/화면 공격을 학습했으며 도로 화면 재촬영만의 분류기가 아니다. DLC는 문서 촬영이고 comma는 도로 원본만이다. 현재 진단 기록에는 실제 도로 콘텐츠를 화면에 재생하고 다시 촬영한 양성이 없다. 근거: `research/stage1/training_manifest.json:5`, `:45`, `:48`; `research/v5_stage1/diagnosis.md:11`, `:13`, `:15`.

**현재 forensic 표현은 해상도와 시간에 제약이 있다.** 프레임당 native 최대 192픽셀 패치 5개를 계산하고 median/q90으로 집계한다. 선택된 22개 특징은 주파수 계열이며 계산한 화면 가장자리 특징은 최종 모델에 들어가지 않는다. 시간 순서를 모델링하지 않는다. TPO는 전체 프레임을 작은 정사각형으로 resize하고 12개 프레임 점수를 평균한다. 원래 물리적 재촬영 증거 중 무엇이 손실되는지는 직접 대조가 없어 확인 불가다.

근거: 제출 코드 `artifacts/submissions/verify_v5/model/stage2/code/solution/stage1.py:70`, `:74`, `:87`, `:95`; 제출 forensic artifact `model/stage1/forensic_frequency_augmented.json:4`; 제출 TPO runtime `stage1_tpo_merged.py:39`.

공개 clean에서 forensic F1=1.00000이었던 기존 진단은 half-resolution에서 0.45055, 고정 결합은 0.69697이었다. 크기 변환에 대한 안정성이 확보됐다는 주장은 반증된다. 다만 축소는 실제 주파수 증거도 바꾸므로 이것만으로 공식 오류가 resize 때문이라고 단정하지 않는다. `research/v5_stage1/diagnosis.md:19`.

**0.5 평균은 실제로 상충하는 두 모델을 결합한다.** 제출 코드 `stage1_v4.py:137`의 규칙은 `p=(pF+pT)/2`, 재촬영 조건은 `pF+pT>=1`이다. pF가 낮으면 pT>=0.5인 검출도 소실된다. 반대로 pF가 낮아서 TPO의 원본 오탐을 막기도 한다.

## 3. V5 실험·선택의 문제와 타당했던 결정

V5의 단일 CPU 결합기 실험은 고정 logit 두 개, fold 안 표준화, L2 logistic C=0.1, threshold=0.5를 결과 전에 동결했다. 문서 제외 OOF F1은 0.73333→0.74286이지만 FP가 0→1로 증가했고, 문서·카메라 동시 제외 F1은 0.58042였다. comma에서는 여섯 fold 모두 오탐이 생겼다: 4, 6, 1, 4, 8, 4 /23. 후보는 gate 5개 모두 실패해 미채택됐다. 근거: `research/v5_stage1/experiment_report.md:7`, `:21`, `:24`, `:38`, `:73`.

이 작은 F1 증가만 보고 채택하지 않은 결정은 타당하다. 전체 fold 공개, 원천 분리, 결과 전 기준 동결, 실패 후 재튜닝 금지는 선택 편향을 줄였다. 그러나 실험의 한계는 다음과 같다.

- **가장 치명적:** 결합기 학습도 양성 검증도 문서 재촬영에만 있다. 목표 도로 재촬영으로의 전이를 검증할 수 없는 설계다. 마지막 결합 계수 조정은 표현 자체가 목표 증거를 추출하는지 답하지 못한다.
- 카메라 동시 제외는 학습 행도 20→10으로 줄인다. 성능 차이가 카메라 변화만의 효과라고 분리할 수 없다. 디스플레이 holdout도 확보하지 못했다.
- 공개 GT는 forensic 학습과 과거 특징/결합 선택에 이미 사용됐다. 최종 artifact의 공개 검사는 training-fit 회귀 검사이며 독립 검증이 아니다. 기존 DLC/comma 역시 이미 본 개발 자료다.
- 모든 fold에서 comma FP=0 유지 등의 엄격한 기준은 위험 통제 정책이지 통계적 최적성의 증명이 아니다. 실패는 이 한 후보를 배제할 근거이며 모든 학습 결합기의 불가능성 증명이 아니다.

결국 V5 회차는 근본 병목을 해결한 분류기를 제공하지 못했다. 실패 변경 제외와 기존 분류기 보존은 증거에 근거한 방어지만, 같은 모델의 재제출 자체로 새로운 Stage1 개선 가설을 시험한 것은 아니다. 실행 안정성 및 다른 stage 변경의 검증 가치는 별도다.

## 5. 다음 한 가지 반증 실험 제안 — 실제 도로 재촬영에서 veto 기여도 분해

**제안이며 이번에는 실행하지 않았다.** 가설은 “실제 도로 화면 재촬영에서 현재 결합의 미검출 중, TPO 자체 미검출보다 forensic에 의해 소실된 TPO 검출이 더 많다”이다. DLC 결합기를 다시 맞추는 실험을 반복하지 않는다. 현재 TPO·forensic·0.5 결합·threshold·프레임 선택을 모두 동결한 채, 실제 물리적 재촬영 대응쌍만 새로 관측한다.

사전 계획 예시: 이용 허가와 원천 출처가 명확하며 기존 public/DLC/comma와 겹치지 않는 도로 원본 6개를 결과 전 고정한다. 각 원본을 디스플레이 2종×재촬영 카메라 2종의 모든 조합에서 물리적으로 재촬영해 원본 6개+재촬영 24개를 만든다. 이 숫자는 최소 진단 설계 제안이지 통계적 충분성 근거가 아니다. 그런 장비·자료·허가가 확보됐는지는 현재 확인 불가다. 디지털 변형으로 물리적 재촬영을 대체하지 않는다.

콘텐츠/주행 구간과 모든 파생본은 같은 source-group으로 묶고 원본 촬영 카메라·디스플레이·재촬영 카메라·촬영 조건·전달 codec·실제 decode 프레임 수와 위치를 기록한다. 카메라/디스플레이의 특정 조합을 임의로 좋은 예만 선택하지 않는다. 원본·재촬영 모두 같은 배포 크기와 codec 규칙을 사전에 적용한 진단 입력을 사용하고 취득 원본도 보존한다. 공통 변환이 물리적 증거를 지울 수 있으므로 결론의 범위는 해당 전달 조건으로 한정한다. 내용·장비별 행을 공개하고 프레임을 독립 표본으로 세지 않는다. 추론 전에 선택 목록·파일 SHA·취득 사실에 근거한 class 라벨·모델 SHA와 판정 기준을 동결한다. 학습·threshold 탐색은 없다.

현재 결합이 미검출한 실제 재촬영마다 다음 두 수를 센다. (A) pT>=0.5인데 pF+pT<1인 veto 손실 수, (B) pT<0.5이며 결합도 미검출한 수. A>B일 때만 이 작은 진단에서 “veto 손실이 더 많다”는 가설과 부합한다. A<=B이면 해당 진단에서는 가설을 반증하며, 결합만 조정하는 방향을 우선하지 않는다. 미검출이 하나도 없으면 두 원인을 비교할 실패 사례가 없으므로 원인 우선순위는 미결정이다. source별·장비 조합별로 따로 표시하고, 양성만의 개선 해석을 막기 위해 대응 원본 FP도 함께 기록한다.

이는 원인 분해용 실험이며 TPO 단독/새 결합 채택 실험이 아니다. A가 크더라도 원본 오탐 손실과 미사용 도로 양성 holdout 검증 없이 모델을 바꾸지 않는다. 이 작은 자료를 본 뒤에는 개발 자료가 되므로 이후 학습과 최종 채택 검증에 재사용하지 않는다. 실제 도로 재촬영 취득이 불가능하면 이 실험은 실행 불가로 남기고, 현재 자료만으로 목표 도메인의 원인 우선순위를 확인했다고 주장하지 않는다.
