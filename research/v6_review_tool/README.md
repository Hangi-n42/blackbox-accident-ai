3. 식별/접촉/진입을 확정할 수 없는 경우 판정 불가와 사유를 남긴다. 대회 기준에 맞는 방향과 회피 공간도 판독 가능한 경우만 기록한다.
4. 예측/다른 사람의 답을 보지 않았는지 사실대로 체크한다. 현재 공개 예제는 과거 모델 개발 노출 이력이 있으므로 체크하더라도 평가용으로 바뀌지 않는다.
5. 초안 저장 버튼으로 JSON을 내려받는다. 브라우저 임시 저장만 믿지 말고 파일을 보존한다.

같은 브라우저 프로필은 이전 초안을 자동 복원한다. 서로 독립인 두 검수자는 서로 다른 브라우저 프로필/기기를 사용하고 다른 사람의 초안을 보지 않아야 한다. 두 파일을 모은 뒤 불일치 조정자가 별도 조정 기록을 작성한다. 검수자 이름과 체크박스는 신원·독립 검수의 자동 인증이 아니다.

## 새 원본 등록

`prepare_case.py`는 원본 영상의 전체 프레임과 native PTS를 읽어 새 폴더만 만든다. 완성된 기존 영상과 주석은 덮어쓰지 않는다. --resume은 case.json이 아직 없는 불완전 추출에만 허용하며, 기존 프레임의 픽셀을 원본과 비교해 재사용한다. 잘린 인코딩 파일은 .interrupted.png로 보존하고 재생성하며 UI 목록에 넣지 않는다. PNG는 손실 없이 저장한다. 원본의 decoded 순번을 0부터 보존하고 FPS로 시각을 만들어내지 않는다. 이미지 폴더 자료의 기존 번호/PTS는 별도 정확한 원본 매핑 없이는 이 경로로 변환하지 않는다.

원본 경로, case ID, 원천 그룹, 출처 URL, seen/unseen 노출 이력을 인수로 전달한다. unseen은 홀드아웃으로 인증됐다는 뜻이 아니며 split은 unassigned다. 원천 중복과 사용 조건을 확인한 뒤 개발/평가 분할을 정한다.

새 영상 확보와 기존 공개 1건의 사람 검수는 진행됐으며 새 영상의 사람 검수·독립 정확도 검증은 미완료다. AI가 이 화면으로 주석한 결과를 사람 주석으로 기록하지 않는다. 브라우저 시각 QA는 수행하지 않았고 JS 문법·상태 기능 및 원본 프레임/PTS 결합을 로컬 검사했다. WebMCP 읽기 보조 API는 지원 브라우저에서만 등록되며 실제 지원 컨텍스트 검증은 미수행이다.
