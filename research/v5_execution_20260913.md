# V5 작업 기록 — 진행 중

사용자 목표: 이번 회차 문제를 전문가 에이전트들과 분석하고 원인을 해결하는 방향으로 수정한 뒤 V5 실제 제출까지 진행한다. V4 제출과 평가는 이미 완료되었다. V5는 아직 제출하지 않았다.

## 확인된 출발점

- V4 공식 제출 88503: Stage1 0.5078837545, Stage2 0.217521476, Stage3 0.5266169416, 실행 44분33초.
- V3 대비 Stage2 -0.0106092222. Stage1/3 예측 점수는 동일하다. V4를 성능 개선 성공으로 취급하지 않는다.
- 연구 PNG/PIL JPEG와 실제 cv2 JPEG의 픽셀이 달랐고, 동일 모델의 일부 Stage2 답변/후속 탐색 창이 달라졌다. 같은 입력 재현은 통과했다. 입력 표현에 대한 민감성과 앞선 답의 오류 전파를 분리해 검증한다.
- 공개 Stage2 원본은 5개다. 세 표현을 만든다고 독립 영상 15개가 되지 않는다.

## 병렬 검증과 채택 기준

- Stage1: 문서/촬영기기 분리 검증과 도로 원본 오탐 방지 기준을 사전 고정한 단일 결합기 실험. 기준 미달로 채택하지 않는다. 세부 결과는 v5_stage1/experiment_report.md.
- Stage2: 대상 차량 고정 → 전체 구간의 차선 진입 탐색 → 국소 확인 → 방향/공간 분류 분리. 네 번 호출, 원본 프레임 번호, 파일별 독립 상태를 유지한다. 움직임 최댓값을 충돌의 완전한 대체물로 인정하지 않는다. 잘못된 움직임 시각 때문에 유효한 진입 답을 거부하지 않는다.
- Stage2 최초 화면 배치에서 네 패널이 canvas의 19.4%만 사용한 결함을 발견했다. 최초 실행/소스/동결 기록을 보존하고 2×2 배치(77.6%)만 수정해 재동결 후 재실험한다. 의미 규칙이나 답에 맞춘 임계값 조정은 금지한다.
- Stage2 동일 원본 PNG/JPEG/좌우반전 입력의 V3/V5 쌍 비교를 실시한다. 표현별 시간 비율 ≤1.25와 VRAM 한도는 결과 전에 고정했다. 로컬 비율은 서버 전체 시간 보장이 아니다.
- Stage3: 원래 864 특징에 전역 움직임/국소 잔차 264 특징을 추가한 실험은 시간 비율 약1.478로 1.25 기준 미달. 정확도 실험 전에 동일 특징을 수치 변경 없이 계산하는 최적화 한 회만 허용했다. 원래 실패 기록은 보존한다.

## 독립 데이터 검증의 범위

DADA 저자 공개 저장소의 사용·공유 초대 문구와 공개 파일 출처를 확인하여 로컬 비상업 연구용으로 12개 영상을 사전 선정했다. 전체 대용량 자료를 받지 않고 원본 RGB 파일 범위만 추출해 CRC와 SHA를 검사했다. 명시적인 표준 데이터 라이선스와 모든 제3자 권리의 포괄 보장은 확인되지 않았다. 데이터는 학습하거나 제출 ZIP에 포함하지 않는다.

예측을 보기 전에 두 AI 검토자가 대상 차량, 차선 진입, 접촉 가능 구간을 독립 기록한다. AI 시각 검토는 공식 정답도 실제 인간 전문가 검수도 아니다. 제공 사고 프레임은 자동으로 대회의 최초 접촉 정답이 되지 않는다. 제3자 사고/접촉 확인 불가/모호한 항목은 제외 또는 진단용으로만 보존한다. 원본 출처 그룹이 모두 독립인지는 확인 불가다.

## 당시 남은 작업 (최종 상태는 아래 접수 완료 기록 참조)

후보 실험과 외부 검증을 완료하고 채택 근거를 확정한다. 이후 격리된 V5 ZIP 구성, 실제 추출 ZIP 오프라인 추론, 파일별 독립성과 출력 형식/시간/크기 검증, V5 제출 및 공식 접수·결과 확인을 진행한다. 아직 성능 향상이나 근본 원인 전체 해결을 주장하지 않는다.

## 중간 결정

- Stage2 ROI 후보는 전체 30clip/120call 실행 완료. 시간 비율 PNG1.7835/JPEG1.5552/좌우반전1.4521로 사전1.25 기준을 모두 초과하여 채택 중단했다. 잘못 지정한 도로/보닛 ROI도 기하 추적을 통과한 직접 관찰이 있다. 복잡한 상태 응답 실패를 첫 프레임 기본값으로 바꾸는 문제도 확인했다. 외부 검증 추론에는 사용하지 않는다.
- 이 실패에 대응한 단일 단순화 후보만 추가 승인했다. V3의 최종 충돌값에 사용되지 않는 VLM 충돌 정밀 질문을 전체 구간 차선진입 질문으로 재배치하고, 다음 질문을 국소 진입 확인에 사용한다. bbox/추적/복합 상태를 없애고 간단한 entry_frame JSON을 유지한다. 공간 문맥은 실제 출력 충돌 시각인 motion 주변으로 통일한다. 따라서 공간 예측 변화도 별도 비교한다. 총4회·192토큰 이하, 같은 시간 기준으로 결과 전에 고정한다. 이 후보까지 실패하면 추가 탐색을 중단하고 기존 검증 결과에 근거한 안전한 조합을 선택한다.
- Stage3 동일 특징 최적화는 공개1.22867176·외부1.22639043으로 시간 기준을 통과했다. 수치 동등성 검사를 통과한 뒤에만 사전 동결된 차량 분리 정확도 실험으로 진행했다. 아직 정확도 향상이나 최종 채택은 확인되지 않았다.
- DADA 독립 검토 두 건에서 접촉 상대 확인 불가로 합의한4개는 사전 선정 reserve4개로 교체한다. 기존 영상과 기록은 진단용으로 보존한다. 다중 사건과 접촉 가림으로 인한 판정 불가를 정확한 정답으로 강제하지 않는다.
- Stage3 차량 분리 정확도 실험: 가감속 -0.0026518253, 조향 +0.0030262272, 종합 -0.0009484096, 개선 경로6/12. 사전 기준을 통과하지 못해 새1128 특징/새모델을 채택하지 않는다. 공개OOF와 최종 재학습도 실행하지 않았다. 기존864 특징과 기존 모델의 예측을 보존하는 순수 계산 최적화만 별도로 검증한다.
- DADA 예비4개도 접촉 상대/최초 접촉의 확정 정답으로 인정하지 못했다. 총16개 자료에서 공식GT로 쓸 수 있는 시각 주석은0개다. 합의 가능한6개 대상의 방향과5개 진입 불확실 구간은 후보의 명백한 오류를 배제하는 보조 검사에만 쓴다. 프레임 구간 안의 예측을 정답으로 세지 않으며 대회0.3초 정확도를 계산하지 않는다. 저자 논문의 명목FPS는 각PNG의 실제PTS를 보장하지 않는다.
